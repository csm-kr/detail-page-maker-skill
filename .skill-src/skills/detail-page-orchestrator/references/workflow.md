# 실행 원칙

**순서와 예산은 여기 적지 않는다.** `scripts/lib/gates.mjs` 하나가 정의하고
`orchestrate gates` 가 표로 보여준다. 문서에 다시 적으면 갈린다 — 그것이 이 스킬을
재구성한 이유다.

이 문서는 게이트가 강제할 수 없는 것만 담는다.

## 입력과 완료

필수 입력은 공급처 URL 과 사용자가 지정한 쿠팡 URL 이다. 실물 제품 사진은 `data/` 에
두고 `start --photos` 로 잠근다. 없으면 같은 SKU 의 공급처 사진을 제품 기준으로 쓴다.

```text
output/detail-page.html
output/media/images/
output/media/gifs/
output/wing/<export-id>/
```

HTML, 섹션 이미지, GIF 의 작업 폭은 모두 780px 다.

## 무엇을 병렬로 하나

| 규칙 | 이유 |
| --- | --- |
| 같은 로컬 브라우저를 쓰는 수집은 **한 lane 에서 직렬** | 탭이 바뀌면 다른 대화·다른 페이지를 읽는다. 2회차에 이것을 "DOM 가상화" 로 오진했다 |
| 저장된 자료의 분석과 기획은 병렬 | 파일은 경쟁하지 않는다 |
| **선행 게이트가 통과한 단계만** 동시에 띄운다 | 2회차에 스틸을 백그라운드로 앞당긴 것이 무드 주입 누락의 직접 원인이었다 |
| 목업 대화는 병렬로 쪼개지 않는다 | 다른 탭은 다른 대화가 되어 톤이 갈린다. 실측: 한 턴 10장은 빠르지만 정렬·배경·아이콘이 갈렸다 |
| 이미지 provider 동시성은 agent slot 과 별개 | 32 workers 는 이미 최대다 |

`orchestrate run --parallel` 이 이 규칙을 적용한다. 사람이 기억하지 않는다.

## 한 생산자가 자기 결과의 유일한 검수자가 되지 않는다

판정은 언제나 그 단계의 `check.mjs` 가 한다. 사람이든 에이전트든 스크립트든
**통과 조건은 같다.** 자기 산출물을 자기 말로 승인하는 경로는 없다.

## 멈추는 조건

끝까지 진행하고, 아래일 때만 멈추고 **필요한 한 가지**를 요청한다.

- 입력에 접근할 수 없다 (URL·사진·캡처)
- 제품 SKU 또는 identity 가 충돌한다
- 필요한 주장을 사실로 뒷받침할 수 없다
- 권리 없는 고유 자산을 써야만 진행할 수 있다
- 로그인이 필요하다 — **ChatGPT 로그인과 `codex login` 은 사용자만 한다**
- 최종 HTML 또는 Wing 검증이 반복 실패한다

중간 승인과 고정 대기시간을 만들지 않는다.

## 강제 안전선

게이트가 검사하지만, 판단이 섞이는 부분은 여기 적어 둔다.

- 실물 사진이 있으면 최우선. 없으면 공급처 동일 SKU 를 기준으로 실루엣·색·부품·수량·
  방향을 유지한다
- 부품의 가동 범위, 분리 가능 여부, 결합 방향, 사용 자세 제약을 identity 와 함께 잠근다.
  **실물에서 불가능한 자세·결합·분리로 그려진 컷은 쓰지 않는다**
- 출처 없는 성능·효능·인증·수치·후기·판매량을 만들지 않는다
- 권리 없는 기준작의 이미지·문장·후기를 복제하지 않는다. **판매 논리만** 재구성한다
- 목업은 기획자료다. `output/` 에 두지 않고 발행하지 않는다. 배경 크롭은 한글이 없는
  영역만 쓰고, 목업 비율을 발행 컷에 그대로 적용하지 않는다
- 색은 한 곳에서만 정한다. 페이지와 GIF 가 같은 토큰을 본다
- 공개 HTML 과 Wing 에 프롬프트·모델·agent·파일명·경로·hash·QA·승인 상태 같은
  제작 메타데이터를 남기지 않는다

## 근거 없는 제약을 규칙으로 승격시키지 않는다

2회차에 앞 회차 문서의 한 문장("인물 얼굴 노출 금지")을 확인 없이 사실 문서에 규칙으로
옮겨 굳혔다. 스킬에 그런 규칙은 없었다.

**앞 회차 산출물을 근거로 쓰지 않는다.** 정책은 `env.lock.json` 의 `policy` 에만 있고,
그 값은 init 인터뷰에서 사용자가 답한 것이다.
