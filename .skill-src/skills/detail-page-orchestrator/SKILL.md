# Detail Page Orchestrator

지정한 쿠팡 상세페이지의 판매 흐름을 읽어 현재 상품의 사실과 자산으로 재구성한다.
**이 스킬은 일을 하지 않는다.** 순서·상태·검사·보고만 소유하고 실제 작업은 단계 스킬이 한다.

## 시작

1. `work/env.lock.json` 이 없으면 **`detail-page-init` 을 먼저 실행한다.**
   사용자가 `$init` 이라 부르는 단계다.
2. 제작을 시작한다.

   ```bash
   node scripts/orchestrate.mjs start --name <이름> \
     --supplier-url <공급처> --coupang-url <기준 쿠팡>
   ```

3. 출력된 표에서 **첫 번째 미통과 게이트의 스킬을 부른다.** 순서를 바꾸지 않는다.

   ```bash
   node scripts/orchestrate.mjs gates
   ```

4. 막히면 `gate <id> --check` 가 부족한 것을 한 줄로 알려준다.
5. `report` 가 exit 0 이 되기 전에는 **"완료" 라고 말하지 않는다.** 표를 그대로 붙인다.
6. 호스트별 역할 배분은 [`references/claude-code.md`](references/claude-code.md) 또는
   [`references/codex.md`](references/codex.md). **순서는 양쪽이 같다.**

## 명령

| 명령 | 내용 |
| --- | --- |
| `start` | 프로젝트 생성 + 상태 파일 + 표 |
| `gates` | 표, 첫 미통과 게이트와 부를 스킬 이름 |
| `gate <id> --start` | 시작 시각 기록. 이것이 없으면 `--pass` 가 거부된다 |
| `gate <id> --check` | 부족한 것을 출력 |
| `gate <id> --pass` | **검사를 다시 돌린 뒤에만** 통과 기록 |
| `gate <id> --exec` | 게이트 하나를 **새 세션**에서 돈다. 아래 참조 |
| `gate <id> --block <이유>` | 사람이 봐야 끝나는 자리. 실패와 구분한다 |
| `lock --read <경로> --url <url>` | 캡처를 해시와 함께 잠근다. 손으로 놓은 파일은 등록되지 않는다 |
| `run [--parallel]` | 판단이 필요한 지점까지 자동으로 걸어간다 |
| `run --exec` | 판단 게이트도 멈추지 않고 헤드리스로 완주한다 |
| `pack [<id>] [--write]` | 게이트가 세션에서 받는 것을 그대로 본다. 인자가 없으면 크기 표 |
| `report` | `work/report.md` 생성. 미통과가 있으면 exit 1 |
| `doctor` | 런타임·설치·정책 확인 |

트래커는 `node scripts/track.mjs`.

## 헤드리스 실행

한 세션이 게이트 12개를 다 들고 가면 실패가 난다. 실제로 난 것들이다 —
필드 이름이 **같은 세션에서 두 번** 갈렸고, 목업을 "ChatGPT 산출물이 아니다" 라고
알면서 자기 HTML 스크린샷으로 만들었고, 문서가 시키는 것과 산출물이 하는 것이
반대였다. 전부 설계 결함이 아니라 **주의력 결함**이다.

`--exec` 는 게이트마다 새 세션을 띄운다. 대화 맥락은 넘어가지 않는다.

```
gate G3 --exec
  ├─ 컨텍스트 팩을 조립한다      ← 게이트가 선언한 것만
  ├─ 남의 산출물 해시를 찍어 둔다
  ├─ claude -p (새 세션 · stdin · 예산×3, 바닥 10분·천장 30분)
  ├─ work/exec/G3-<n>.json 에 남긴다
  ├─ check.mjs 를 **부모가 다시 돌린다**
  └─ 통과 → 기록 · 실패 → 사유를 넣어 재시도 (최대 3회)
```

**자식의 자기 보고는 통과가 아니다.** 통과 판정은 언제나 부모의 `check.mjs` 다.
헤드리스로 가면 사람이 자식을 안 보므로 오히려 더 중요해진다.

**그렇다고 자식의 말을 버리지는 않는다.** 5회차에 자식이 두 회차 연속 "node 실행
권한이 막혔다" 고 보고했고 그게 사실이었는데, 실행기가 그 보고를 어디에도 남기지
않아 오진으로 흘려보냈다. 판정에서 뺀 것과 기록에서 빼는 것은 다른 일이다.
그래서 로그에 셋을 남기고 있으면 화면에도 한 줄 낸다.

| 남기는 것 | 무엇을 막는가 |
| --- | --- |
| `child.denials` | 자식이 무엇을 거부당했는지. 권한이 깨져도 "그냥 안 됐다" 로 안 끝난다 |
| `child.timed_out` | 끝까지 간 세션과 **죽인** 세션이 같아 보이는 것 |
| `child.trespass` | 남의 게이트 산출물을 고친 것. 팩이 금지하지만 말로 한 제약은 제약이 아니다 |

세션이 받는 것 — **통째로 붓지 않는다.**

| 무엇 | 어떻게 | 왜 |
| --- | --- | --- |
| 지시서 | SKILL.md 본문 | 그 게이트가 할 일 자체다 |
| 정본 | `gates.mjs` 의 `reads` 본문 | 읽히지 않아서 어긋난 것이 3회차의 실패다 |
| 입력 | **경로만** | 플랜 하나가 정본 전체보다 크다 |
| 앞 게이트 | 한 줄 요약 | 대화 맥락은 안 넘긴다 |
| 판정 | 지금 부족한 것 | 무엇으로 판정되는지 미리 안다 |

팩 크기는 정본 전량의 **1/3 이하**여야 한다. `pack` 으로 잰다.
결정적인 게이트(G0·G9·G10)는 세션을 띄우지 않는다 — 판단할 것이 없다.

권한을 통째로 끄지 않는다. 편집만 자동 승인하고(`acceptEdits`) 작업 범위를 회차 폴더로
묶고 도구를 `Read/Write/Edit/Glob/Grep/TodoWrite/Bash(node *)` 로 좁힌다.
`WebFetch`·`WebSearch` 는 막는다 — 수집은 `capture` 가 해시로 잠근다.
**프롬프트가 아니라 실행기가 정한다.**

인자를 셸에 넘길 때 반드시 감싼다. Windows 에서 `claude` 는 `.cmd` 셔임이라 셸이
필요한데, Node 는 `shell: true` 면 인자를 **이스케이프 없이 이어붙인다**(DEP0190).
4회차·5회차 초반의 자식들은 그래서 `Bash(node *)` 가 괄호와 공백에서 쪼개진
**깨진 허용 목록**을 받았고, `node -e "console.log(1+1)"` 조차 거부당했다.

5회차 실측 — 12게이트 완주 · 개입 2회 · 자식이 스스로 고친 결함 5건.
자세한 것은 [`docs/history/2026-08-06-5회차-헤드리스-완주.md`].

## 품질의 정의

이 스킬은 "단계를 밟았는가" 가 아니라 **"기준작만큼 나왔는가"** 를 본다.

| 문서 | 무엇 |
| --- | --- |
| [`references/benchmark/BENCHMARK.md`](references/benchmark/BENCHMARK.md) | 기준작 2개와 실측 하한. G3·G9 가 검사한다 |
| [`references/sales-story.md`](references/sales-story.md) | 판매 서사 순서와 `role`, 소구점 계약. G2·G3 가 검사한다 |

**하한은 두 기준작 실측의 최솟값이다.** 사람이 고르지 않는다 — 낮춰 잡은 하한은
하한이 아니라 면제다. 올리고 싶으면 하한이 아니라 기준작을 바꾼다.

```
sections 13 · fullBleed 4 · overlays 3 · visualStages 8 · maxTypePx 116 · typeScale 21
```

- 공급처와 쿠팡이 쓰는 판매 표현은 **그대로 쓴다.** 과장이어도 원문에 있으면 쓴다.
  G2 가 6개 이상 모으고 G3 이 3개 이상 실제로 쓰는지 본다
- 고객 화면에 제작 과정을 쓰지 않는다. 한계 고지는 **푸터 한 줄**로 모은다
- GIF 의 입력은 **발행된 스틸**이다. 도형에 애니메이션을 걸지 않는다
- GIF 는 **얼마나 오래 보이는가**도 잰다. 첫 프레임 0.8초, 마지막 1초, 한 바퀴 2.5초 이상
- 목업은 **밖에서** 온다. 우리 HTML 을 찍은 스크린샷은 목업이 아니라 결과물이다

## 규칙

- **우회 플래그가 없다.** `--force` 를 만들지 않는다. 게이트가 틀렸으면 게이트를 고친다.
- 게이트 정의·순서·예산은 [`scripts/lib/gates.mjs`](scripts/lib/gates.mjs) 한 곳에만 있다.
  다른 문서에 다시 적지 않는다 — 적으면 갈린다.
- 상류 산출물이 바뀌면 하류 게이트가 **자동으로 되돌아간다.** 정상 동작이다.
- 단계 스킬을 직접 부르면 선행 게이트 검사로 거부된다.
- 실행 원칙과 안전선은 [`references/workflow.md`](references/workflow.md).
