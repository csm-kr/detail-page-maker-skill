# 쿠팡 상세페이지 이미지 제작 프롬프트 템플릿



이 문서는 쿠팡 모바일 상세설명 영역에 업로드할 수 있는 세로형 상세페이지 이미지를 제작하기 위한 프롬프트 템플릿이다.  

기본 목표는 **제품 정보에 근거한 신뢰감 있는 광고형 상세페이지 N장**을 만드는 것이다.

N은 제공된 상세페이지 기획에 따라 정해진다. 단, 상세페이지의 설득 흐름과 정보 전달력을 충분히 확보할 수 있도록 **10장 이상**으로 구성한다.

이 문서는 상세페이지의 전체 기획을 고정하는 템플릿이 아니다.  
사용자가 제공한 기획안의 장수, 순서, 핵심 메시지, 장면 구성, 강조 포인트를 바탕으로 각 장의 이미지 생성 프롬프트를 만드는 데 사용한다.

전체 구성은 제공된 기획안에 따라 달라질 수 있으며, 상품 특성과 제작 목적에 맞게 장면을 합치거나 나누고, 순서를 조정하거나 필요한 장면을 추가할 수 있다.  
다만 사용자가 명시한 기획 의도와 핵심 메시지를 임의로 변경하거나 삭제하지 않는다.



---



## 1. 사용 목적



이 프롬프트는 다음 목적에 사용한다.



- 쿠팡 상품 상세페이지 이미지 기획

- 780px × 1560px 세로형 상세페이지 이미지 제작

- 모바일에서 읽기 쉬운 광고형 상세페이지 구성

- 상품의 핵심 장점과 구매 판단에 필요한 정보를 중심으로 한 구매 설득 흐름 설계

- 과장 광고, 허위 수치, 임의 리뷰, 임의 인증 문구 방지



---



## 2. 상세페이지 기획안 입력란

아래에는 이미 작성된 상세페이지 기획안을 입력한다.

기획안에는 가능한 경우 다음 내용을 포함한다.

- 전체 예상 장수 또는 최소 장수
- 장별 목적
- 장별 핵심 메시지
- 장별 헤드라인과 보조 문구
- 사용해야 할 제품 컷 또는 연출 장면
- Before / After, 비교, 사용법, 규격, 구성품 등 필수 장면
- 반드시 유지해야 할 순서
- 삭제하거나 변경하면 안 되는 요소
- 이미지 생성 시 강조할 제품 디테일
- 후편집 예정인 텍스트 영역

제공된 기획안은 전체 제작의 기준이다.  
에이전트는 이 기획안을 분석하여 각 장별 이미지 생성 프롬프트를 작성한다.

기획안이 충분히 구체적이면 그대로 따른다.  
기획안에 시각적 설명이 부족하거나 이미지 생성에 필요한 정보가 빠져 있으면 상품 정보 범위 안에서만 보완한다.  
상품 정보에 없는 기능, 수치, 인증, 장면은 임의로 추가하지 않는다.

## 4. 제작 규격





text

[제작 규격]



- 총 10장의 상세페이지 이미지를 제작한다.

- 각 이미지는 780px × 1560px 세로형 이미지로 제작한다.

- 쿠팡 모바일 상세설명 영역에 적합한 광고형 상세페이지 디자인으로 만든다.

- 각 이미지는 독립적으로 보이되, 전체 N장을 이어서 보면 자연스러운 구매 설득 흐름이 되도록 구성한다.

- 한 장에 너무 많은 정보를 넣지 않는다.

- 모바일에서 잘 읽히는 큰 글씨와 짧은 문구를 사용한다.

- 제품 이미지, 짧은 카피, 아이콘, 카드형 정보, 비교 구성, 사용 장면 등을 적절히 활용한다.

- 전체 이미지는 하나의 브랜드 상세페이지처럼 톤앤매너를 통일한다.





---



## 5. 디자인 방향





text

[디자인 방향]



- 깔끔하고 신뢰감 있는 공산품 상세페이지 스타일로 만든다.

- 모바일에서 한눈에 읽히는 큰 헤드라인을 사용한다.

- 제품의 장점이 직관적으로 보이는 구성을 사용한다.

- 과도한 장식보다 제품과 메시지 중심의 레이아웃을 사용한다.

- 배경은 깔끔하고 제품을 돋보이게 만든다.

- 텍스트는 자연스러운 한글로 작성한다.

- 너무 작은 글씨, 긴 문단, 복잡한 표는 피한다.

- 여백을 충분히 두고, 정보는 카드형으로 정리한다.

- 제품 이미지가 가장 먼저 눈에 들어오도록 배치한다.

- 전체 색감은 상품 분위기에 맞추되 과하게 튀지 않게 구성한다.





---



## 6. 텍스트 작성 규칙



이미지 생성 모델은 한글 텍스트를 깨뜨릴 수 있으므로 문구는 짧고 명확하게 작성한다.





text

[텍스트 규칙]



- 모든 문구는 자연스러운 한글로 작성한다.

- 한 이미지당 메인 헤드라인은 1개만 사용한다.

- 보조 문구는 1~3개 이내로 제한한다.

- 긴 문장보다 짧은 카피를 사용한다.

- 작은 설명문, 긴 문단, 복잡한 표 텍스트는 만들지 않는다.

- 텍스트가 깨질 가능성이 있는 경우 텍스트 영역은 비워두고 후편집 가능한 여백을 남긴다.

- 의미 없는 영어 더미 텍스트를 넣지 않는다.

- 깨진 한글이나 무의미한 문자를 넣지 않는다.

- 상품 정보에 없는 수치, 인증, 리뷰, 별점, 판매량은 절대 만들지 않는다.





---



## 7. 광고 표현 제한



상세페이지는 구매 설득을 위한 광고 이미지이지만, 과장 광고처럼 보이면 안 된다.





text

[광고 표현 제한]



- 입력되지 않은 가격, 할인율, 리뷰 수, 별점, 판매량을 임의로 만들지 않는다.

- 입력되지 않은 인증, 테스트 결과, 수상 내역, 보증 문구를 임의로 만들지 않는다.

- 의학적 효능, 치료, 완치, 회복, 개선 보장처럼 보이는 표현을 사용하지 않는다.

- "100%", "완벽", "무조건", "최고", "1위" 같은 근거 없는 절대 표현을 사용하지 않는다.

- Before / After는 효능 보장처럼 표현하지 않는다.

- 사용 전후 비교가 필요한 경우, 신체 변화나 효과 보장이 아니라 "불편한 상황 vs 편리한 사용 상황"으로 구성한다.

- 환불/보증 정보가 입력되어 있지 않다면 허위 보장 문구를 넣지 않는다.





---



## 8. 절대 금지 요소





text

[절대 금지]



- 이미지 안에 Page 01, Page 02, 페이지 번호, 장 번호를 넣지 않는다.

- 쿠팡 로고, Coupang 로고를 넣지 않는다.

- 검색 아이콘, 장바구니 아이콘, 하트 아이콘을 넣지 않는다.

- 쿠팡 앱 화면, 앱 상단바, 모바일 UI 프레임, 스마트폰 목업을 넣지 않는다.

- 실제 쿠팡 공식 화면처럼 보이는 디자인을 만들지 않는다.

- 입력되지 않은 가격, 할인율, 리뷰 수, 별점, 판매량을 임의로 만들지 않는다.

- 입력되지 않은 인증, 테스트 결과, 수상 내역, 보증 문구를 임의로 만들지 않는다.

- 깨진 한글, 의미 없는 영어 더미 텍스트를 넣지 않는다.

- 과장 광고나 허위 효능처럼 보이는 표현은 사용하지 않는다.

- 제품과 무관한 인물, 배경, 소품을 임의로 넣지 않는다.

- 브랜드명이 입력되지 않았다면 임의 브랜드 로고를 만들지 않는다.

## 9. N장 상세페이지 구성



아래 흐름은 기획안이 일부 비어 있거나 장면 구체화가 필요할 때 참고하는 보조 모듈이다.

제공된 기획안이 있으면 그 기획안의 장수, 순서, 메시지와 장면 구성을 우선한다.  
아래 모듈을 반드시 모두 사용하거나 동일한 순서로 배치할 필요는 없다.  
필요한 경우에만 장면을 합치거나 나누고, 이미지 생성에 필요한 수준으로 구체화한다.



---



### 기본 모듈 A: 문제 후킹





text

고객이 겪는 대표 불편함을 보여주는 후킹 이미지로 구성한다.



구성:

- 큰 헤드라인

- 문제 상황을 보여주는 이미지

- 짧은 공감 문구



목표:

- 고객이 "내 얘기다"라고 느끼게 만든다.

- 제품을 바로 설명하기보다 문제 상황에 집중한다.



주의:

- 과장된 공포 마케팅은 피한다.

- 신체적 변화나 질병처럼 보이는 표현은 피한다.





---



### 기본 모듈 B: 상품이 필요한 이유





text

상품이 필요한 이유를 설명한다.



구성:

- 기존 방식의 아쉬움 3가지

- 불편함을 카드형으로 정리

- 간단한 아이콘 또는 상황 이미지



목표:

- 고객이 왜 이 상품을 고려해야 하는지 이해하게 만든다.



주의:

- 경쟁 제품을 비방하지 않는다.

- 검증되지 않은 수치를 넣지 않는다.





---



### 기본 모듈 C: 상품 메인 소개





text

상품을 메인으로 보여준다.



구성:

- 상품 이미지 크게 배치

- 상품명

- 메인 소구점

- 핵심 장점 3가지



목표:

- 이 상품이 무엇이고 어떤 장점이 있는지 한눈에 보여준다.



주의:

- 핵심 장점 3가지는 사용자가 입력한 문구를 기준으로만 작성한다.

- 입력되지 않은 기능을 추가하지 않는다.





---



### 기본 모듈 D: 사용 전후 상황 비교





text

사용 전후의 과장된 효능 비교가 아니라,

사용하지 않았을 때의 불편한 상황과 사용했을 때의 편리한 상황을 비교한다.



구성:

- 좌측: 사용 전 불편 상황

- 우측: 사용 후 편리한 사용 상황

- 짧은 비교 문구



목표:

- 상품 사용으로 얻을 수 있는 실용적 차이를 직관적으로 보여준다.



주의:

- 치료, 개선, 회복, 효과 보장처럼 보이는 표현을 사용하지 않는다.

- Before / After가 신체 변화나 효능 보장처럼 보이지 않게 한다.





---



### 기본 모듈 E: 핵심 장점 상세 설명





text

상품의 핵심 장점을 중요도와 정보량에 따라 한 장 또는 여러 장으로 나누어 설명한다.



구성:

- 제품 디테일 컷

- 장점별 카드 또는 장점별 독립 장면

- 짧은 문구와 아이콘



목표:

- 상품의 주요 장점을 구체적으로 이해시킨다.



주의:

- 입력된 핵심 장점의 범위 안에서만 설명한다.

- 없는 테스트 결과나 수치를 만들지 않는다.





---



### 기본 모듈 F: 추가 장점 및 사용 편의 설명





text

추가 핵심 장점, 사용 편의성 또는 구매 판단에 필요한 세부 정보를 설명한다.



구성:

- 사용 편의성, 실용성, 내구성, 휴대성 등 상품에 맞는 포인트

- 제품 사용 장면

- 짧은 보조 설명



목표:

- 구매자가 실제 생활에서 어떻게 편하게 쓸 수 있는지 보여준다.



주의:

- 상품 정보에 없는 내구성, 방수, 항균, 냉감, 보온 등의 기능을 임의로 넣지 않는다.





---



### 선택 모듈 G: 일반 제품과 비교





text

일반 제품과 우리 제품을 비교한다.



구성:

- 비교표 3~5개 항목

- 복잡하지 않은 O / △ / X 또는 짧은 문구 비교

- 제품 이미지 또는 아이콘



목표:

- 차별점을 직관적으로 보여준다.



주의:

## 10. 권장 작업 방식



이미지 생성 AI는 한 번에 전체 N장을 완벽하게 만들기 어렵다.  

따라서 아래 순서로 작업하는 것을 권장한다.





text

1단계:

먼저 제공된 기획안을 분석하고, 전체 N장의 장별 목적, 헤드라인, 보조문구, 이미지 구성을 정리한다. 기획안에 누락된 시각 정보만 상품 정보 범위 안에서 보완한다.



2단계:

각 장별로 이미지 생성 프롬프트를 따로 만든다.



3단계:

1장씩 이미지를 생성한다.



4단계:

한글 텍스트가 깨진 경우, 텍스트 없는 버전으로 다시 생성하고 후편집한다.



5단계:

전체 N장을 이어 붙였을 때 구매 설득 흐름이 자연스러운지, 중복되거나 불필요한 장면이 없는지 검토한다.

- N은 최소 10장 이상으로 구성하되, 정보 반복이나 의미 없는 장수 늘리기는 금지한다.

- 각 프롬프트는 쿠팡 상세설명 영역에 업로드 가능한 완성형 세로 이미지를 생성할 수 있을 만큼 구체적이어야 한다.

- 실제 이미지 안에는 페이지 번호나 Page 문구를 넣지 않는다.

- 쿠팡 로고, 앱 UI, 검색창, 장바구니 아이콘을 넣지 않는다.

- 모든 문구는 자연스러운 한글로 작성한다.

- 제품 정보에 없는 내용은 임의로 만들지 않는다.

- 입력된 상품 정보와 확인 가능한 핵심 장점을 기준으로만 구성한다.

- 한 장에 너무 많은 정보를 넣지 않고, 모바일에서 읽기 쉬운 큰 글씨와 짧은 문구를 사용한다.

- 과장 광고나 허위 효능처럼 보이는 표현을 사용하지 않는다.

text

[디자인 방향]

- 전체 N장의 톤앤매너는 통일감 있게 구성한다.

- 여백을 충분히 두고, 정보는 카드형으로 정리한다.

- 사용 전후 비교가 필요한 경우, 신체 변화나 효과 보장이 아니라 "불편한 상황 vs 편리한 사용 상황"으로 구성한다.

- 환불/보증 정보가 입력되어 있지 않다면 허위 보장 문구를 넣지 않는다.

- 쿠팡 로고, Coupang 로고를 넣지 않는다.

실제로 활용 가능한 장소와 상황을 보여준다.

- 입력된 상품 정보와 확인 가능한 핵심 장점을 기준으로만 구성한다.

- 한 장에 너무 많은 정보를 넣지 않고, 모바일에서 읽기 쉬운 큰 글씨와 짧은 문구를 사용한다.

- 과장 광고나 허위 효능처럼 보이는 표현을 사용하지 않는다.
