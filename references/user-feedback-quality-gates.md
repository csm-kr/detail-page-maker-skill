# 사용자 피드백 기반 상용 품질 게이트

최근 노바페이스 기능성깔창 제작에서 반복된 사용자 피드백을 다음 상품에도 재사용할 수 있도록 검수 규칙으로 정규화한다. 대화 문장을 그대로 복사하지 않고 `요청 요지 → 실패 예시 → 통과 조건 → 증거`로 판정한다.

## 최근 품질 향상 요구 20개

## 적용 순서

1. 제작 시작 전에 6·8·9·10번으로 제품 구조를 잠근다.
2. 기획 단계에서 1·2·16·19번으로 전체 서사를 만든다.
3. ImageGen 단계에서 7·8·9·10·11·12번을 검사한다.
4. HyperFrames 단계에서 3·4·5·10·13번을 검사한다.
5. HTML 단계에서 13·14·15·17·18·20번을 검사한다.
6. 최종 QA에서 20개를 모두 `pass | fail | not-applicable`로 기록한다. 증거가 없으면 pass로 판정하지 않는다.

## 노바페이스 즉시 회귀 항목

- `ventilation-airflow-v2.png`는 블루쿠션에서 공기가 나오는 것처럼 보여 폐기한다.
- 통풍 장면은 `ventilation-airflow-v4.png`와 에어홀 전용 HyperFrames 경로로 교체한다.
- 쿠션 장면은 `cushion-impact-v4.png`에서 `ZOOM SPORTS`와 블루쿠션 위치를 확인한다.
- `발이 닿는 면은 부드럽게`, `발의 움직임을 따라`, `노바페이스를 넣어주세요`는 단어 중간 분절 없이 고정한다.
- `Flux2-Klein_00355_.png`는 사용자 승격 SSOT로 사용한다.
- 에어홀·블루쿠션·유연함 장면에서 `ZOOM SPORTS`가 모두 보이는지 장면별로 확인한다. 한 장면의 보존을 다른 장면의 통과로 대신하지 않는다.
- 말풍선 본체와 SVG 꼬리는 같은 불투명 단색을 사용한다. 반투명 색을 겹쳐 본체 경계가 진해지면 실패다.
- 후기처럼 읽히는 소구 메시지를 3개 이상 두되 포근한 지지·에어홀 통기·쉬운 사이즈 선택처럼 서로 다른 소구를 맡긴다. 별점·실명·구매 인증·후기 출처는 만들지 않는다.
- 제품 인쇄는 생성 이미지 안에 포함하고 HTML·SVG·HyperFrames 텍스트 오버레이를 제거한다.
- `상면/하면`은 구매자 화면에서 `윗면/아랫면`으로 바꾼다.
- 소재 비교 분할선은 좌우 끝 상태를 각각 홀드하고 화면 폭의 절반 이상을 이동한다. 중앙의 짧은 왕복은 실패다.
- 군화·작업화·운동화·일상화 사용 상황은 각각 별도 ImageGen 이미지로 보여 주며 한 장의 배경을 재사용하지 않는다.
- 같은 삽입 장면을 정적 사진과 GIF로 연속 반복하지 않고 GIF 하나로 합친다.

## v10 추가 회귀 항목

- 좌우 윗면은 동일 길이·외곽·패턴을 유지하면서 안쪽 아치가 중앙을 향하는 진짜 거울 대칭이어야 한다.
- `ZOOM SPORTS`는 철자뿐 아니라 블루쿠션·제품 장축과 같은 방향으로 놓여야 한다.
- GIF의 상태 라벨과 작은 설명은 800×800 기준 18px·700 이상을 기본으로 하고 390px 카드 축소 화면에서 다시 읽는다.
- 사이즈 선택 포인터는 `260` 카드 내부 도착, 눌림, 활성 상태 전환의 세 단계를 모두 보여 준다.
- 군화 장면은 군화를 실제로 신은 상태여야 하며 벗어 둔 군화 정물은 실패다.
- 네 사용 장면이 착화 행동과 장소를 충분히 보여 주면 작은 제품 인셋은 제거한다. 제품 존재가 메시지인 삽입·구성·피날레에만 제품을 유지하고 길이·로고·장축을 검사한다.
- 마지막 장면은 네 종류 신발과 제품 한 쌍을 함께 보여 주고, 착화 후 장면은 과장 없는 보행 파동으로 마감한다.
- Studio 후속판은 말풍선·꼬리·텍스트·GIF·이미지 박스 위치를 layer ID로 수정하고 스냅·안전영역으로 얼라인을 유지해야 한다.

## v11 추가 회귀 항목

- 블루쿠션의 정확한 `ZOOM SPORTS`와 흰 PU 본체의 정확한 `SPORTS`를 별도 검사한다. `STORTS`, `ZZOM`, `ZZOOM`은 하드 실패다.
- 제품 문자 기준선은 화면 수평이 아니라 블루쿠션과 깔창의 장축을 따라야 한다.
- HyperFrames의 모든 한글은 HTML과 같은 폰트 계열·굵기·색을 사용하고 390px 카드 안에서 읽어 승인한다.
- 두 줄 모션 제목의 글리프 bounding box가 겹치면 line-height와 줄 간격을 늘린다.
- 255mm→260처럼 양쪽 텍스트를 연결하는 화살표는 두 텍스트 bounding box와의 좌우 간격을 같게 맞춘다.
- 사이즈 장의 결과바는 첫 프레임부터 읽히게 해 하단의 긴 빈 공간을 만들지 않는다.
- 굽힘 곡선의 오목·볼록 방향은 실제 제품 굽힘 방향과 일치해야 한다.
