# 제품 SSOT·ImageGen 동일성 규약

## 자산 위계

1. 사용자가 직접 수정하고 SSOT로 승격한 제품 참조
2. 사용자가 제공한 동일 SKU 실제품 촬영 원본
3. 공급처 원본
4. 동일성 검수를 통과한 ImageGen 상용 파생 소재

실제 촬영본은 기본적으로 소비자 화면에 바로 쓰는 완성 소재가 아니라 제품 정체성 기준이다. 거친 누끼, 촬영 책상, 비상업 조명은 공개 자산으로 자동 승격하지 않는다.

## 사용자 승격 SSOT

사용자가 생성·수정 이미지를 명시적으로 SSOT로 승격하면 다음을 manifest에 기록한다.

- 파일명과 승격 시각
- 사용자가 수정했거나 승인했다는 provenance
- 구조 판단에 사용할 역할
- 공개 페이지 직접 사용 여부
- 다른 원본과 충돌할 때의 우선순위

노바페이스의 `Flux2-Klein_00355_.png`는 측면 두께, 굽힘 곡선, 에어셀과 블루쿠션의 상대 위치를 판단하는 사용자 승격 SSOT다.

## 면 지도

| 면 | 반드시 보이는 구조 | 보이면 안 되는 구조 |
|---|---|---|
| 윗면 | 회색 에어메시, 회색 뒤꿈치 접촉 패치 | 블루쿠션, 아랫면 에어셀 |
| 아랫면 | 흰색 PU 입체 에어셀, 앞꿈치·중족부 에어홀, 뒤꿈치 중앙 블루쿠션 | 회색 힐 접촉 패치 |

## 명칭 레지스트리

- 둥근 입체 완충 구조: `에어셀`
- 실제로 뚫린 원형 구멍: `에어홀`
- 아랫면 뒤꿈치 중앙의 파란 고체 부품: `블루쿠션`
- 블루쿠션의 제품 인쇄: `ZOOM SPORTS`

`통풍홀`, `타공`, `구멍`, `블루 패드`, `힐 포인트`를 같은 페이지에서 혼용하지 않는다.

## 위치형 부품 검수

“뒤꿈치에 있다”만으로 승인하지 않는다.

- 전체 길이 대비 부품 길이
- 해당 구역 폭 대비 부품 폭
- 부품 바깥의 셀 테두리 여유
- 장축 방향
- 인접 에어홀과의 거리
- 다른 면에서의 노출 여부

한 장면에서 위치 오류가 발견되면 같은 구조가 나오는 모든 이미지·GIF를 다시 검사한다.

## 기능-구조 인과 지도

시각 효과는 실제 구조에서 시작해야 한다.

- 통풍 효과 → 앞꿈치·중족부의 실제 에어홀
- 쿠션 파동 → 에어셀 또는 블루쿠션
- 굽힘 곡선 → PU 본체
- 윗면 접촉 → 에어메시

구멍이 없는 블루쿠션에서 바람이 나오면 하드 실패다. 블루쿠션 표면과 가장자리에는 통풍 광선·입자·바람의 시작점을 두지 않는다.

## ImageGen 프롬프트 필수 블록

1. 제품 역할과 보이는 면
2. surface map의 보존 대상
3. 위치형 부품의 상대 비율
4. 고유 인쇄와 읽혀야 할 정확한 문자
5. 효과 시작점과 금지 영역
6. 카메라·조명·안전 여백
7. 바꾸면 안 되는 형상·색상·부품 수

## 승인 게이트

- 실루엣과 길이·폭 비율
- 윗면·아랫면 분리
- 에어셀과 에어홀 구분
- 블루쿠션 위치·크기
- `ZOOM SPORTS` 보존
- 사용 장면에서 물리적으로 올바른 면
- 첫·중간·마지막 프레임의 제품 동일성

하나라도 불확실하면 공개 자산으로 승격하지 않는다.

## 고유 인쇄 보존과 보정

- 고유 인쇄는 작은 장식이 아니라 제품 동일성이다. 한 소재에서 보존됐다고 다른 소재를 자동 승인하지 않는다.
- `ZOOM SPORTS`가 보여야 하는 에어홀·블루쿠션·유연함 장면을 각각 확대해 철자·줄 순서·방향·부품 안쪽 위치를 검사한다.
- ImageGen이 인쇄를 누락하거나 글자를 왜곡하면 승인된 실제 부품 패치를 결과 이미지 안에 원근·각도·조명까지 맞춰 합성하거나 해당 장면을 다시 만든다.
- HTML·SVG·HyperFrames의 별도 텍스트 오버레이는 화면 위에 글자가 떠 보이고 제품 회전·변형과 분리되므로 최종 공개 자산에서 금지한다.
- 정적 확대와 GIF 첫·중간·마지막 프레임 모두 같은 픽셀 인쇄를 공유해야 한다. 인쇄가 이미지에 포함되지 않으면 공개 자산으로 승인하지 않는다.

## 사용 상황 ImageGen 분리

- 사용 상황 하나마다 `신발 종류 / 장소 / 행동 / 조명` 중 둘 이상을 달리한다.
- 제품 동일성이 필요 없는 배경에는 제품을 생성하지 않는다. 군화·작업화·운동화·일상화 같은 무브랜드 신발만 보여 주고 제품 구조 주장은 인접 HTML·GIF가 맡는다.
- 생성 장수 목표는 각 장면이 다른 구매 질문을 답할 때만 의미가 있다. 같은 구도와 배경을 색만 바꾼 이미지는 장수로 세지 않는다.
