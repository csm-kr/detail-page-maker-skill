# Behance 제품 상세페이지 디자인 문법 조사

조사일: 2026-07-24  
조사 진입점: [Behance `상세페이지` 검색 결과](https://www.behance.net/search/projects/%EC%83%81%EC%84%B8%ED%8E%98%EC%9D%B4%EC%A7%80)

## 결론

조사한 우수 사례 9개는 서로 다른 미감에도 불구하고 공통적으로 다음 순서를 사용한다.

> 제품·가치의 즉시 인지 → 고객 상황 또는 문제 → 해결 원리와 핵심 장점 → 구조·성분·수치 증거 → 사용 장면과 방법 → 구매 전 확인 정보

완성도를 만드는 핵심은 특정 작품의 컬러나 구도를 복제하는 데 있지 않다. 긴 페이지에서 `감성 장면`, `설명 장면`, `증거 장면`을 번갈아 배치하고, 각 주장과 그 주장을 뒷받침하는 시각 자료를 한 시야 안이나 바로 다음 블록에 두는 데 있다. 타이포그래피는 페이지 전체에서 같은 비율 체계를 유지하되, 제품군에 맞춰 서체 성격과 정렬 방식만 바뀐다. 제품 연출은 한 장의 멋진 합성으로 끝나지 않고 `전체 형태 → 사용 스케일 → 작동 부위 → 재질 매크로 → 결과`로 카메라 거리를 바꾼다.

이 문법을 수정 가능한 HTML 상세페이지에 적용할 때는 이미지 안에 구워진 카피를 그대로 모방하지 않는다. 카피·수치·캡션·근거 출처는 HTML 데이터로 분리하고, 제품 사진과 GIF만 교체 가능한 자산으로 둔다.

## 조사 방법과 선정 기준

- 사용자가 지정한 Behance 검색 결과와 스포틀러 스텝밀 프로젝트를 브라우저에서 직접 열었다.
- 검색 카드만 보지 않고 각 원본 프로젝트의 상단, 중단, 하단과 로드된 프로젝트 이미지·GIF 모듈을 확인했다.
- 운동기구, 헤어케어, 기능성 음료, 유아 조리가전, 구강용품, 반려동물 영양제, 주얼리, 페이스타월, 밀키트로 제품군을 분산했다.
- 조회수는 선정 기준으로 사용하지 않았다. 첫 화면 전달력, 긴 페이지의 리듬, 타이포 위계, 제품과 배경의 일관성, 주장과 증거의 연결, 구매 판단 정보의 구조화를 기준으로 삼았다.
- 아래의 조회·평가 수는 조사 시점에 화면에 보인 동적 스냅샷일 뿐 품질이나 전환 성과를 입증하지 않는다.
- Behance 프로젝트는 판매 채널의 실제 전환율 자료가 아니다. 또한 일부 프로젝트는 AI 비주얼 또는 목업 사용을 명시한다. 따라서 여기서 추출하는 것은 시각 문법이며 제품 사실이나 광고 근거가 아니다.

## 표본 9개와 작품별 관찰 근거

### 1. 스포틀러 스텝밀 상세페이지 — 운동기구

- 원본: [스포틀러 스텝밀 상세페이지](https://www.behance.net/gallery/222599995/_?tracking_source=search_projects%7C%EC%83%81%EC%84%B8%ED%8E%98%EC%9D%B4%EC%A7%80&l=14)
- 제작자·게시: 김예지, 2025-03-31
- 조사 시 화면 수치: 평가 5, 조회 387
- 선정 이유: 지정 표본이며, 감성적 홈 피트니스 연출과 기계 구조의 설명을 긴 페이지 안에서 가장 적극적으로 교차한다.
- 정보 구조 관찰:
  - 밝은 주거 공간과 운동 모델로 “집에서 하는 새로운 운동”이라는 사용 맥락을 먼저 전달한다.
  - 일반 스텝밀과 제품을 같은 화면에서 비교하고 `2090 mm`, `1510 mm`, `580 DOWN`처럼 공간 절약을 치수로 보인다.
  - 이후 `POINT 01`부터 번호화된 장점으로 전환해 롤링 스텝, 이중 롤러·강철 레일, 핸들바, 6 kg 드럼 같은 기능을 한 번에 하나씩 설명한다.
- 타이포 관찰: 작은 영문 눈썹·포인트 라벨, 중간 크기 효익 문장, 두 줄의 굵은 핵심 제목 순이다. 밝은 베이지 화면에서 짙은 회갈색을 사용해 제품의 가정용·프리미엄 인상을 유지한다.
- 제품 연출 관찰: 전신 사용 장면, 경쟁 구조와 나란히 놓은 측면 비교, 롤러와 레일의 매크로, 손과 발의 접촉 장면으로 카메라 거리가 반복해서 바뀐다.
- 증거 표현 관찰: 치수선, 동일 화면 비교, 부품 매크로와 영문 부품명, 손목 부담 부위 오버레이를 주장 바로 아래에 둔다.
- 모션 관찰: 프로젝트에 다수의 GIF 모듈이 삽입되어 있다. 직접 확인한 GIF는 페달 왕복과 사용 자세를 시간축으로 보여준다. 다만 여러 자세를 한 GIF에 묶는 포트폴리오식 몽타주는 새 스킬의 `한 GIF 한 주장` 원칙에는 그대로 사용하지 않는다.
- 추출할 규칙: 큰 운동기구는 `공간 적합성 → 사용 자세 → 구동 구조 → 접촉 안전성` 순으로 설명하고, 치수 비교와 부품 매크로를 감성 사진 사이에 넣는다.
- 복제하지 않을 요소: 동일 모델·실내 세트, 베이지 팔레트, `POINT 01` 캡슐 모양, 원문의 카피와 비교 실루엣.

### 2. 헤어 팩 트리트먼트 뷰티 상세페이지 — 헤어케어

- 원본: [헤어 팩 트리트먼트 뷰티 상세페이지 디자인](https://www.behance.net/gallery/246328393/_)
- 제작자·게시: 누니 스튜디오, 2026-03-24
- 조사 시 화면 수치: 평가 27, 조회 약 1.9천
- 선정 이유: 제품의 색·질감에서 페이지 전체 미감을 끌어내고, 감성 카피에서 성분·시험 수치까지 설득 강도를 단계적으로 높인다.
- 정보 구조 관찰:
  - 말차색 용기와 모찌 같은 제형을 첫 인상으로 고정한 뒤 소비자 후기형 말풍선으로 사용 감각을 제시한다.
  - “특별한 이유”를 4개 효익으로 묶고, 이후 성분 조합과 체감 수치로 이동한다.
  - 구매 혜택 블록도 존재하지만 제품 가치보다 먼저 놓일 경우 캠페인 정보가 제품 논리를 가릴 수 있어 일반형 상세페이지에서는 후순위가 적합하다.
- 타이포 관찰: 짙은 올리브 배경에서는 굵은 흰색 산세리프, 밝은 크림 배경에서는 짙은 회색 본문, 핵심 수치는 큰 올리브색으로 처리한다. 제품명과 장식적 영문은 브랜드 성격을 만들고, 기능 설명은 읽기 쉬운 산세리프로 분리한다.
- 제품 연출 관찰: 완성 용기뿐 아니라 뚜껑 위로 늘어나는 제형, 용기 매크로, 머릿결 전후와 성분 조합을 함께 사용한다. 제품의 고유한 물성이 곧 페이지의 그래픽 언어가 된다.
- 증거 표현 관찰: 네 개 원이 겹치는 성분·효익 도식, `522.17%`처럼 크게 드러낸 수치, 전후 머릿결 분할 화면이 사용된다. 실제 HTML에서는 시험 조건·대상·기간·출처가 같은 블록에 있어야 수치가 증거가 된다.
- 모션 관찰: 확인된 GIF는 머릿결 상태의 전후를 시간차로 보여준다. 제형이 늘어나는 정도나 도포 전후처럼 정지 이미지로 변화량을 설명하기 어려운 장면이 우선 모션 후보이다.
- 추출할 규칙: 뷰티 제품은 `감각적 물성 → 사용자가 느끼는 변화 → 작용 성분 → 시험 근거`로 추상적 효익을 구체화한다.
- 복제하지 않을 요소: 말차·모찌 콘셉트, 올리브 팔레트, 제품명, `522.17%` 수치와 원형 네 개 도식의 외형.

### 3. 마시는 샐러드 식품 상세페이지 — 기능성 음료

- 원본: [마시는 샐러드 식품 상세페이지 디자인](https://www.behance.net/gallery/240887707/_)
- 제작자·게시: Sungbae Park, 2025-12-22
- 조사 시 화면 수치: 평가 20, 조회 약 1.8천
- 선정 이유: 미니멀한 브랜드 인상과 많은 원료·섭취 정보를 충돌 없이 한 페이지에 담는다.
- 정보 구조 관찰:
  - 연두색 패키지 군집으로 SKU와 제품군을 먼저 보여주고, 큰 세리프 `DAY SALAD`로 브랜드 선언을 한다.
  - `48가지 채소·과일`이라는 핵심 약속을 제시한 뒤 원료를 레드·퍼플·옐로 등 색군으로 분류한다.
  - 후반에는 1일 섭취 횟수, 물의 양, 섞는 방법처럼 실제 사용 정보를 단계화한다.
- 타이포 관찰: 감성 선언에는 고대비 영문 세리프를 크게 쓰고, 한국어 설명과 수치에는 산세리프를 사용한다. 원료군의 색을 제목·불릿·제품 이미지에 제한적으로 반복해 정보 탐색을 돕는다.
- 제품 연출 관찰: 패키지 반복 배열, 원료가 담긴 투명 컵, 신체와 함께 놓인 패키지, 완성 음료를 교대로 사용한다. “무엇이 들어 있는가”와 “어떻게 마시는가”가 서로 다른 이미지 문법을 가진다.
- 증거 표현 관찰: 색군별 원료 목록, 원료 이미지, 효익 불릿을 한 묶음으로 반복한다. 제품이 아닌 원물 설명임을 밝히는 단서도 보인다. 원료의 일반 특성과 제품 효능을 구분하는 문구는 새 스킬에서도 필수다.
- 모션 후보: 분말이 물에 풀리고 균일하게 섞이는 과정은 모션이 유효하다. 원료 목록·영양 수치·섭취량은 정지가 더 정확하다.
- 추출할 규칙: 다성분 제품은 전체 성분을 한 번에 나열하지 말고 의미 있는 분류축 하나로 묶은 뒤 `분류명 → 대표 원료 → 해당 제품에서의 역할 → 근거`를 반복한다.
- 복제하지 않을 요소: 형광 연두 패키지 배열, `DAY SALAD` 세리프 조판, 색군 명칭과 원료 구성.

### 4. 퍼스트 이유식 포트 상세페이지 — 유아 조리가전

- 원본: [유아제품 상세페이지 디자인](https://www.behance.net/gallery/249220371/_)
- 제작자·게시: 스튜디오 초비, 2026-05-12
- 조사 시 화면 수치: 평가 8, 조회 371
- 선정 이유: 부모의 일상적 불편을 먼저 공감한 다음, 기능과 재질 안전성으로 신뢰를 쌓는 가전형 서사를 보여준다.
- 정보 구조 관찰:
  - 따뜻한 실내의 제품 단독 히어로로 종류와 대상 사용자를 즉시 알린다.
  - 엄마와 아기를 흐리게 두고 제품을 선명한 전경에 놓아 “육아 시간을 덜어주는 도구”라는 역할을 설명한다.
  - `CHECKPOINT` 장으로 전환해 자동 저어주기, 온도 유지, 스테인리스 구조 같은 기능을 차례로 풀고, 식품 접촉 재질과 세척 안전으로 마무리한다.
- 타이포 관찰: 크림·브라운 팔레트, 둥근 굵은 제목, 짧은 체크포인트 라벨이 제품의 부드러운 실루엣과 일치한다. 안전 정보에서는 굵은 단어와 `OK` 배지를 제한적으로 사용한다.
- 제품 연출 관찰: 단독 정면 제품, 가족 맥락, 내부 교반 날개의 매크로가 `정서 → 사용 이유 → 구조` 순서로 이어진다.
- 증거 표현 관찰: 부품을 잘라 보여주는 매크로와 라인 콜아웃, 재질명, 소독·상해 위험 관련 체크 항목을 함께 둔다. 단, `BPA free`나 식품등급 같은 문구는 실제 시험서·공급처 근거가 있을 때만 사용해야 한다.
- 모션 후보: 교반 날개의 회전, 온도 유지의 시간 경과, 조리 전후 상태가 해당된다. 안전 재질과 세척 가능 여부는 정지 구조도와 근거 문서가 우선이다.
- 추출할 규칙: 유아 제품은 감성 사진만으로 안전을 암시하지 말고, 불편 감소 기능과 식품 접촉 부품·세척법·시험 근거를 분리해 명시한다.
- 복제하지 않을 요소: 특정 부모·아기 장면, 브라운 `CHECKPOINT` 모양, 제품 카피와 생성된 제품 형태.

## 반복 가능한 정보 구조

모든 제품에 아래 장을 의무적으로 넣는 것이 아니라, 제품 사실과 구매 불안에 맞춰 필요한 장을 선택한다. 순서는 기본 골격이며 근거가 없는 장은 삭제한다.

### 기본 서사 패턴

`감성 → 정보 → 증거`의 세 박자를 한 사이클로 본다.

1. 감성 블록은 사용 결과나 브랜드 태도를 경험하게 한다.
2. 정보 블록은 제목, 짧은 설명, 구조화된 장점으로 의미를 고정한다.
3. 증거 블록은 수치, 비교, 부품·재질 매크로, 시험 조건으로 주장을 검증한다.
4. 다음 사이클에서는 카메라 거리, 정렬, 배경 명도를 바꿔 새 장이 시작됐음을 알린다.

감성 블록 두 개 이상을 연속하면 무드보드가 되고, 정보 블록 세 개 이상을 같은 카드 형태로 반복하면 카탈로그 템플릿처럼 보인다. 증거 블록이 주장과 한 화면 이상 떨어지면 사용자가 둘의 관계를 잃는다.

| 보조 효익·리드 | 1.3–1.6× | 핵심 제목 앞의 짧은 맥락 |
| 섹션 제목 | 2.0–2.8× | 한 블록 한 주장, 2–3줄 이내 |
| 히어로 제목 | 3.0–4.5× | 제품 종류와 핵심 가치, 첫 화면 한정 |
| 증거 수치 | 4.0–7.0× | 값과 단위의 크기를 구분하고 조건을 인접 배치 |

- 한국어 제목은 한 줄 약 10–18자, 본문은 약 25–40자 폭을 우선한다.
- 한 섹션 안에서 굵기, 색, 밑줄, 배경 강조를 동시에 쓰지 않는다. 주 강조 수단은 하나, 보조 수단은 하나로 제한한다.
- 세리프는 프리미엄·감성 선언이나 음식의 전통성처럼 제품 세계와 연결될 때만 사용한다. 기능·사용법·주의사항은 산세리프가 기본이다.
- 영문 눈썹은 장식이 아니라 정보 유형을 알려야 한다. 순서가 아닌데 습관적으로 `01`, `02`를 붙이지 않는다.
- 큰 수치는 값만 키우지 말고 단위, 비교 기준, 시험 조건, 출처를 읽을 수 있는 크기로 같은 컴포넌트에 둔다.

### 제품군별 변형

- 기계·가전: 단단한 산세리프, 짧은 효익 제목, 치수·부품명과 정렬되는 그리드.
- 뷰티·웰니스: 브랜드 디스플레이 서체와 설명 산세리프의 2종 체계, 질감과 성분 장에서 색 변화.
- 식품: 맛의 성격을 드러내는 디스플레이 서체는 히어로에 제한하고, 원산지·조리법은 높은 가독성으로 전환.
- 패션·주얼리: 큰 세리프와 여백을 감성 장에 사용하되 소재·치수·착용 정보는 별도 실용 블록으로 분리.
- 유아·반려동물: 친근한 둥근 제목은 가능하지만 안전·시험 문구까지 귀엽게 처리하지 않는다.

## 제품 연출 문법

### 카메라 거리의 사다리

긴 페이지에서 다음 다섯 거리 중 최소 세 가지를 사용한다.

1. `전체`: 제품 종류와 실루엣을 오인 없이 인지한다.
2. `사람·공간과 함께`: 실제 크기, 잡는 방향, 사용 자세를 확인한다.
3. `작동 부위`: 버튼, 헤드, 페달, 교반 날개처럼 효익을 만드는 부위를 보인다.
4. `재질 매크로`: 제형, 섬유, 칫솔모, 롤러, 음식 표면을 확대한다.
5. `결과`: 완성 음식, 머릿결, 음료, 운동 자세처럼 사용 후 상태를 보인다.

같은 3/4 제품 컷만 크기와 배경을 바꿔 반복하는 것은 카메라 거리 변화가 아니다.

### 합성·촬영 일관성

- 한 장 안에서 제품, 사람, 바닥의 접촉점과 그림자 방향이 같아야 한다.
- 페이지 전체에서 제품의 실루엣, 로고, 부품 수, 색, 결합 구조가 제품 사실 SSOT와 일치해야 한다.
- 사용자의 손이나 발이 등장하면 접촉 위치와 힘의 방향이 기능 설명과 맞아야 한다.
- 비교 화면은 가능하면 같은 시점, 같은 축척, 같은 기준선으로 맞춘다.
- 분위기용 상징 오브제는 실제 SKU 장면으로 오인되지 않게 `campaign visual` 등 역할을 분리한다.
- 한 장면의 대표 재질과 광원을 다음 장면까지 이어 색과 합성의 연결성을 유지한다.

## 섹션 리듬과 컬러

### 리듬 단위

- `몰입형`: 큰 이미지, 짧은 카피, 넓은 여백. 사용 결과와 감정을 전달한다.
- `설명형`: 제목, 본문, 제품·부품 이미지. 기능의 의미를 이해시킨다.
- `증거형`: 수치, 비교, 시험 조건, 표·도식. 판단 근거를 고정한다.
- `행동형`: 사용 단계, 손동작, 관리법. 실행 가능성을 보여준다.

동일 유형을 두 번 이상 연속할 때는 구도를 바꾼다. 예를 들어 첫 설명형은 좌측 카피·우측 제품, 다음 설명형은 전체 매크로·하단 콜아웃으로 바꾼다.

### 장 전환 신호

- 배경 명도의 큰 변화는 정보 장이 바뀔 때만 사용한다.
- 기본색 1개, 중립색 1–2개, 강조색 1개를 페이지 토큰으로 잠근다.
- 원료군이나 옵션처럼 의미가 있을 때만 보조색을 확장한다.
- 강한 색은 효익 전체가 아니라 숫자, 핵심 단어, 포인트 라벨 중 한 곳에 집중한다.
- 넓은 여백은 고급감뿐 아니라 앞 장의 인상을 정리하는 쉼표로 사용한다. 여백 뒤에는 새로운 정보 목적이 와야 한다.

## 증거 표현 문법

### 주장-근거 컴포넌트

각 광고 주장은 다음 순서의 편집 가능한 블록으로 만든다.

1. `claim`: 사용자가 이해할 한 문장.
2. `scope`: 원료 일반 특성인지, 제품 시험 결과인지, 단순 제품 사실인지.
3. `visual`: 비교·치수·매크로·도식·시험 이미지 중 하나.
4. `method`: 대상, 기간, 방법, 대조 조건.
5. `result`: 값, 단위, 오차 또는 판정.
6. `source`: evidence ID와 원문 출처.

`visual`은 근거를 설명할 수 있지만 근거를 대체하지 않는다. 시설 사진은 인증서가 아니며, 측정기 이미지는 시험 전체 조건이 아니다.

### 잘 작동한 표현

- 같은 축척의 나란한 크기 비교: 스포틀러.
- 부품 매크로와 콜아웃: 스포틀러, 이유식 포트.
- 원료·성분의 의미 있는 군집: 마시는 샐러드, 헤어 팩.
- 문제 부위의 확대 인셋: 교체형 칫솔.
- 큰 결과 수치와 시험 대상의 인접 배치: 반려견 유산균.
- 감성 장과 분리된 시험 전용 장: 페이스타월.
- 원물·시설·조리 결과를 별도 장으로 분리: 밀키트.

### 피해야 할 표현

- 출처 없는 큰 퍼센트, 인증 배지, `국내 최초`, `안전`, `무해` 문구.
- 다른 조건의 사진을 같은 조건의 전후처럼 보이게 하는 분할.
- 원료의 일반 특성을 완제품 효과처럼 이어 붙이는 도식.
- 실제 제품과 다른 생성형 목업을 구조 증거로 사용하는 것.
- 측정 장비 숫자만 확대하고 시험 조건·단위를 숨기는 것.
- 한 화면에 장점 6개 이상과 작은 아이콘을 같은 무게로 나열하는 것.

## 모션 후보 결정 규칙

Behance 표본 중 스포틀러, 헤어 팩, 마시는 샐러드, 교체형 칫솔, 밀키트는 GIF를 사용했고 나머지는 정지만으로도 서사를 구성했다. GIF 수가 많다고 설득력이 자동으로 높아지지는 않는다.

### GIF를 쓰는 조건

다음 질문 중 하나가 `예`이고, 실제 근거가 있는 시작·종료 상태를 확보했을 때만 후보로 잡는다.

- 움직임의 방향이나 순서를 봐야 작동을 이해할 수 있는가?
- 시간 경과에 따른 상태 변화가 주장 자체인가?
- 사용자의 손·발과 제품의 접촉을 정지 이미지 한 장으로 오해 없이 설명하기 어려운가?
- 전후 비교에서 중간 과정이 신뢰를 높이는가?

| 제품군 | 유효한 한 GIF 후보 | 정지가 더 나은 내용 |
|---|---|---|
| 스텝밀 | 페달 1회 왕복, 핸들 위치 한 가지 전환 | 높이 비교, 부품 재질, 중량 |
| 헤어 팩 | 제형 늘어남 한 번, 동일 조건의 전후 와이프 | 성분 구성, 시험 조건·수치 |
| 기능성 음료 | 정량 분말이 물에 풀리는 한 과정 | 원료 목록, 섭취량 |
| 이유식 포트 | 교반 날개 한 사이클, 온도 변화 | 재질 안전, 구성품 |
| 교체형 칫솔 | 헤드 분리·결합 한 번 | 미세플라스틱 설명, 규격 |
| 반려견 영양제 | 정량 급여 또는 섞는 방법 | 균주, 기호성 시험 수치 |
| 주얼리 | 기본 증거 모션 없음 | 소재, 치수, 착용 크기 |
| 페이스타월 | 동일 조건의 흡수 또는 양면 전환 | 시험 결과, 무형광 주장 |
| 밀키트 | 포장 상태에서 완성까지 한 조리 단계 | 원산지, 시설, 구성 |

### GIF 제작·배치 규칙

- 한 GIF는 한 동작 또는 한 효과만 설명한다.
- 주장 제목과 GIF는 같은 섹션에 두고, 짧은 캡션으로 무엇을 볼지 알려준다.
- 첫 프레임만 봐도 제품과 상태를 이해할 수 있어야 한다.
- 루프 경계에서 제품 위치·조명이 튀지 않아야 한다.
- 장식용 카메라 줌, 반복 불꽃, 떠다니는 입자는 기본 후보에서 제외한다.
- `prefers-reduced-motion`에서는 동일 주장에 대한 대표 정지 이미지와 설명을 제공한다.
- GIF의 제품은 승인된 제품 컷아웃 SSOT 또는 출처가 명확한 제품 뷰 시트를 참조해야 한다.

## 수정 가능한 HTML로 옮길 디자인 규칙

### 800px 판매 캔버스 기준 토큰

아래 값은 특정 작품의 픽셀을 복사한 것이 아니라 관찰한 상대 관계를 800px 상세페이지에 적용하기 위한 시작 범위다.

- 콘텐츠 최대 폭: `800px`
- 기본 좌우 안전 여백: `40–64px`
- 본문 최대 폭: 전체 캔버스의 `62–78%`
- 섹션 상하 여백: 보통 블록 `72–120px`, 몰입형 장 전환 `120–180px`
- 카드 간격: 본문 행간의 `1.5–2.5배`
- 이미지 모서리: 제품 세계가 요구할 때만 하나의 반경 토큰 사용
- 그림자: 제품 접지용과 카드 계층용을 분리하고 한 화면에 한 종류만 주로 사용

### DOM 컴포넌트

```text
detail-page
├─ product-hero
├─ problem-scene?
├─ value-thesis
├─ feature-section × 3–5
│  ├─ feature-copy
│  ├─ product-media
│  └─ evidence-ref?
├─ proof-section × N
│  ├─ claim
│  ├─ method
│  ├─ result
│  └─ source
├─ usage-steps
├─ options-and-specs
├─ care-and-cautions
└─ final-summary
```

- 제목, 본문, 수치, 단위, 각주를 이미지에 굽지 않는다.
- 각 섹션은 `data-section-kind="emotion|information|proof|action"`처럼 목적을 표시한다.
- 제품 미디어에는 `data-product-view`, 근거에는 `data-evidence-id`, 주장에는 `data-claim-id`를 연결한다.
- 색, 타입 스케일, 여백, 곡률, 테두리, 그림자를 CSS 변수로 둔다.
- 섹션을 이동·복제·삭제해도 주장의 evidence ID가 깨지지 않게 콘텐츠 데이터를 분리한다.
- 감성 장면도 대체 텍스트에 제품 사실과 사용 맥락을 구분해서 기록한다.

## 복제 없이 문법을 추출하는 절차

### 1. 작품을 네 층으로 분해한다

- `정보 목적`: 이 섹션이 답하는 구매 질문.
- `구성 원리`: 정렬, 비율, 이미지 거리, 여백과 반복 방식.
- `표현 변수`: 색, 서체 성격, 재질, 광원, 카메라.
- `고유 표현`: 카피, 모델, 배경 세트, 구체 구도, 그래픽 모티프.

재사용하는 것은 앞의 두 층이다. 표현 변수는 새 제품의 사실과 브랜드에 맞춰 다시 결정하고, 고유 표현은 가져오지 않는다.

### 2. 한 작품에서 전체 방향을 가져오지 않는다

한 상세페이지의 디자인 방향을 잠글 때 최소한 다음처럼 역할이 다른 참조를 사용한다.

- 정보 구조 참조 1개
- 증거 표현 참조 1개
- 제품 재질·조명 참조 1개
- 필요할 때만 감성·편집 리듬 참조 1개

예를 들어 스텝밀의 치수 비교 원리, 페이스타월의 시험 전용 장, 주얼리의 넓은 감성 여백을 조합할 수는 있지만 어느 작품의 팔레트·서체·구도 묶음을 통째로 가져오지 않는다.

### 3. 세 작품 이상에서 반복된 것만 공통 문법으로 승격한다

- 한 작품에서만 보인 장치는 `제품군별 변형` 또는 `실험 후보`로 둔다.
- 세 작품 이상에서 다른 미감으로 반복된 구조는 공통 문법으로 본다.
- 공통 문법도 현재 제품 사실과 구매 불안에 필요하지 않으면 사용하지 않는다.

### 4. 유사성 검사를 한다

최종 디자인 디렉션에는 다음을 기록한다.

- 참조 작품마다 가져온 추상 원칙 한 문장.
- 의도적으로 바꾼 팔레트, 서체, 구도, 모델·공간, 그래픽 모티프.
- 제품 사실 때문에 추가·삭제한 섹션.
- 어느 한 작품과도 연속 2개 이상의 섹션이 같은 구도·색·카피 리듬을 공유하지 않는지 여부.

## 디자인 디렉션 승인 체크리스트

### 첫 화면

- 제품 종류, 핵심 가치, 실제 제품 또는 결과를 첫 화면에서 이해할 수 있는가?
- 히어로가 캠페인 상징이라면 실제 SKU를 같은 화면 또는 바로 다음 화면에서 확인할 수 있는가?
- 첫 화면의 제목 위계가 세 단계 이내인가?

### 긴 페이지 리듬

- 감성형·설명형·증거형·행동형이 정보 목적에 따라 교차하는가?
- 같은 카드 구도가 세 번 연속되지 않는가?
- 배경색 변화가 장 전환과 연결되는가?
- 제품의 카메라 거리가 전체·사용·작동·매크로·결과 중 세 단계 이상을 포함하는가?

### 증거

- 각 성능·효과·안전 주장이 evidence ID와 연결되는가?
- 수치 옆에 단위, 대상, 방법, 비교 기준, 출처가 있는가?
- 원료 일반 특성과 완제품 시험 결과를 구분하는가?
- 생성 이미지나 시설 사진을 제품 사실·시험 증거로 오인하게 하지 않는가?

### 제품 동일성

- 모든 제품 장면의 실루엣, 로고, 색, 부품, 결합 구조가 제품 사실 SSOT와 일치하는가?
- 사람과 함께 있을 때 크기와 잡는 방향이 자연스러운가?
- 비교 화면이 같은 시점·축척·기준선을 사용하는가?

### 편집 가능한 HTML

- 모든 핵심 카피와 수치가 HTML 텍스트인가?
- 이미지·GIF가 파일 교체 가능한 자산인가?
- 섹션의 목적, claim ID, evidence ID가 DOM 또는 콘텐츠 데이터에 남는가?
- 색·폰트·간격을 토큰에서 일괄 조정할 수 있는가?
- 모션 감소 환경에 정지 대체물이 있는가?

## 한계와 후속 적용

- 이 조사는 Behance 원본 작품의 시각 구성 조사다. 실제 판매 데이터, 접근성, 페이지 속도, 판매 채널 HTML 제약을 검증하지 않았다.
- 작품에 이미지로 포함된 광고 수치와 인증의 사실 여부를 별도로 검증하지 않았다. 새 스킬에서는 공급처 원문·시험서·실측 결과에 연결되지 않은 주장을 사용하면 안 된다.
- Behance에서는 통이미지와 GIF가 자연스럽지만, 새 스킬의 최종 산출물은 수정 가능한 HTML이다. 작품의 시각 밀도를 재현하되 텍스트·데이터·근거 관계는 DOM과 JSON으로 분리해야 한다.
- 판매 채널별 허용 폭, GIF 예산, 외부 폰트·스크립트 제약이 정해지면 위 토큰과 모션 후보를 해당 채널 계약에 맞게 축소해야 한다.

최종적으로 고정할 문법은 하나의 스타일이 아니라 다음 운영 규칙이다.

> 제품 세계에서 미감을 만들고, 구매 질문으로 섹션을 나누며, 감성·정보·증거를 교차하고, 모든 주장 가까이에 검증 가능한 근거를 두며, 시간 변화가 주장인 경우에만 한 GIF로 한 동작을 보여준다.
