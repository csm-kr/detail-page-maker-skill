# ADR-0001 — 게이트 순서를 문서 대신 스크립트가 소유한다

**상태** 채택 · 2026-08-05

## 맥락

현재 진입점은 문서다.

```text
SKILL.md 시작:
  1. 항상 references/workflow.md 를 읽는다
  2. 호스트가 Codex 가 아니면 claude-code.md 를 함께 읽는다
  3. 필요한 시점에만 … 를 읽는다
```

문서 진입점의 성질이 2회차에 그대로 나타났다.

| 성질 | 실제로 일어난 일 |
| --- | --- |
| 읽는 순서를 에이전트가 정한다 | `workflow.md`는 읽고 `templates.md`(1,208줄)는 안 읽었다 |
| 읽었는지 확인할 수 없다 | 기준작 캡처(780×16,215)를 안 열고 G1을 "확정"했다 |
| 호스트마다 읽는 문서가 다르다 | Codex 분기 조건문이 순서 차이를 허용한다 |
| **건너뛰어도 다음 단계가 돌아간다** | 무드 주입을 건너뛰고 스틸 30장이 그대로 생성됐다 |
| 완료 판정이 에이전트의 말이다 | Studio·Wing·압축이 빠진 상태에서 "전부 완료" |

**45개 회귀 테스트가 전부 GREEN인 채 6개 결함이 남았다.** 테스트가 있었는데 실행을
막지 못했다. 검사와 실행이 분리돼 있었기 때문이다.

## 결정

순서·상태·판정을 **스크립트가 소유한다.**

- `orchestrator/scripts/lib/gates.mjs` 가 게이트 정의와 순서의 **유일한 출처**다.
- 상태는 `<프로젝트>/work/gates.json`. 사람이 열어 볼 수 있는 평문 JSON.
- 단계 스킬의 `run.mjs` 첫 줄이 `requireEnv()` + `requireGates(...)`로 선행을 검사하고
  미통과면 `exit 1`이다.
- 통과 기록은 `check.mjs`를 **다시 돌린 뒤에만** 쓰인다.
- 문서에는 순서를 적지 않는다. 적으면 갈린다 — 중복 기재 금지 테스트로 막는다.
- 우회 플래그(`--force`)를 처음부터 만들지 않는다.

## 결과

**좋아지는 것.** 순서를 지켰는지가 파일 상태로 판정된다. 호스트가 달라도 결과가 같다.
어느 단계를 안 했는지 그 단계 자신이 안다.

**나빠지는 것.** 게이트를 고치지 않으면 진행할 수 없어 초기에 마찰이 크다. 그것이 의도다.

**막지 못하는 것.** 에이전트가 스킬을 건너뛰고 파일을 직접 만드는 것은 막을 수 없다.
막는 대상을 **실행이 아니라 판정**으로 옮긴 것이 이 결정의 요지다 — 손으로 만든
산출물도 같은 검사를 받는다.

## 기각한 대안

| 대안 | 기각 이유 |
| --- | --- |
| 문서를 더 강한 어조로 쓴다 | 2회차의 문서는 이미 "반드시 읽는다"라고 쓰여 있었다. 어조는 실행을 바꾸지 못했다 |
| 체크리스트를 SKILL.md에 넣는다 | 체크했다고 말하는 것과 체크한 것이 구분되지 않는다 |
| 사람이 단계마다 승인한다 | 승인 대기가 60분 목표를 깨고, 승인자도 근거 없이 승인하게 된다 |
| CI로 검사한다 | 워크스페이스가 git 저장소가 아니고 CI가 없다. 실행 시점에 막아야 한다 |
