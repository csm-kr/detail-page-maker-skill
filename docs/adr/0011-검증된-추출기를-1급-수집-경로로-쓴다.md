# ADR-0011 검증된 추출기를 1급 수집 경로로 쓴다

- 상태: 결정
- 날짜: 2026-08-05
- 관련: [ADR-0004](0004-인증은-호스트에서만.md), R8(다른 기계에서도 된다)

## 맥락

3회차 실테스트에서 공급처 수집은 되고 기준작 수집은 막혔다. 원인을 찾는 동안
`coupang-extractor` 와 `dmk-extractor` 가 이미 번들에 들어 있는 것을 발견했다.
2회차를 통과한 것들이다. 내가 그것을 보지 않고 `lib/capture.mjs` 를 새로 짜고 있었다.

두 코드를 비교하면 내장 캡처에 없는 것이 이렇다.

| 추출기에 있는 것 | 내장 캡처 |
| --- | --- |
| `ACCESS_BLOCKED` · `LOGIN_REQUIRED` 판정 후 재시도 0회 | 없음 |
| 썸네일·상세·후기의 상품 ID 대조 (`PRODUCT_MISMATCH`) | 없음 |
| 후기 작성자·연락처 마스킹 | 없음 |
| 자산별 원본 바이트 1회 다운로드 + SHA-256 | 스크린샷 한 장 |
| `manifest.json` + `validate_capture.py` 검증 | 없음 |
| GIF 프레임 분리 (도매꾹 상세설명 내부만) | 없음 |

즉 내장 캡처는 열등한 사본이었다.

## 결정

호스트로 수집 경로를 고른다. `lib/extract.mjs` 가 이 선택을 갖는다.

| 호스트 | 경로 |
| --- | --- |
| `domeggook.com` | `dmk-extractor` |
| `coupang.com` | `coupang-extractor` |
| 그 외 | 내장 CDP 캡처 |

호스트는 **정확히** 일치해야 한다. 부분 일치로 고르면 `coupang.com.evil.kr` 이
쿠팡 선택자를 받는다. 테스트로 고정했다.

추출기는 `browser-harness` 명령을 요구한다. 없으면 그 사실을 말하고 내장 캡처로
내려간다 — 조용히 실패하지 않는다.

등록하는 것은 번들의 `manifest.json` 하나다. 자산별 해시가 그 안에 있고, 추출기가
검증을 통과한 뒤에만 정상 위치로 승격한다. `manifest.json` 이 없으면
`BUNDLE_INCOMPLETE` 로 거부한다 — `PARTIAL` 결과를 근거로 쓰지 않는다.

### 요청을 최소로 둔다

추출기 기본값은 후기 200개를 최대 36페이지 넘겨 가며 긁는다. 그러면 사이트가 막는다.
이 단계에서 우리가 원하는 것은 구성과 자산이므로 인자를 고정한다.

- 기준작(`coupang-extractor`): `--sections thumbnails,detail` — 후기 단계를 끈다
- 공급처(`dmk-extractor`): `--review-limit 20` — 표본만 본다

## 내장 캡처를 남기는 이유

새 참고 사이트가 생길 때마다 추출기를 쓸 수는 없다. 다만 실테스트가 두 가지를
가르쳤고 둘 다 코드와 테스트에 박았다.

1. **페이지 소켓에 직접 붙지 않는다.** `PUT /json/new` 로 만든 탭의 소켓에 붙으면,
   쿠팡이 띄우는 `shared_worker`(blob:) 들이 죽을 때 연결이 함께 끊긴다. 진단에서
   `Inspector.targetCrashed` 두 번과 그 워커들의 `Target.detachedFromTarget` 을 봤고
   페이지 타깃 자체는 멀쩡했다. 브라우저 소켓에 붙어
   `Target.attachToTarget {flatten:true}` 로 부착하면 남의 타깃이 죽어도 견딘다.
   `browser-harness` 가 같은 방법을 쓴다.

2. **성공한 캡처가 쓰레기일 수 있다.** 없는 쿠팡 상품이 HTTP 200 에 스크린샷까지
   성공으로 돌아왔다. 본문은 "상품을 찾을 수 없습니다" 였고 높이는 1028px 였다.
   그대로 기준작으로 등록될 뻔했다. 상세페이지는 길다 — 높이 2000px 미만은
   `CAPTURE_TOO_SHORT` 로 거부한다. 짧은 페이지가 맞으면 `--min-height` 로 낮춘다.

## 대가

- `browser-harness` 는 호스트 설치다. R8 을 온전히 만족하지 못한다. 없는 기계에서는
  내장 캡처로 돌고, 그때는 위 두 보호만 남는다. 이 차이를 감추지 않고 알린다.
- 추출기는 파이썬을 쓴다. 스킬 트리에 `.pyc` 가 생기지 않는지 순수성 검사가 계속 본다.
