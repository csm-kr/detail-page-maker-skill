# ADR-0007 — 목표는 95분이고, 근거가 쌓인 게이트만 완화한다

**상태** 채택 · 2026-08-05

## 맥락

2회차 실측 벽시계는 **100분**이다(10:20 프로젝트 생성 → 12:00 `detail-page.html`).
그런데 그 100분에는 기준작 판독·무드 주입·컷 선별·레이아웃 기획·컴포지션 재작성·
Studio·Wing·압축이 **빠져 있다.** 빠진 것을 다 넣으면 145분 정도로 추정된다.

사용자 판단 — "95분이지만 하면서 하네스가 필요없는 부분 잘하는 부분은 점점 완화할꺼야."

즉 목표는 낮게 두고, 검사(하네스)를 **줄여서** 도달한다. 그런데 검사를 줄이는 것은
2회차 실패의 원인이기도 하다. 그러므로 줄이는 조건이 필요하다.

## 결정

### 목표는 95분

게이트별 예산의 합은 병렬을 반영해 **86분**이고 9분 여유가 있다.

| 게이트 | 예산 | 근거 |
| ---: | ---: | --- |
| G0 | 1분 | 스크립트 |
| G1 ∥ G2 | 10분 | G1 8 / G2 10. 병렬이므로 max |
| G3 | 12분 | 2회차 실측 29분 — 화면 문자열 전량을 플랜에 넣는 대신 G9가 짧아진다 |
| G4 | 23분 | 2회차 실측. 4장씩 4배치 + 재요청 3장. **병렬 불가** |
| G5 | 2분 | 주입은 기계적 |
| G6 | 12분 | god-tibo 32 workers + 선별 |
| G7 | 8분 | 신설 |
| G8 ∥ G9 | 10분 | G8 10 / G9 6. 병렬 ([ADR-0009](0009-G8과-G9를-병렬로-돌린다.md)) |
| G10 | 3분 | 스크립트 |
| G11 | 5분 | Wing + 서버 복구 |
| **합계** | **86분** | 목표 95분, 여유 9분 |

`INIT`은 워크스페이스 1회이므로 회차 예산에 넣지 않는다.

### 도입 직후 초과는 정상

| 회차 | 목표 | 상태 |
| --- | ---: | --- |
| 1회차 (엔진 도입 직후) | 145분 | 게이트 전량 활성. 초과를 기록만 한다 |
| 2회차 | 120분 | 근거가 쌓인 게이트를 완화 |
| 3회차 이후 | **95분** | 정상 목표 |

**트래커는 초과를 표시하지만 막지 않는다.** 막으면 "시간 때문에 검사를 건너뛴다"가
정당화된다 — 그것이 2회차에 일어난 일이다.

### 완화 규칙

완화는 `orchestrator relax <gate> --evidence …`로만 한다.

| 조건 | 내용 |
| --- | --- |
| **근거** | `gates.history.json`에 그 게이트가 **3회 연속 통과 + 그 게이트가 잡는 결함 0건** |
| **대상** | 상류가 이미 보장하는 중복 검사, 또는 `actor`를 `mixed` → `script`로 내리는 것 |
| **금지** | 그 게이트가 **유일하게** 잡는 검사는 완화 대상이 아니다 |
| **기록** | `env.lock.json.relaxations`에 게이트·항목·근거·시각 |
| **원복** | 완화 후 그 게이트가 잡을 결함이 **1건이라도** 나오면 즉시 원복하고 원복 사유를 기록 |

완화 후보는 판단이 아닌 게이트다 — G1(사실 추출이 안정되면), G5(주입은 기계적),
G10(검사는 이미 스크립트). **G2·G4·G7은 완화 대상이 아니다.** 판단이 그 게이트의 본체다.

## 결과

**좋아지는 것.** 목표가 낮아도 검사를 줄이는 데 근거가 필요하므로 "빠르게 하려고
건너뛴다"가 구조적으로 막힌다. 완화가 기록되므로 어떤 검사가 왜 사라졌는지 추적된다.

**나빠지는 것.** 초기 3회차 동안은 목표를 못 맞춘다. 그것을 실패로 보지 않는다 —
2회차 100분은 6개 단계를 빼먹은 100분이었다.

## 기각한 대안

| 대안 | 기각 이유 |
| --- | --- |
| 95분 유지 + 범위 축소 (목업 14→8섹션, 스틸 30→24장) | 목표를 지키려고 2회차가 **잘한 부분**을 줄이게 된다 |
| 120분으로 목표 재설정 | 사용자가 95분을 선택했다. 낮은 목표가 범위 이탈 감지에 쓸모 있다 |
| 총 목표 없이 게이트별 예산만 | 총합이 회차마다 달라져 "오래 걸렸다"를 판정할 기준이 없다 |
| 시간 초과 시 게이트 자동 완화 | 검사를 줄이는 이유가 "느려서"가 된다. 근거가 아니라 조급함이다 |
