# 경쟁상품 후기 개인정보 검증 보강

상태: ready-for-agent
발견일: 2026-07-25

## 문제

`coupang-extractor`가 `author_identifiers_removed: true`를 기록했지만 일부 `review_text`에 `장*선`, `김*라`, `ARY*******`, `쿠팡실구매자` 같은 작성자·판매자 헤더 문자열이 남았다. 현재 validator는 이 상태를 `VALID`로 통과시킨다.

## 영향

- 원문 경쟁상품 번들을 저장소에 커밋할 수 없다.
- 의미 없는 헤더 문자열이 저평점 후기처럼 집계된다.
- 개인정보 제거 계약과 실제 산출물이 불일치한다.

## 임시 조치

- 재생성 가능한 경쟁상품 캡처는 `.artifacts/`에서 관리하고 Git에서 제외했다.
- 현재 상품에는 익명화된 주제 집계, 상품 URL·ID와 표본 상태만 저장했다.
- 작성자 문자열이 섞인 원문은 카피나 사용자 발화로 사용하지 않는다.

## 완료 조건

- 후기 카드 파서가 작성자·판매자 헤더를 본문에서 분리한다.
- `review_text === option_name` 또는 헤더만 남은 카드를 내용 없는 후기로 분류한다.
- validator가 마스킹된 작성자 패턴, 판매자 헤더, 계정형 문자열을 검사한다.
- `author_identifiers_removed: true`는 검사 통과 후에만 기록한다.
- 개인정보 fixture와 회귀 테스트를 추가한다.
