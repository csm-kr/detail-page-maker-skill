Blocked by:

## Question

새 스킬이 도달할 목적지와 공급처·사용자 사진·생성 이미지·모션·HTML 사이의 책임을 어떻게 정의할 것인가?

## Answer

- 최초 입력은 공급처 상품 URL 1개다.
- 공급처 스냅샷과 사용자가 촬영한 무가공 다각도 사진이 제품 사실 SSOT다.
- 사용자 촬영 원본에서 배경을 제거한 승인 PNG 묶음이 제품 컷아웃 SSOT다.
- ImageGen은 컷아웃과 다각도 제품 뷰, 디자인 장면을 만들지만 제품 사실을 생성하지 않는다.
- HyperFrames는 승인된 제품 자산으로 제품 작동·효과 모션을 만들고, 결과 GIF를 관련 HTML 섹션에 삽입한다.
- 최종 결과는 카피·이미지·GIF·레이아웃·디자인 토큰을 각각 수정할 수 있는 HTML이다.
- Behance 우수 상세페이지는 복제 대상이 아니라 상용 품질 문법을 추출할 표본 풀이다.

상세 내용은 [`plan.md`](../../../plan.md)와 [`CONTEXT.md`](../../../CONTEXT.md)를 따른다.
