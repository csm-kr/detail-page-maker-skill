# 아쿠아슈즈 사진 중심 상세페이지와 독립 Studio

상태: completed
결정일: 2026-07-25

## 결정

- 사용 맥락을 수영장·워터파크·해변·계곡의 별도 ImageGen 장면으로 확장한다.
- 생성 이미지 안에는 한글 광고 문구를 넣지 않고 실제 제품, HTML 카피, 장식 레이어를 분리한다.
- 구매자용 `index.html`과 편집용 `studio.html`을 분리한다.
- Studio는 문구·타이포·정렬·색상·이미지·초점·오버레이·토큰을 수정하고 JSON과 이미지 내장 단일 HTML을 내보낸다.
- 발길이 안내는 첫 소구가 아니라 구매 후반의 사이즈 선택 정보로 둔다.

- 단일 HTML 31,287,338바이트, 이미지 16개 내장, 재오픈 통과
- HyperFrames 발길이 바·점·활성 카드 단일 좌표 교정 완료
- Behance 상용 QA 97/100, 하드 실패 0개

## 회귀 조건

- 편집 도구가 모바일 구매 콘텐츠를 가리키면 실패다.
- 첫 소구가 치수·주의 같은 보조 정보로 되돌아가면 재검토한다.
- Studio 내보내기를 실제 재오픈하지 않으면 완료로 판정하지 않는다.
