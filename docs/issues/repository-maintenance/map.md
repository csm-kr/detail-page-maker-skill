# Repository maintenance

## Destination

상품별 자료를 `projects/` 안에서 자기완결시키고, 장기 연구·이슈·재사용 규약과
설치 스킬의 경계를 문서와 테스트로 고정한다.

## Decisions so far

- [저장소 구조 통합과 학습 승격 루프](issues/01-consolidate-repository-structure.md):
  프로젝트 자기완결 경계와 `LEARNINGS → issue → 재검증 → skill` 승격 흐름을
  정본으로 채택했다.
