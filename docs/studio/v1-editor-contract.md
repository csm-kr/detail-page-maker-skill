# Studio v1 상세 편집 계약

상태: 활성. 상세 구현 규약은
[`studio-workflow.md`](../../skills/detail-page-maker-skill/references/studio-workflow.md)가
소유하며 이 문서는 저장소 수준의 제품 계약을 요약한다.

## 화면

작업면은 `상세 편집 → 에셋 승인 → 최종 출력` 세 개다. UI는 차분한 어두운
중립색, 밝은 작업 캔버스, 한 가지 블루 강조색을 사용한다. 장식보다 선택 상태,
조작 결과, 승인 잠금과 오류가 먼저 보여야 한다.

## 선택과 편집

- `V 요소 배치`와 `T 텍스트 변환`은 상호 배타적이다. 요소 배치에서는 이동·
  크기·삭제만, 텍스트 변환에서는 내용·글꼴·색·정렬만 활성화한다.
- 상세페이지의 의미 있는 텍스트·이미지·GIF·figure·목록·표 셀을 선택할 수 있다.
- 선택 요소의 X/Y 위치를 숫자로 입력하거나 1px 버튼, `Shift` 10px, 화살표 키로
  이동한다.
- 비텍스트 요소는 드래그 이동과 휠 25~400% 확대·축소를 지원한다.
- 텍스트는 직접 편집하고 왼쪽·가운데·오른쪽·양쪽 정렬과 텍스트 비우기를 지원한다.
- 선택 요소 삭제는 실행 취소할 수 있고 내보낸 HTML에서는 삭제 요소를 제거한다.
- 이동 중에는 세로 중심선, 좌우 8% 안전선, 현재 섹션 가로 중심선을 표시하고
  8px 이내에서 스냅한다. 보조선은 출력에 포함하지 않는다.
- 글자색과 `Noto Sans KR`, `Gmarket Sans`, `S-Core Dream`, `Wanted Sans`,
  `Black Han Sans`, `Jalnan`을 선택할 수 있다.
- 실행 취소 버튼과 `Ctrl/Cmd+Z`를 제공하며 최소 최근 50개 체크포인트를 유지한다.
- 위치·배율·글꼴·색은 안정적인 요소 ID와 함께 로컬 상태에 저장한다.

단축키는 `V`, `T`, 방향키, `Shift+방향키`, `Delete/Backspace`, `Esc`,
`Ctrl/Cmd+Z`, `Ctrl/Cmd+Shift+L/E/R/J`를 제공한다. 입력 중에는 문자·삭제
도구 단축키가 본문 편집을 방해하지 않아야 한다.

## 승인과 출력

- 신규 이미지·GIF는 pending에서 시작한다.
- 사용자 승인 전 approved로 이동하지 않는다.
- pending 필수 에셋이 있으면 최종 출력을 잠근다.
- 사용자가 여는 결과는 `deliverables/<revision>/index.html` 하나다.
- 프로젝트 `index.html`에서 Studio로 바로 이동할 수 있어야 한다.

## 회귀 검사

1. 모든 편집 컨트롤 존재
2. 텍스트와 이미지 각각 선택 가능
3. 1px 이동 결과 반영
4. 여섯 글꼴과 색 반영
5. 텍스트 비우기 뒤 undo 복원
6. 저장 상태 schema migration
7. 두 도구의 상호 배타성, 네 정렬, 삭제·undo
8. 보조선 스냅과 출력 시 Studio 전용 보조선·삭제 요소 제거
9. 내보낸 HTML에서 Studio 전용 속성 제거, 사용자 스타일 유지
