## 사람 검토 게이트

- [ ] 실제 상품 상세페이지 사례인가
- [ ] 제품 동일성과 주장 근거를 해치지 않는가
- [ ] 카피·이미지·치수·모션을 수정 가능한 HTML로 분리할 수 있는가
- [ ] 서로 다른 우수 사례 3개 이상에서 같은 규칙이 재현되는가
- [ ] 현재 상품 A/B에서 점수를 높이고 하드 실패가 없는가

통과한 규칙만 `docs/references/design-study.md`에 `candidate`로 기록한다.
