- 줄바꿈: 제품 부품명 한 줄, 편익 한 줄, 짧은 설명의 3단 구조다.
- 어투: 감성보다 동작과 제어를 말한다.
- 소구 제시: 부품 매크로 뒤에 즉시 손 사용 장면을 배치해 구조와 결과를 연결한다.
- 문제 후킹: 작업 정밀도와 제어 불안을 날·그립·손 사용으로 답한다.
- GIF: 12개가 날 움직임, 손잡이 제어, 사용 과정 등 정적 이미지로 이해하기 어려운 동작을 담당한다.
- 노바페이스 적용: `ZOOM SPORTS` 표기와 블루쿠션을 매크로에서 확인한 뒤, 쿠션 GIF에서 같은 위치가 유지되는지 검수한다.

## 공통 상용 규칙

1. 팔레트는 주색 1개, 보조색 1개, 중립색으로 제한한다.
2. 첫 화면은 제품명보다 “무엇이 달라지는가” 또는 “어떤 상품인가” 중 하나를 2줄 이내로 답한다.
3. 한글 제목은 의미 단위 8~16자 덩어리로 끊고 단어·조사·어미 중간을 자르지 않는다.
4. 디스플레이 서체는 감각 제목 하나에만 쓰고 수치·본문·표는 산세리프를 유지한다.
5. 문제 후킹은 생활 상황 또는 선택 불안을 제시하고 바로 다음 시각 근거에서 답한다.
6. GIF는 존재 자체가 아니라 상태 변화, 사용 과정, 대응 관계, 데이터 변화 중 하나를 맡는다.
7. 움직이는 선·광선만 있고 제품이나 정보 상태가 변하지 않으면 기능 GIF로 인정하지 않는다.
8. 인접 섹션은 주장·제품 거리·배경·레이아웃 중 둘 이상을 바꾼다.
9. 제품 매크로 뒤에는 사용 장면 또는 구조 결과를 배치한다.
10. 내부 정보가 길어도 한 화면에는 한 주장만 남긴다.

## 노바페이스에 적용한 구조 수정

- 23개 섹션을 18개로 줄였다.
- `정지 설명 → 같은 내용의 정사각 GIF`가 반복되던 소재·통풍·쿠션·유연성 구간을 하나의 기능 섹션으로 통합했다.
- GIF 8개는 제거하지 않고 서로 다른 구매 질문을 맡겼다.
- 통풍 GIF의 바람 시작점을 앞꿈치·중족부 에어홀로 제한하고 구멍이 없는 블루쿠션에서는 모든 바람·빛줄기를 제거했다.
- 소재 GIF는 상면과 하면의 폭을 번갈아 넓혀 비교하고, 쿠션 GIF는 `닿기 전 → 블루쿠션이 닿을 때` 상태를 표시한다.
- 페이지의 핵심 명칭을 `에어셀`, `에어홀`, `블루쿠션`, `ZOOM SPORTS`로 고정했다.
