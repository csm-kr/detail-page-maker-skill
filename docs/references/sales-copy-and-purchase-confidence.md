# 판매형 카피와 구매 불안 해소

상세페이지를 `판매 정보 70 : 브랜드 감성 30`으로 구성하기 위한 저장소 정본이다.
실행 규칙과 예시는 설치형 스킬의
[`sales-copy-and-purchase-confidence.md`](../../skills/detail-page-maker-skill/references/sales-copy-and-purchase-confidence.md)가
소유한다.

## 저장소 적용

1. 제품 자체와 기존 대안의 차이를 첫 화면에서 직접 보여 준다.
2. 일반 설득 장은 `특징 → 고객 효익 → 사용 장면 → 즉시 증거`로 쓴다.
3. 명확한 생활 언어를 먼저 쓰고 비유는 제품 차이를 흐리지 않을 때만 더한다.
4. 손등 문제는 `손등이 노출된다`, 핏 문제는 `타이트하게 붙는다`처럼 보이는
   결과로 쓴다.
5. 비교 장면은 얼굴·전신보다 팔과 제품을 중심으로 같은 축척에서 보여 준다.
6. 실제 라벨은 구매 이유가 아니면 제목·콜아웃·확대·표 행으로 강조하지 않는다.
7. 같은 장점은 최대 두 번만 말하고, 세 번 이상이면 약 30%를 줄인다.
8. 소재 혼용률·신축 범위·모델 치수·비침·흘러내림·세탁·제조 정보는 확인된
   값만 공개한다.
9. 제조사 제공 쿨 소재는 정성 범위로 사용하되 냉감 시험이 없으면 온도 하강,
   그래프, 막대, 꺾은선, 가짜 열화상을 만들지 않는다.
10. 최종 정보 장은 상품명·색상·수량·치수·소재·세탁·제조 정보 중 확인된
    항목만 한눈에 정리한다.
