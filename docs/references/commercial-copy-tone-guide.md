# Commercial Copy Tone Guide

상세페이지의 기능 사실을 구매자가 자기 하루로 상상할 수 있는 상용 광고 언어로
바꾸는 실행 가이드다. 근거 표시는 프로젝트 기록에 남기되, 고객 화면은 제품이
주는 장면·감정·변화부터 말한다.

## 1. 핵심 원칙

### 고객은 제작 방식을 사지 않는다

고객 화면에서 `무엇으로 만들었는지`, `어떤 원본을 참조했는지`, `누가 확인한
주장인지`, `어떤 생성 도구를 썼는지`를 설명하지 않는다. 고객이 알고 싶은 것은
자기 상황과 제품이 주는 변화다.

```text
내부 기록: 제조사 확인 쿨 소재
고객 화면: 한여름의 팔 위로, 산뜻함이 머무는 소재

내부 기록: 실물 구조를 기준으로 상용 촬영 톤으로 재구성
고객 화면: 문장 삭제. 제품 이미지와 자연스러운 캡션만 남긴다.
```

### 기능명보다 장면을 먼저 쓴다

```text
상황 → 감정 → 변화 → 짧은 사실 캡션
```

- 상황: 고객이 제품을 찾는 실제 순간
- 감정: 불편, 망설임, 기대
- 변화: 제품을 사용한 뒤 달라지는 하루의 인상
- 사실 캡션: 이미지·GIF가 무엇을 보여 주는지 한 줄로 고정

### 비유는 사실을 흐리지 않는 범위에서 쓴다

비유는 온도·차단율·지속 시간 같은 미확인 성능을 대신하지 않는다. 촉감, 실루엣,
옷차림, 계절, 움직임처럼 장면으로 확인 가능한 영역에 사용한다.

좋은 비유:

- 바람이 머무는 여유
- 오늘의 실루엣은 그대로
- 햇살 앞에 가볍게 더하는 한 겹
- 손끝 가까이 이어지는 여름

피해야 할 비유:

- 얼음장처럼 차갑다
- 햇빛을 완벽하게 차단한다
- 하루 종일 온도를 낮춘다
- 입는 순간 체온이 내려간다

## 2. 카피 변환 공식

### 공식 A — 구조를 결과 장면으로

```text
루즈핏 → 팔의 선을 조이지 않는 가벼운 흐름
47cm 길이 → 팔에서 손등 가까이 이어지는 긴 실루엣
엄지홀 → 손을 움직여도 손등 위 자리를 잡는 구조
화이트 컬러 → 오늘의 옷차림에 조용히 섞이는 색
```

### 공식 B — 기능을 생활 순간으로

```text
쿨 소재 → 한여름 외출에 가볍게 더하는 산뜻한 소재
얇은 소재 → 셔츠와 원피스 위에도 무겁지 않은 한 겹
한 쌍 구성 → 오늘의 외출을 바로 준비하는 두 장
```

### 공식 C — 부정적 문제를 스타일 장벽으로

```text
너무 꽉 낀다
→ 햇살보다 먼저 느껴지는 조임

등산용처럼 보인다
→ 오늘의 옷차림엔 조금 너무 스포티해서

길이가 짧다
→ 팔은 가렸는데, 손등 앞에서 멈춰버린 길이
```

### 공식 D — 주장과 증거를 한 호흡으로

```text
헤드라인: 힘을 뺀 실루엣, 오늘의 옷차림은 그대로
서브: 타이트하게 조이기보다 자연스럽게 흐르는 루즈핏
증거: 같은 모델의 타이트형·루즈핏 슬라이드 비교 GIF
관찰 캡션: 팔 둘레를 따라 생기는 여유와 길이를 확인하세요
```

## 3. 문장 리듬

- 헤드라인은 8~16자 의미 덩어리 1~2줄을 우선한다.
- 한 문장에는 감정 하나와 변화 하나만 둔다.
- 접속사를 줄이고 명사형·짧은 서술형을 섞는다.
- 큰 제목은 설명을 끝내지 않고 다음 이미지가 답할 여지를 남긴다.
- 부품명·치수·주의사항은 광고 제목이 아니라 캡션·표·정보 블록에 둔다.

### 좋은 리듬

```text
오늘의 옷차림엔,
조금 더 가벼운 한 겹.
```

```text
팔을 조이지 않고
햇살 앞에 여유를 남기다.
```

### 나쁜 리듬

```text
팔에는 여유를 제공하며 손등에는 이어지는 길이를 제공합니다.
```

```text
제조사 확인 쿨 소재를 사용해 표면 온도를 낮추는 방향의 기능을 제공합니다.
```

## 4. 고객의 목소리와 말풍선

고객의 공감 문장은 후기 증거가 아니라 문제 인식 장치다.

### 허용 표기

- 오늘의 고민
- 옷장 앞 한마디
- 이런 날 있죠?
- 여름 외출 전, 문득
- 내가 찾던 건

### 금지 표기

- 구매 후기
- 실구매자 리뷰
- 별점
- 구매 인증
- 가짜 이름·날짜·프로필
- 실제 출처가 없는 따옴표 인용

### 말풍선 스타일

- 한 말풍선은 18~42자, 2~4줄 이내로 쓴다.
- 본체와 꼬리는 같은 불투명색으로 자연스럽게 연결한다.
- 꼬리는 말하는 사람·손·옷장·햇빛 장면 중 명확한 대상 하나를 가리킨다.
- 말풍선을 세 개 연속 카드로 만들지 말고 배경 이미지 안의 서로 다른 위치와
  높이에 배치한다.
- 작은 보조 이모지는 의미를 보강할 때만 하나 사용한다.

### 쿨토시의 세 가지 고객 목소리

1. `햇살보다 먼저 느껴지는 조임은 싫어요.`
2. `오늘 옷차림엔, 등산용 토시는 조금 무거워 보여요.`
3. `팔은 가렸는데 손등 앞에서 끝나면 자꾸 신경 쓰여요.`

## 5. 제조사 제공 기능의 고객 언어

제조사 제공 기능은 내부 `fact_id`로 관리한다. 고객 화면에서는 확인 주체나 근거
분류를 제목으로 쓰지 않는다.

| 내부 표현 | 고객 표현 | 증거 방식 |
|---|---|---|
| 제조사 확인 쿨 소재 | 한여름의 팔 위로, 산뜻함이 머무는 소재 | 착용 장면 + 무수치 하강 막대 |
| 표면 온도가 낮아지는 방향 | 입기 전의 따뜻함에서, 입은 뒤의 산뜻함으로 | 동일 기준선의 전후 막대 |
| 공급처 표기 47cm | 팔에서 손등 가까이 이어지는 47cm 길이 | 제품 전체 길이 이미지 + 규격표 |
| 화이트 한 쌍 | 옷장 앞에서 바로 꺼내는 화이트 한 쌍 | 구성 FX GIF |

### 그래프 규칙

- `착용 전`과 `착용 후` 두 상태를 같은 기준선의 막대로 보여 준다.
- 결과 막대는 분명히 낮아지고 하강 화살표가 한 번 꺾여 도착한다.
- 제조사가 제공하지 않은 숫자, 눈금, °C, %, 시간, 시험기관은 넣지 않는다.
- 제목은 `그래프`나 `제조사 주장`이 아니라 고객 변화로 쓴다.
- 그래프 바로 옆에 실제 착용 이미지가 있어야 한다.

## 6. 배경 이미지 카피

### 사용할 때

- 문제 상황을 한눈에 느끼게 할 때
- 스타일과 옷차림을 보여 줄 때
- 제품 사용 후의 분위기를 마감할 때
- 다음 정보 장으로 넘어가기 전 감정적 쉼표가 필요할 때

### 배치

- 모델 또는 제품의 반대쪽 빈 공간을 카피 안전영역으로 정한다.
- 800px 기준 좌우 48~64px, 위·아래 72px 이상을 기본으로 둔다.
- 텍스트 뒤에는 불투명 패널, 방향성 그라데이션, 충분한 그림자 중 하나만 쓴다.
- 사진 위 본문은 2~4줄을 넘기지 않는다.
- 제품 실루엣, 손, 엄지홀, 라벨 위에 제목을 올리지 않는다.

### 배경 이미지 섹션 리듬

```text
문제 배경 이미지
→ 고대비 제품 답
→ 즉시 증명 GIF
→ 스타일 배경 이미지
→ 정보 테이블
→ 피날레 배경 이미지
```

## 7. 소구와 즉시 증명

핵심 장점은 페이지 후반 증거 갤러리로 보내지 않는다.

```text
소구 헤드라인
→ 0~1개의 짧은 설명
→ 전용 이미지 또는 GIF
→ 관찰 캡션
→ 다음 소구
```

증거 매칭:

- 루즈핏: 같은 축척의 타이트형↔루즈핏 슬라이드 비교
- 쿨 소재: 착용 장면 + 무수치 하강 막대
- 스타일: 같은 모델의 캐주얼·주말·원피스 전환
- 손등 길이: 착용 전→엄지홀→완성 순서
- 상품 구성: 한 쌍 정렬→윤곽 강조→`2장 / 1세트` 카운트

### 이펙트 적극성

적극적인 이펙트는 많이 움직이는 것이 아니라 구매 판단을 빠르게 만드는 것이다.

- 슬라이드 와이프: 같은 조건의 차이를 한 축에서 비교
- 리빌 마스크: 제품 전체 길이나 구성을 순서대로 공개
- 라이트 스윕: 라벨·봉제·재질의 실제 위치를 한 번 강조
- 카운트업: 실제 판매 수량만 짧게 확정
- 구조 트레이스: 실제 외곽과 엄지홀을 따라 이동
- 하강 막대: 방향성 기능을 수치 없이 비교
- 스타일 매치컷: 같은 모델·같은 제품으로 옷차림만 전환

이펙트가 제품이나 정보 상태를 바꾸지 못하면 삭제한다.

## 8. 금지 표현

고객 화면에서 다음 표현을 사용하지 않는다.

- 제조사 확인
- 제조사 주장
- 실물 구조를 기준으로
- 상용 촬영 톤으로 재구성
- SSOT
- ImageGen
- God Tibo
- HyperFrames
- 생성 이미지
- 검수 완료
- 근거 이미지
- QA 통과
- 승인본

내부 기록의 `MANUFACTURER_CLAIM`도 공개 제목·배지·캡션에 표시하지 않는다.

## 9. 쿨토시 적용 예시

### 히어로

나쁨:

> 팔에는 여유를, 손등에는 이어지는 길이를

대안 A:

> 오늘의 옷차림엔,<br>
> 조금 더 가벼운 한 겹.

대안 B:

> 햇살은 가볍게 멀리,<br>
> 오늘의 실루엣은 그대로.

대안 C:

> 힘을 뺀 여름,<br>
> 손끝 가까이 이어지다.

### 루즈핏

나쁨:

> 넉넉한 루즈핏으로 편안하게 착용하세요.

좋음:

> 햇살보다 먼저<br>
> 조임을 느끼고 싶지 않으니까.

증거 캡션:

> 팔 둘레를 타이트하게 누르기보다 자연스럽게 흐르는 실루엣.

### 스타일

나쁨:

> 어떤 스타일에도 잘 어울립니다.

좋음:

> 등산 가는 날이 아니어도,<br>
> 자연스럽게 꺼내 입는 팔토시.

증거 캡션:

> 캐주얼부터 원피스까지, 같은 화이트 한 겹으로 이어집니다.

### 손등 길이

나쁨:

> 엄지홀이 있어 손등을 덮어줍니다.

좋음:

> 팔에서 멈추지 않고,<br>
> 손끝 가까이 이어지는 길이.

증거 캡션:

> 엄지홀을 지나 손등 위에 자연스럽게 자리 잡는 구조.

### 쿨 소재

나쁨:

> 제조사 확인 쿨 소재로 표면 온도가 낮아집니다.

좋음:

> 한여름의 팔 위로,<br>
> 산뜻함이 머무는 소재.

증거 캡션:

> 착용 전의 따뜻함과 착용 후의 산뜻함을 방향 변화로 확인하세요.

## 10. QA

- 첫 두 화면 안에 제품 장면과 고객의 하루가 모두 있는가?
- 헤드라인이 부품명·제작 방식·근거 분류로 시작하지 않는가?
- 세 가지 불편이 서로 다른 문제인가?
- 말풍선이 가짜 후기처럼 보이지 않는가?
- 각 소구 바로 다음에 전용 증거가 있는가?
- 배경 이미지 위 카피가 제품과 겹치지 않는가?
- 그래프에 임의 숫자·눈금·시험 문구가 없는가?
- 같은 직역형 제목 구조가 세 번 이상 반복되지 않는가?
- 제품 사실·구성·규격은 광고 비유와 분리된 표에서 정확한가?
- 고객 화면에 금지 표현이 0건인가?
