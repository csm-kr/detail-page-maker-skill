# Commercial Copy Tone Guide

상세페이지의 기능 사실을 구매자가 결제 판단에 쓸 수 있는 상용 광고 언어로
바꾸는 실행 가이드다. 이 문서는
[`sales-copy-and-purchase-confidence.md`](sales-copy-and-purchase-confidence.md)의

고객 화면은 제품 차이와 구매 효익을 먼저 말하고 감성은 보조한다.

## 1. 핵심 원칙

### 고객은 제작 방식을 사지 않는다

고객 화면에서 `무엇으로 만들었는지`, `어떤 원본을 참조했는지`, `누가 확인한
주장인지`, `어떤 생성 도구를 썼는지`를 설명하지 않는다. 고객이 알고 싶은 것은
자기 상황과 제품이 주는 변화다.

```text
내부 기록: 제조사 확인 쿨 소재
고객 화면: 얇고 가벼운 여름용 쿨 소재

내부 기록: 실물 구조를 기준으로 상용 촬영 톤으로 재구성
고객 화면: 문장 삭제. 제품 이미지와 자연스러운 캡션만 남긴다.
```

### 기능은 구매 효익으로 연결한다

```text
고객 질문 → 제품 특징 → 고객 효익 → 사용 장면 → 즉시 증거
```

- 고객 질문: 결제를 망설이게 하는 실제 불안
- 제품 특징: 확인된 구조·소재·규격
- 고객 효익: 그 특징이 구매자에게 주는 실제 이점
- 사용 장면: 언제 그 이점이 필요한지
- 사실 캡션: 이미지·GIF가 무엇을 보여 주는지 한 줄로 고정

### 비유는 사실을 흐리지 않는 범위에서 쓴다

비유는 온도·차단율·지속 시간 같은 미확인 성능을 대신하지 않는다. 촉감, 실루엣,
옷차림, 계절, 움직임처럼 장면으로 확인 가능한 영역에 사용한다.

좋은 비유:

- 바람이 머무는 여유
- 오늘의 실루엣은 그대로
- 햇살 앞에 가볍게 더하는 한 겹
- 손끝 가까이 이어지는 여름

피해야 할 비유:

- 얼음장처럼 차갑다
- 햇빛을 완벽하게 차단한다
- 하루 종일 온도를 낮춘다
- 입는 순간 체온이 내려간다

## 2. 카피 변환 공식

### 공식 A — 구조를 결과 장면으로

```text
루즈핏 → 타이트한 스포츠형과 달리 여유 있게 떨어지는 핏
47cm 길이 → 팔에서 손등까지 이어지는 약 47cm 길이
엄지홀 → 엄지홀을 지나 손등 위에 놓이는 구조
화이트 컬러 → 티셔츠·출근 룩·원피스에 자연스럽게 맞추기 쉬운 색
```

### 공식 B — 기능을 생활 순간으로

```text
쿨 소재 → 얇고 가벼운 여름용 쿨 소재
얇은 소재 → 여름 옷차림에 부담을 덜어 주는 한 겹
한 쌍 구성 → 화이트 2개입, 양팔을 한 번에 준비
```

### 공식 C — 부정적 문제를 스타일 장벽으로

```text
너무 꽉 낀다
→ 팔에 꽉 붙는 착용감이 불편하다

등산용처럼 보인다
→ 스포티한 디자인이 일상복에 부담스럽다

길이가 짧다
→ 손목에서 끝나 손등이 그대로 노출된다
```

### 공식 D — 주장과 증거를 한 호흡으로

```text
헤드라인: 타이트하게 붙지 않는 루즈핏
서브: 여유 있게 떨어져 운전·산책·일상 외출에 부담을 덜어 줍니다
증거: 같은 모델의 타이트형·루즈핏 슬라이드 비교 GIF
관찰 캡션: 팔을 중심으로 같은 축척에서 핏의 차이를 확인하세요
```

## 3. 문장 리듬

- 헤드라인은 8~16자 의미 덩어리 1~2줄을 우선한다.
- 한 문장에는 감정 하나와 변화 하나만 둔다.
- 접속사를 줄이고 명사형·짧은 서술형을 섞는다.
- 큰 제목은 설명을 끝내지 않고 다음 이미지가 답할 여지를 남긴다.
- 부품명·치수·주의사항은 광고 제목이 아니라 캡션·표·정보 블록에 둔다.

### 좋은 리듬

```text
조이지 않게 여유롭고,
손등까지 길게.
```

```text
손목에서 끝나는 팔토시는
손등을 그대로 노출합니다.
```

### 나쁜 리듬

```text
팔에는 여유를 제공하며 손등에는 이어지는 길이를 제공합니다.
```

```text
제조사 확인 쿨 소재를 사용해 표면 온도를 낮추는 방향의 기능을 제공합니다.
```

## 4. 고객의 목소리와 말풍선

고객의 공감 문장은 후기 증거가 아니라 문제 인식 장치다.

### 허용 표기

- 오늘의 고민
- 옷장 앞 한마디
- 이런 날 있죠?
- 여름 외출 전, 문득
- 내가 찾던 건

### 금지 표기

- 구매 후기
- 실구매자 리뷰
- 별점
- 구매 인증
- 가짜 이름·날짜·프로필
- 실제 출처가 없는 따옴표 인용

### 말풍선 스타일

- 한 말풍선은 18~42자, 2~4줄 이내로 쓴다.
- 본체와 꼬리는 같은 불투명색으로 자연스럽게 연결한다.
- 꼬리는 말하는 사람·손·옷장·햇빛 장면 중 명확한 대상 하나를 가리킨다.
- 말풍선을 세 개 연속 카드로 만들지 말고 배경 이미지 안의 서로 다른 위치와
  높이에 배치한다.
- 작은 보조 이모지는 의미를 보강할 때만 하나 사용한다.

### 쿨토시의 세 가지 고객 목소리

1. `햇살보다 먼저 느껴지는 조임은 싫어요.`
2. `오늘 옷차림엔, 등산용 토시는 조금 무거워 보여요.`
3. `팔은 가렸는데 손등 앞에서 끝나면 자꾸 신경 쓰여요.`

## 5. 제조사 제공 기능의 고객 언어

제조사 제공 기능은 내부 `fact_id`로 관리한다. 고객 화면에서는 확인 주체나 근거
분류를 제목으로 쓰지 않는다.

| 내부 표현 | 고객 표현 | 증거 방식 |
|---|---|---|
| 제조사 확인 쿨 소재 | 얇고 가벼운 여름용 쿨 소재 | 실제 제품 위의 짧은 쿨 스윕 |
| 표면 온도가 낮아지는 방향 | 공개 문안에서 삭제 | 수치·시험 근거 없이는 그래프 금지 |
| 공급처 표기 47cm | 팔에서 손등까지 이어지는 약 47cm 길이 | 제품 전체 길이 이미지 + 측정 FX + 규격표 |
| 화이트 한 쌍 | 화이트 2개입, 양팔 한 쌍 | 구성 FX GIF |

### 쿨 표현 규칙

- 공인 시험 수치가 없으면 온도 하강 그래프·막대·꺾은선·열화상을 만들지 않는다.
- 제품과 무관한 서리·얼음 대신 실제 착용 제품 위에 짧은 쿨 스윕을 한 번 둔다.
- `제조사 주장`, 시험기관, 임의 온도·퍼센트·지속 시간을 공개 화면에 쓰지 않는다.
- 제목은 `얇고 가벼운 여름용 쿨 소재`처럼 확인된 범위에서 직접 쓴다.

## 6. 배경 이미지 카피

### 사용할 때

- 문제 상황을 한눈에 느끼게 할 때
- 스타일과 옷차림을 보여 줄 때
- 제품 사용 후의 분위기를 마감할 때
- 다음 정보 장으로 넘어가기 전 감정적 쉼표가 필요할 때

### 배치

- 모델 또는 제품의 반대쪽 빈 공간을 카피 안전영역으로 정한다.
- 800px 기준 좌우 48~64px, 위·아래 72px 이상을 기본으로 둔다.
- 텍스트 뒤에는 불투명 패널, 방향성 그라데이션, 충분한 그림자 중 하나만 쓴다.
- 사진 위 본문은 2~4줄을 넘기지 않는다.
- 제품 실루엣, 손, 엄지홀 위에 제목을 올리지 않는다.
- 라벨은 실제 제품의 일부로만 두고 카피·줌·라이트 스윕으로 강조하지 않는다.

### 배경 이미지 섹션 리듬

```text
문제 배경 이미지
→ 고대비 제품 답
→ 즉시 증명 GIF
→ 스타일 배경 이미지
→ 정보 테이블
→ 피날레 배경 이미지
```

## 7. 소구와 즉시 증명

핵심 장점은 페이지 후반 증거 갤러리로 보내지 않는다.

```text
소구 헤드라인
→ 0~1개의 짧은 설명
→ 전용 이미지 또는 GIF
→ 관찰 캡션
→ 다음 소구
```

증거 매칭:

- 루즈핏: 같은 축척의 타이트형↔루즈핏 슬라이드 비교
- 쿨 소재: 착용 장면 + 실제 제품 위의 짧은 쿨 스윕
- 스타일: 같은 모델의 캐주얼·주말·원피스 전환
- 손등 길이: 착용 전→엄지홀→완성 순서
- 상품 구성: 한 쌍 정렬→윤곽 강조→`2장 / 1세트` 카운트

### 이펙트 적극성

적극적인 이펙트는 많이 움직이는 것이 아니라 구매 판단을 빠르게 만드는 것이다.

- 슬라이드 와이프: 같은 조건의 차이를 한 축에서 비교
- 리빌 마스크: 제품 전체 길이나 구성을 순서대로 공개
- 라이트 스윕: 주장과 직접 관련된 봉제·재질의 실제 위치를 한 번 강조
- 카운트업: 실제 판매 수량만 짧게 확정
- 구조 트레이스: 실제 외곽과 엄지홀을 따라 이동
- 쿨 스윕: 실제 착용 제품 위에서 얇고 가벼운 여름용 소재를 정성적으로 강조
- 스타일 매치컷: 같은 모델·같은 제품으로 옷차림만 전환

이펙트가 제품이나 정보 상태를 바꾸지 못하면 삭제한다.

## 8. 금지 표현

고객 화면에서 다음 표현을 사용하지 않는다.

- 제조사 확인
- 제조사 주장
- 실물 구조를 기준으로
- 상용 촬영 톤으로 재구성
- SSOT
- ImageGen
- God Tibo
- HyperFrames
- 생성 이미지
- 검수 완료
- 근거 이미지
- QA 통과
- 승인본

내부 기록의 `MANUFACTURER_CLAIM`도 공개 제목·배지·캡션에 표시하지 않는다.

## 9. 쿨토시 적용 예시

### 히어로

나쁨:

> 팔에는 여유를, 손등에는 이어지는 길이를

좋음:

> 조이지 않게 여유롭고,<br>
> 손등까지 길게.

서브:

> 팔에 달라붙는 스포츠형 팔토시가 불편했다면,<br>
> 옷차림에 자연스럽게 떨어지는 루즈핏으로 바꿔보세요.

### 루즈핏

나쁨:

> 넉넉한 루즈핏으로 편안하게 착용하세요.

좋음:

> 타이트한 밀착 대신,<br>
> 여유롭게 떨어지는 루즈핏.

증거 캡션:

> 팔을 중심으로 같은 축척에서 루즈핏의 여유를 확인하세요.

### 스타일

나쁨:

> 어떤 스타일에도 잘 어울립니다.

좋음:

> 티셔츠부터 출근 룩,<br>
> 원피스까지 자연스럽게.

증거 캡션:

> 캐주얼부터 원피스까지, 같은 화이트 한 겹으로 이어집니다.

### 손등 길이

나쁨:

> 엄지홀이 있어 손등을 덮어줍니다.

좋음:

> 손목에서 끝나는 팔토시는<br>
> 손등을 그대로 노출합니다.

증거 캡션:

> 엄지홀을 지나<br>
> 손등까지 길게.

### 쿨 소재

나쁨:

> 제조사 확인 쿨 소재로 표면 온도가 낮아집니다.

좋음:

> 얇고 가벼운<br>
> 여름용 쿨 소재.

증거 캡션:

> 실제 착용 제품 위의 쿨 스윕으로 소재의 가벼운 인상을 보여 줍니다.

## 10. QA

- 첫 화면에서 모델보다 제품이 크고 제품 차이가 직접 보이는가?
- 판매 정보 70 : 브랜드 감성 30 비율인가?
- 각 장점이 특징 → 고객 효익 → 사용 장면 → 즉시 증거로 이어지는가?
- 같은 장점을 세 번 이상 반복하지 않았는가?
- 헤드라인이 부품명·제작 방식·근거 분류로 시작하지 않는가?
- 세 가지 불편이 서로 다른 문제인가?
- 말풍선이 가짜 후기처럼 보이지 않는가?
- 각 소구 바로 다음에 전용 증거가 있는가?
- 배경 이미지 위 카피가 제품과 겹치지 않는가?
- 수치·시험 근거 없는 쿨 그래프·막대·열화상이 없는가?
- 같은 직역형 제목 구조가 세 번 이상 반복되지 않는가?
- 비교 장면이 얼굴·전신보다 제품을 착용한 팔을 같은 축척으로 보여 주는가?
- 라벨을 소구나 FX 대상으로 강조하지 않았는가?
- 제품 사실·구성·규격은 광고 비유와 분리된 표에서 정확한가?
- 고객 화면에 금지 표현이 0건인가?
