# 03. 로컬 Studio 서버와 작업 대기열 구현

- Type: task
- Status: resolved
- Triage: ready-for-agent
- Blocked by: 01, 02
- Created: 2026-07-26

## Question

외부 데이터베이스 없이 프로젝트 폴더에서 에셋·작업·승인·개정판·조립 잠금을 안정적으로 관리할 수 있는가?

## Acceptance criteria

- Node.js 기본 모듈만으로 서버가 시작된다.
- 프로젝트 상태는 원자적으로 저장된다.
- 이미지 등록, 작업 생성, QA 결과 기록, 승인, 조립 잠금, 새 개정판 인터페이스가 있다.
- 승인·잠금 불변식을 서버가 검증한다.
- 변경 에셋의 의존 항목만 다시 승인 대상으로 계산한다.

## Answer

Node.js 기본 모듈만 사용하는 로컬 서버, 원자 프로젝트 저장소, append-only 이벤트, 작업 대기열, 에셋 QA·승인, 조립 잠금, 의존성 개정판, HTML 레이어 저장과 세 가지 내보내기를 구현했다.

## Comments

- 2026-07-26: 브라우저에 API 키를 두지 않고 Codex가 로컬 작업 대기열을 소비하는 구조로 결정했다.
- 2026-07-26: Windows `npx.cmd` 진단 실행과 존재하지 않는 기본 프로젝트 상위 폴더 생성 문제를 회귀 테스트로 교정했다.
