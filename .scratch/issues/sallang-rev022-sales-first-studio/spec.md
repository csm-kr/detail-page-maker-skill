## 목적

기존 제품·모델 SSOT와 승인된 상용 파생 자산은 보존하고, 상세페이지를 판매 정보
70 : 브랜드 감성 30의 비율로 다시 조립한다. Studio는 문서·프레젠테이션 편집기처럼
요소 배치와 텍스트 변환 모드를 분리하고 정렬·삭제·가이드·단축키를 제공한다.

## 사용자 요구

1. 요소 배치와 텍스트 변환을 별도 버튼·별도 동작 범위로 분리한다.
2. 요소 배치 모드에 캔버스 중심·섹션 중심·안전 여백 가이드와 스냅을 둔다.
3. 텍스트 변환 모드에 왼쪽·가운데·오른쪽·양쪽 정렬을 추가한다.
4. `V`, `T`, 화살표, `Shift+화살표`, 정렬 단축키, `Delete`, `Esc`,
   `Ctrl/Cmd+Z`를 제공한다.
5. 선택 요소 삭제를 실행 취소할 수 있어야 한다.
6. 첫 화면은 모델보다 제품을 크게 보여 주고 제품 차이를 직접 말한다.
7. 손등 문제는 `손등이 노출된다`는 의미를 명확히 전달한다.
8. 비교 장면은 얼굴·전신보다 팔과 제품을 중심으로 크롭한다.
9. 라벨은 판매 소구로 쓰지 않는다.
10. 특징을 생활 효익과 사용 장면으로 연결한다.
11. 근거 없는 냉감 수치·그래프·UV·흘러내림 보장을 만들지 않는다.
12. 확인된 구성·치수·비침 가능성과 구매 전 질문을 앞쪽·후반 정보 장에 배치한다.
13. 감성 반복을 줄이고 같은 장점은 최대 두 번만 말한다.
14. 축약된 스킬 설명 환경에서도 `SKILL.md → guide.md → 작업별 reference`로
    라우팅되어 위 규칙을 빠짐없이 읽고 실행하게 한다.
