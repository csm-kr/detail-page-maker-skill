## 목적

현재 rev020의 제품 동일성과 스타일 섹션은 유지하되, 구매자에게 보이는 모든
카피·이미지·GIF·정보 흐름을 상용 광고 언어와 즉시 증명 구조로 다시 설계한다.
제작 방식이나 내부 근거 분류를 설명하지 않고 고객의 불편, 기대 장면, 제품이 주는
변화를 먼저 보여 준다.

## 사용자 피드백 정본

1. `팔에는 여유를, 손등에는 이어지는 길이를`처럼 구조를 직역한 문장은 광고적
   비유와 감정적 장면이 부족하다.
2. Behance `상세페이지` 검색 결과의 실제 프로젝트 50개 이상을 조사해 커머셜
   카피·문자·말풍선·배경 이미지·비교 연출 패턴을 학습해야 한다.
3. 불편은 세 가지로 구성한다.
   - 타이트한 팔토시가 남기는 답답함과 눌림
   - 등산용·스포티 팔토시가 오늘의 옷차림을 무겁게 만드는 문제
   - 자외선 차단은 필요하지만 손등까지 자연스럽게 이어지지 않는 문제
4. 고객 메시지·고객의 소리처럼 읽히는 짧은 문장과 자연스러운 말풍선 스타일은
   유지하고 재사용 가능한 흐름으로 문서화한다.
5. `제조사 확인 쿨 소재`, `실물 구조를 기준으로 상용 촬영 톤으로 재구성`,
   `God Tibo`, `ImageGen`, `SSOT`, `제조사 주장`처럼 제작자에게만 필요한 표현은
   고객 화면에서 제거한다.
6. 제조사 제공 기능은 내부 근거로만 관리한다. 고객 화면에서는 제조사나 근거
   분류를 말하지 않고 착용자가 느끼는 변화와 제품 장면으로 표현한다.
7. 배경 자체가 이미지인 몰입형 섹션을 늘리되 카피 안전영역과 대비를 보장한다.
8. 실제 착용 이미지에서 위쪽 원단이 트위스트·꽈배기처럼 꼬인 오류를 수정한다.
9. 쿨링은 그래프·막대·임의 온도 수치 없이, 열감이 걷히고 차가운 공기감이
   퍼지는 전후 이펙트로 즉시 이해되게 표현한다.
10. HyperFrames의 슬라이드 비교, 전후 분할, 강조 FX를 적극 사용한다.
11. 소구점 하나를 제시하면 전용 이미지 또는 GIF 증거를 바로 다음 모듈에 둔다.
    상세 증거 GIF를 페이지 후반에 한꺼번에 모으지 않는다.
12. 중복되는 `detail proof` 묶음은 제거한다.
13. 상품 구성은 가장 제품 동일성이 좋은 한 쌍 이미지와 HyperFrames FX로 즉시
    이해되게 표현한다.
14. 현재 스타일 섹션과 규격 테이블의 좋은 방향은 유지한다.
15. 마지막 피날레 이미지는 실제 47cm 비례와 길게 떨어지는 실루엣이 충분히
    보이도록 다시 생성한다.
16. 실제 촬영 원본과 공급처 원본은 동일성 SSOT로만 사용한다. 공개 이미지와 GIF
    픽셀은 God Tibo 상용 파생 자산만 사용한다.
17. 작업 자산과 사용자 검토·납품 결과를 분리한다. `asset/`은 입력·SSOT·생성
    후보·승인 자산만 보존하고, 사용자가 열 결과는
    `deliverables/<revision>/` 아래 한 패키지로 고정한다.
18. 모든 GIF에는 주장과 직접 관련된 FX를 하나 이상 넣는다. 장식용 FX는
    수락하지 않는다.
19. GIF 안 문구는 해당 GIF 위의 헤드라인·설명과 반복하지 않는다. GIF 안에는
    상태 변화만 읽히는 짧은 라벨을 사용한다.
20. 규격 표 위에는 제품의 실제 47 cm 측정 시작점·끝점·측정선을 보여 주는
    전용 GIF를 둔다. 이후 모든 상품도 핵심 치수 표에 측정 위치 GIF를 필수로
    연결한다.
21. Studio에서 텍스트·이미지·GIF·장식 요소를 모두 선택할 수 있어야 하며,
    선택 요소 위치 이동, 텍스트 비우기, 실행 취소, 글꼴과 글자색 변경을
    지원한다.
22. Studio 글꼴 선택지는 Noto Sans KR, Gmarket Sans, S-Core Dream,
    Wanted Sans, Black Han Sans, Jalnan을 포함한다.
23. 사용하지 않는 `asset/assets` 자료는 삭제하지 않고
    `archive/legacy-assets/<date>/`로 옮겨 원래 경로·SHA-256·복구 경로를
    manifest에 기록한다.
24. `migration/asset-root-unification` 워크트리 커밋을 병합하고 원격 최신
    `main`을 반영한 뒤, 이번 변경만 선별 커밋·푸시한다.

- `deliverables/rev021-commercial/index.html`만 현재 검토본 링크로 안내한다.
- `media/`에는 실제 HTML이 참조하는 파일만 복사한다.
- 다음 개정은 기존 폴더를 덮어쓰지 않고 `rev022-*`를 만든다.
