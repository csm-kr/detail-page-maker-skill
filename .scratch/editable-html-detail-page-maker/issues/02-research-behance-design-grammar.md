# Behance 우수 상세페이지의 디자인 문법 조사

Type: research
Status: resolved
Blocked by:

## Question

Behance `상세페이지` 검색 결과의 우수한 제품 프로젝트들은 어떤 반복 가능한 정보 구조, 타이포 위계, 제품 연출, 섹션 리듬과 증거 표현 문법을 사용하며 이를 복제 없이 디자인 규칙으로 어떻게 추출할 것인가?

## Answer

[`Behance 제품 상세페이지 디자인 문법 조사`](../../../research/behance-detail-page-design-grammar.md)에서 지정 스포틀러를 포함한 서로 다른 범주의 원본 프로젝트 15개를 조사했다.

- 공통 서사는 `제품·가치 인지 → 상황·문제 → 해결 원리·장점 → 구조·수치 증거 → 사용 → 구매 확인`이다.
- 긴 페이지는 감성·정보·증거 블록을 교차하고, 같은 카드 구도를 세 번 연속 사용하지 않는다.
- 전체·사용 스케일·작동 부위·재질 매크로·결과 중 최소 세 가지 카메라 거리를 사용한다.
- 모든 주장은 시각 자료와 evidence ID를 가까이 두며, 시간 변화가 주장일 때만 한 GIF로 한 동작을 보여준다.
- 작품의 정보 목적과 구성 원리만 추출하고 팔레트·서체·카피·모델·고유 구도는 복제하지 않는다.
- 최종 HTML에서는 카피·수치·근거를 DOM/JSON으로 분리하고 이미지·GIF를 교체 가능한 자산으로 둔다.
