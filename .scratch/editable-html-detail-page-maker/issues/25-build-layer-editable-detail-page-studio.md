# 25. 말풍선·텍스트·GIF 박스 레이어 편집 Studio

- Type: prototype
- Status: open
- Blocked by: 24
- Created: 2026-07-25

## 질문

현재 카피·자산·섹션 순서·강조색 중심 Studio를 확장해, 말풍선 본체와 꼬리·텍스트·GIF·이미지·강조 박스의 위치와 얼라인까지 비개발자가 안전하게 수정할 수 있는가?

## 검토 범위

- 안정된 `section ID + layer ID` 데이터 모델
- `x/y/width/height/z-index`, 정렬, 글자 크기·행간·색, 배경·곡률
- 말풍선 본체와 SVG 꼬리의 종속 이동, 꼬리 방향·끝점·곡률
- 이미지/GIF crop, `object-position`, poster, 재시작, 자산 교체
- 8px 그리드, edge/center 스냅, 안전영역, 제품 비가림 경고
- 320·390·800px별 위치 오버라이드와 상속
- undo/redo, JSON preset, 버전 비교, 독립 HTML 내보내기
- HyperFrames 원본 타임라인과 HTML 배치 편집의 책임 분리

## 수락 기준

- 말풍선 그룹을 옮겨도 본체·꼬리 접합부가 벌어지지 않는다.
- 텍스트와 GIF 박스를 옮길 때 스냅 가이드와 안전영역 경고가 작동한다.
- 800px 편집이 390px 레이아웃을 깨뜨리지 않으며 뷰포트별 오버라이드를 명시적으로 저장한다.
- 편집 결과가 새로고침·내보내기 뒤 안정된 layer ID로 복원된다.
- 제품 실루엣·주요 카피 겹침, 화면 밖 요소, 잘린 텍스트를 자동 검사한다.
- 기존 단일 HTML 내보내기와 GIF 상대 경로가 유지된다.

## Answer

아직 구현하지 않았다. 현재 노바페이스 commercial-final v10 승인 이후 별도 프로토타입으로 진행한다.
