# 공급처 URL 추출 계약 결정

Type: grilling
Status: resolved
Blocked by:

## Question

공급처 URL 하나에서 반드시 수집·보존·해시해야 할 원문 필드와 이미지, 누락·로그인·캡차·동적 콘텐츠 실패 시의 중단 조건은 무엇인가?

## Answer

첫 공급처를 도매꾹으로 확정하고 [`도매꾹 공급처 추출 계약`](../../../docs/contracts/domeggook-supplier-extraction.md)을 채택한다.

- 입력은 숫자 상품번호를 포함한 실제 도매꾹 상세 URL 하나와 새 출력 경로다.
- 기존 `dmk-extractor`가 격리 Browser Harness로 대표 이미지, 펼친 상세 원본, 상세 내부 GIF 전체 프레임, 최근 6개월 공개 후기와 SHA-256 원장을 만든다.
- 원본 portable bundle은 수정하지 않고, 새 스킬이 출처 locator가 붙은 `planning/supplier-facts.json`을 별도로 만든다.
- 공급처 원문에 없는 사실은 추정하지 않으며 OCR 미확인 값, 시험 조건이 없는 주장과 출처 충돌을 명시적 공백으로 남긴다.
- 가격·재고·배송 조건은 수집 시점 운영 정보로만 저장하고 영구 제품 사실이나 광고 카피에 사용하지 않는다.
- CAPTCHA·로그인·접근 제한은 우회하지 않으며 캡처·해시·개인정보·후기 수 검증 실패 시 후속 기획을 중단한다.
- 공급처 이미지의 사용허용 표시는 관찰값이며 판매용 권리 보증으로 간주하지 않는다.
