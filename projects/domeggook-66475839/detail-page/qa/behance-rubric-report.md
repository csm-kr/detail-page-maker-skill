## 문제→해결 기획 QA

동종 제품 세 상품의 후기에서 다음 불편이 반복됐다.

- 사이즈가 크거나 헐겁게 느껴짐: 3/3 상품
- 뒤꿈치 또는 봉제 마찰: 3/3 상품
- 젖은 바닥에서의 미끄럼 불안: 3/3 상품
- 모래 유입: 3/3 상품
- 배수 체감: 2/3 상품

## ImageGen 소재 QA

- `product-green-side.png`: 공급처의 그린 측면 제품을 참조하고 `Sport Keeper` 레터링, 뒤꿈치 고리, 입구 봉제, 보강 패턴을 눈검수했다.
- 투명 누끼는 1,870×841 RGBA이며 SHA-256은 `5fffb93e...f32ddb0`이다.
- 생성 과정에서 만든 보이지 않는 밑창 시안은 형태를 추정했기 때문에 증거 사용에서 탈락시켰다.
- `aqua-use-context.gif`의 기반 장면은 승인 컷아웃과 공급처 참조를 사용한 착화 연출이다. 미끄럼·배수·건조 성능 장면이 아니다.
- `campaign-hero-v2.png`, `use-pool-v1.png`, `use-waterpark-v1.png`, `use-beach-v1.png`, `use-valley-v1.png`는 각각 별도 생성한 1,586×992 가로 자산이다.
- 다섯 이미지 모두 입력 1을 제품 동일성 SSOT, 입력 2를 착화 비례, 입력 3을 공급처 색·형태 보조로 명시했다.
- 이미지 내부에는 새 광고 문구를 굽지 않았다. 제목·설명·고지 문구는 모두 HTML이며 Studio에서 수정 가능하다.
- 수영장 장면은 착화와 입구 마감 확인, 워터파크는 이동 전 사이즈 확인, 해변은 모래 제거·건조, 계곡은 젖은 지면 주의에만 연결했다. 생성 장면을 성능 시험으로 사용하지 않았다.

## 한국어 카피 QA

카피는 `고객이 겪는 상황 → 확인할 불편 → 지금 할 행동 → 주장 한계` 순서로 다시 읽었다.

- 제작 메모형 문장 `성능을 단정하지 않고`, `과장된 성능 문구 대신`, `보이는 구조는 분명하게`를 고객 행동 문장으로 교체했다.
- 제목은 명사 나열보다 질문·행동·선택의 한 문장으로 통일하고, 본문은 `-하세요/-습니다` 존댓말로 맞췄다.
- `발끝이 남는다`는 `발끝에 여유가 너무 남는다`, `피부를 불편하게 누른다`는 `피부에 거슬린다`로 고쳐 실제 쇼핑 문장에 가깝게 만들었다.
- `도매꾹`, `공급처 상세 원문 기준`, `성능을 단정`, `과장은` 같은 제작·근거 관리 문구가 구매자 화면에 남지 않았음을 확인했다.
- 영어 눈썹 라벨은 5개다. 16개 섹션의 Taste 상한 `ceil(16/3)=6`을 넘지 않는다.
- em dash와 en dash는 0개이며, 첫 화면 제목은 320·360·390·768·800px에서 모두 2줄이다.

## 상세페이지 Studio QA

- 장면 이미지 파일·상대 경로, 가로·세로 초점, 오버레이 농도와 4개 색상 토큰을 수정할 수 있다.
- 800px·390px 미리보기 전환과 모션 정지·재생이 동작한다.
- JSON 저장·내보내기와 2단계 초기화를 제공하며 `alert`·`confirm`에 의존하지 않는다.
- 단일 HTML 내보내기를 실제 실행했다. 결과는 31,287,338바이트이며 PNG·GIF 16개가 `data:` URL로 포함됐다.
