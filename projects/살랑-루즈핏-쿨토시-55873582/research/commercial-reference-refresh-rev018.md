## 공식 페이지 관찰

### MISSION Cooling Sun Sleeves

- URL: https://www.mission.com/products/sun-sleeves
- 관찰: 제품 착용 전신·제품 단품·기능별 이미지를 분리하고 `INNOVATIVE COOLING`, `SUN PROTECTION`, `CHEMICAL-FREE COOLING`, `ODOR CONTROL`처럼 기능 하나당 한 장면을 준다.
- 채택: 한 GIF는 한 소구만 증명하고, 제품 사진 주변의 효과가 해당 소구의 원인과 결과를 직접 가리키게 한다.
- 채택하지 않음: MISSION의 성능 수치·기술명·냉각 방식은 살랑의 근거가 아니므로 사용하지 않는다.

### UNIQLO AIRism UV Protection Arm Cover

- URL: https://www.uniqlo.com/it/en/products/E474206-000/00
- 관찰: 상품 갤러리 뒤에 짧은 기능 문장, `Official/StyleHint styling`, 실제 구매후기를 순서대로 배치한다. 스타일링은 제품 자체 설명과 분리해 여러 착장 속 동일 제품을 보여준다.
- 채택: 같은 20대 여성 모델과 같은 화이트 제품을 고정하고 캐주얼·출근·페미닌 세 착장만 바꾸는 스타일 전환. 후기 섹션은 동일 SKU 후기 문장이 확보될 때만 노출한다.
- 채택하지 않음: AIRism·UV Protection 등 UNIQLO 고유 기술과 후기는 살랑의 근거로 옮기지 않는다.

### BUFF Safety Arm Sleeves

- URL: https://www.buff.com/safety/arm-sleeves/
- 관찰: 더운 환경이라는 문제를 먼저 두고 `STAY COOL AND PROTECTED`처럼 해결 결과를 큰 문장으로 고정한다. 기술 설명은 제품·환경 사진과 함께 별도 구역에 둔다.
- 채택: 냉감 GIF를 `열감 상태 → 원단 중심의 냉감 전환 → 하강 방향 곡선 완성`의 세 단계로 만든다. 숫자 대신 방향과 색 변화만 사용한다.
- 채택하지 않음: 인증, UPF, 특정 섬유 기술, 동적 체온 반응은 살랑의 제공 근거가 아니므로 사용하지 않는다.

### Ergodyne Chill-Its 6690

- URL: https://www.ergodyne.com/chill-its-6690-cooling-arm-sleeves.html
- 관찰: 실제 제품 이미지, 한 장짜리 기능 인포그래픽, 치수표를 분리한다. 각 기능 이미지는 제품 전체보다 증명할 부위를 더 크게 보여준다.
- 채택: 손등 커버는 엄지홀·커프, 루즈핏은 팔뚝 플리츠와 여유 실루엣, 사용법은 손이 들어가는 경로를 각각 확대한다.
- 채택하지 않음: 물에 적시는 냉각 방식, UPF, 보호 성능, 반사 디테일, 수치형 치수는 살랑과 동일하지 않으므로 사용하지 않는다.

## 제작 금지

- 단순 확대·축소, 느린 크로스페이드만으로 끝내지 않는다.
- 제품 원단·길이·엄지홀·커프·라벨을 생성 모델의 상상으로 바꾸지 않는다.
- 제품을 가리는 눈송이·얼음·과한 광선·입자 폭발을 사용하지 않는다.
- 제조사가 주지 않은 섭씨, 퍼센트, 시간, 시험기관, 정확한 눈금을 만들지 않는다.
- 같은 SKU의 실제 후기 문장이 없는 상태에서 별점·후기 인용을 만들지 않는다.
