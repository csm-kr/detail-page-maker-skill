# 노바페이스 부품별 주장-증거 개편안

- 작성일: 2026-07-27
- 상태: 구현 전 사용자 확인 대기
- 대상: 노바페이스 발편한 기능성깔창
- 구현 범위: 아직 HTML·ImageGen·HyperFrames 자산을 변경하지 않음
- 조사 근거: [`official-insole-support-patterns-20260727.md`](official-insole-support-patterns-20260727.md)

## 현재 문제

현재 03번 에어셀 섹션은 카피에서 `입체 에어셀`을 말하지만 `cell-scan.gif`는 뒤꿈치 중앙의 블루쿠션 접촉 전후를 보여 준다. 같은 섹션의 `충격을 부드럽게 분산` 문구도 현재 시험 근거가 없어 공급처 사실 레코드의 금지 범위를 넘는다.

따라서 현재 구성은 다음 두 이유로 조립 전 승인 게이트를 통과할 수 없다.

1. 카피가 말하는 부품과 GIF가 강조하는 부품이 다르다.
2. 보이는 구조를 시험되지 않은 성능 결과로 확장한다.

## Design Read

실제 제품의 구조 매크로를 중심으로, 코발트 블루와 차가운 중립색의 운동감 있는 아트디렉션을 적용한 증거 주도형 상용 인솔 상세페이지.

- `DESIGN_VARIANCE`: 6
- `MOTION_INTENSITY`: 7
- `VISUAL_DENSITY`: 6
- 팔레트: 기존 코발트 블루·미드나이트 네이비·화이트 유지
- 원칙: 한 화면 한 부품, 한 GIF 한 변화, 한 주장 한 직접 증거

| claim_id | component_id | fact_id | evidence_asset_id | section_id | 공개 상태 |

기존 `CLAIM-CUSHION`처럼 에어셀과 블루쿠션을 한 문장에 합친 주장은 폐기 후보로 두고, 구조별 claim으로 분리한다.

## 신규 에어셀 GIF

목적: 흰 PU 아랫면의 다각형 돌출 셀이 `에어셀`임을 명확히 보여 준다.

시퀀스:

1. 실제 아랫면 전체 0.8초 정지
2. 중족부의 흰색 다각 셀로 확대
3. 셀 외곽을 앞에서 뒤로 순차 강조
4. 15-20도 사선으로 바뀌며 셀 높낮이 확인
5. 전체 아랫면으로 복귀하고 `입체 에어셀` 상태 라벨 유지

하드 게이트:

- 활성 마스크와 광원 중심은 흰 PU 셀 안에만 둔다.
- 블루쿠션은 보일 수 있으나 강조하지 않는다.
- 에어홀은 공기 흐름 효과 없이 원래 위치만 보존한다.
- 셀 수·배열·높이를 SSOT보다 과장하지 않는다.
- 압력맵, 하중 수치, 충격 흡수 결과를 만들지 않는다.

## 기존 GIF의 블루쿠션 재분류

`cell-scan.gif`의 실제 내용은 `발이 닿기 전 → 블루쿠션 접촉`이다. 구현 시 다음 항목을 함께 바꾼다.

- 파일 역할과 manifest: `blue-cushion-contact`
- `data-asset-id`: `GIF-BLUE-CUSHION-CONTACT`
- 제목과 alt: 블루쿠션만 명명
- 상태 라벨: `닿기 전 → 블루쿠션이 닿을 때`
- 파동 중심: 실제 뒤꿈치 접점과 일치

단순히 파일명과 카피만 바꾸지 않고, 첫·중간·마지막 프레임의 강조 영역이 블루쿠션 안에 머무는지 다시 검수한다.

## 06 입체 설계

사용자 요청의 `발을 잡아주는 입체 설계`는 고정·안정화 성능으로 읽힐 수 있어 현재 근거로는 그대로 확정하지 않는다. 실제 윗면 SSOT에서 직접 보이는 뒤꿈치 둘레의 높이와 굴곡만 사용해 다음 문구를 제안한다.

권장 헤드라인:

> 뒤꿈치 둘레까지,  
> 입체적으로 감싸는 설계.

권장 설명:

> 발 모양을 따라 굴곡진 윗면이  
> 뒤꿈치 둘레를 부드럽게 감싸도록 설계했습니다.

증거 구성:

1. 실제 윗면 SSOT의 뒤꿈치 테두리와 중앙 패치를 보존한 3/4 상용 이미지
2. 정면 → 뒤꿈치 사선 → 측면의 3단계 회전 GIF
3. 주변의 올라온 테두리만 따라가는 얇은 윤곽선
4. 마지막 1초는 윤곽선을 제거해 제품 구조만 보이는 상태

## 구현 승인 조건

1. 사용자가 06번 문구를 승인한다.
2. 에어셀·블루쿠션·입체 윗면의 claim과 component 연결이 각각 하나다.
3. 신규 정지 이미지와 GIF는 조립 전에 원본과 후보 한 개를 비교해 사용자 승인을 받는다.
4. ImageGen 결과는 실제 셀 배열, 뒤꿈치 테두리 높이, 윗면·아랫면, 블루쿠션 위치를 바꾸지 않는다.
5. 모든 공개 주장에 전용 이미지 또는 GIF가 있고, 근거 없는 기능 결과는 0건이다.
6. 조립 뒤 상용 QA 97점 이상과 하드 실패 0건을 다시 확인한다.
