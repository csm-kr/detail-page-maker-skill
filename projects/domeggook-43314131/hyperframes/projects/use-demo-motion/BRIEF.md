# Use Demo Motion Brief

- Workflow: `motion-graphics`
- Output: 4초 반복 GIF/MP4, 800×600, 15/30fps
- Message: 실제 이중 칼날 커터로 오이를 얇게 슬라이스하는 사용 전후를 한 번에 이해시킨다.
- Product identity: 도매꾹 원본과 제품 누끼를 참조해 생성한 start/end keyframe을 그대로 사용한다.
- Motion: start 위에 end frame을 방향성 있는 mask reveal로 노출하고 다시 start로 복귀한다.
- Constraints: 새 제품 구조를 그리지 않는다. 수치나 속도 주장을 넣지 않는다. 텍스트·로고를 영상에 굽지 않는다.
