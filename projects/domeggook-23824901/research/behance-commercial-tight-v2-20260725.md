# Behance commercial-tight v2 추가 조사

조사일: 2026-07-25
방법: 격리 Browser Harness로 Behance `상세페이지` 검색 결과와 개별 프로젝트 원본 모듈을 관찰했다.
범위: 기존 `research/behance-detail-page-design-grammar.md`에 없던 프로젝트만 선택했다.

## 새 표본

1. [테리브 앰플클렌저 상세페이지 제작](https://www.behance.net/gallery/241274633/_)
   - 게시: 2025-12-30
   - 관찰: 단색에 가까운 올리브 배경, 중앙 제품, 위쪽 2단 제목, 아래쪽 정량 정보의 세 덩어리로 첫 화면을 단순화했다.
   - 변환 규칙: 히어로에는 제품·핵심 한 문장·보조 근거 한 줄만 둔다. 통계는 같은 화면에 억지로 다 넣지 않고 다음 밝은 정보 블록으로 넘긴다.

2. [루케 바디미스트 상세페이지 제작](https://www.behance.net/gallery/251502623/_)
   - 게시: 2026-06-22
   - 관찰: 큰 실제 사용 사진 위 2~3줄 카피, 다음 장면은 종이 카드 형태의 서사 블록으로 전환한다. 사진의 빈 피부·의복 영역을 카피 안전 영역으로 사용한다.
   - 변환 규칙: 실제 사진과 HTML 카피를 분리하되 카피 위치는 피사체가 없는 여백에 고정한다. 밝은 사진에는 로컬 오버레이를 추가한다.

3. [[상세페이지] 레모라 유기농 레몬즙](https://www.behance.net/gallery/220227061/-Lemon-juice-Product-page)
   - 게시: 2025-02-27
   - 관찰: 재료 매크로 장면과 짧은 질문형 GIF를 사용해 정지 정보 사이에 리듬을 만든다. 모션은 한 장면에서 한 질문만 다룬다.
   - 변환 규칙: ImageGen 장식은 소재·온도·질감의 분위기 전환에만 쓰고, 실제 제품 사실과 수치는 HTML·SVG·HyperFrames로 다시 증명한다.

4. [[상세페이지] 전문가용 미용 트리머](https://www.behance.net/gallery/252540551/-Professional-Hair-Trimmer)
   - 게시: 2026-07-11
   - 관찰: 무채색 제품 무대, 제품 외곽과 평행한 치수선, 옵션·구성품을 독립된 흰 카드로 분리한다. 장식보다 제품 형태와 수치가 먼저 읽힌다.
   - 변환 규칙: 치수선은 제품과 접촉하지 않고 측정 대상과 평행해야 한다. 수치·단위·끝점은 같은 SVG 좌표 모델을 사용한다.

## 타이포·정렬 기준

- 800px 기준 히어로 제목은 56~76px, 섹션 제목은 40~62px, 본문은 16~19px를 사용한다.
- 390px 기준 히어로 제목은 34~48px, 섹션 제목은 30~42px, 본문은 16~18px를 사용한다.
- 의미 있는 구매자용 텍스트는 모든 기준 폭에서 14px 아래로 내리지 않는다.
- 사진 위 카피는 최대 3줄, 한 줄 12~18자 안팎을 우선하며 제품과 같은 초점 영역을 차지하지 않는다.
- 제품 중심 장면은 중앙축, 사용 장면은 피사체 반대편 여백, 정보 장면은 12열 또는 4열 그리드에 맞춘다.
- 숫자와 단위는 붙여 읽히게 하되 설명 문장은 별도 줄로 분리한다.

## 쿨패치에 적용할 변환

- 얼음·눈송이의 양을 늘리는 대신 하이드로겔의 투명함, 물결, 응결광을 장식 레이어로 사용한다.
- 첫 장면은 손에 들고 있는 얼음팩과 붙여 쓰는 패치의 사용 방식 차이를 질문으로 보여준다.
- 실제 제품은 공급처 참조 누끼를 크게 두고 카피는 HTML로 분리한다.
- 5×12cm, 2매입, 하이드로겔·PE, 36개월 이상, 사용 순서는 SVG와 HyperFrames로 표현한다.
- `-10.1°C`, `최대 8시간`, `저자극`, `무자극`, `강한 접착`은 별도 시험 확인 전 사용하지 않는다.

## 복제 방지

- 원본 브랜드명·로고·제품·카피·고유 레이아웃을 가져오지 않는다.
- 채택 대상은 `사진→짧은 카피→정보`, 카피 안전 영역, 치수선 정렬, 한 모션 한 메시지의 추상 규칙뿐이다.
- 쿨패치 페이지는 아쿠아 블루·클리어 젤·딥 네이비의 자체 토큰으로 다시 설계한다.
