# 도매꾹 60851997 실제품 원본

이 폴더는 사용자가 직접 촬영한 동일 SKU의 원본과 사용자가 직접 수정해 SSOT로 승격한 참조 이미지를 보관한다.

- 촬영 원본은 회전, 배경 제거, 색 보정, 리사이즈하지 않는다.
- 제품의 형상, 색상, 로고, 부품 결합 구조는 이 폴더의 자산을 최우선 SSOT로 사용한다.
- `Flux2-Klein_00355_.png`는 사용자가 수정 후 SSOT로 명시한 측면·굽힘 구조 참조다.
- 누끼와 정규화 참조본은 하위 폴더 또는 `../../cutout/`에 별도 저장하며 원본을 덮어쓰지 않는다.
- ImageGen은 상용 장면을 만들 수 있지만 상면·하면 구조, 블루쿠션 위치, 에어홀, 에어셀, `ZOOM SPORTS` 표기를 바꾸면 폐기한다.
- GIF는 첫·중간·마지막 프레임 모두에서 동일 제품으로 보이는 소재만 사용한다.
- 원본 촬영 상태, 누끼 방식, 생성 과정 같은 내부 제작 설명은 소비자 상세페이지에 쓰지 않는다.

권장 촬영 파일명:

`01_front`, `02_back`, `03_left`, `04_right`, `05_top`, `06_bottom`,
`07_detail`, `08_in_hand`, `09_in_use`, `10_package`, `11_measurement`

JPG, PNG, HEIC, MP4, MOV 원본을 그대로 넣는다.
