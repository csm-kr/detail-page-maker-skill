# 아이스 쿨패치 상세페이지

도매꾹 상품 `23824901`의 확인된 상품정보, 공개 시장 불편 조사, 제품 파생 SSOT, ImageGen 맥락 소재, HyperFrames GIF를 결합한 800px 상용 상세페이지 프로토타입입니다.

## 열기

- `index.html`: 구매자용 상세페이지
- `studio.html`: 카피·글자 크기·정렬·색상·이미지 초점·이미지/GIF 교체, JSON 저장, 단일 HTML 내보내기
- `qa/export/cool-patch-detail-page-standalone.html`: 이미지와 GIF 13개를 모두 포함한 독립 실행 HTML

## 주장 경계

판매 화면에는 상품정보로 확인된 재질·크기·구성·사용 연령·사용법·주의사항만 사용했습니다. 온도 하락, 최대 사용 시간, 접착력, 저자극, 치료 효능, 인증 배지는 검증 전까지 차단합니다.

## 모션

`videos/cool-patch-motion-studio/`의 편집 가능한 HyperFrames 프로젝트에서 문제·준비·필름 제거·치수·주의 다섯 장면을 만들었습니다. 각 GIF는 800×800, 5.2초, 15fps, 무한 반복입니다.
