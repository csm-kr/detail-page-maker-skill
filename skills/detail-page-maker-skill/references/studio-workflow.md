# Studio 승인·개정판 계약

## 작업면

1. 에셋 검수
2. GIF·HyperFrames 편집
3. 상세페이지 조립
4. HTML 인터랙티브 편집
5. 최종 QA

## 역할

- Studio: 기계 검사, 상태·잠금·의존성 강제
- Codex: ImageGen·HyperFrames 작업과 시각 QA
- 사용자: 승인·재생성·보류·조립·게시 결정

## 승인

`qa.status === passed`, 하드 실패 0건, 사용자 결정이 모두 있어야 승인한다. 디자인 경고는 사용자가 판단할 수 있다.

## 조립

모든 필수 에셋의 승인 버전과 SHA-256을 manifest에 고정한다. 이후 에셋·GIF 탭은 읽기 전용이다.

## HTML 편집

허용:

- 카피·타이포·색
- 위치·크기·정렬·크롭
- 말풍선·꼬리·선·강조 박스
- 인터랙션
- 320·390·800px 오버라이드
- 자동 저장·undo/redo·체크포인트

금지:

- 에셋 등록·교체·재생성
- GIF 내부 레이어·타임라인 변경
- 제품 SSOT 변경

## 개정판

현재 조립본을 잠금 해제하지 않는다. 새 개정판이 현재 에셋 선택을 복제하고, 변경 에셋과 이를 의존하는 GIF·HTML 섹션만 다시 연다.

- QA 뒤: 게시용 단일 HTML
- 항상: 승인·프롬프트·HyperFrames·레이어·체크포인트를 포함한 Studio 프로젝트 묶음
