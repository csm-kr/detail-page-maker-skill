# Commercial Copy Tone Guide

기능 직역을 고객의 장면·감정·변화로 번역하고, 제작 메타데이터를 고객 화면에서
제거하기 위한 실행 요약이다.

## 기본 문장 구조

```text
고객 상황 → 감정 또는 망설임 → 제품이 주는 변화 → 증거 캡션
```

- 헤드라인은 8~16자 의미 덩어리 1~2줄을 우선한다.
- 부품명·치수·주의사항은 헤드라인이 아니라 캡션·표·정보 블록에 둔다.
- 비유는 촉감·실루엣·옷차림·계절처럼 장면으로 확인 가능한 범위에만 쓴다.
- 미확인 온도·차단율·지속 시간·성능을 비유로 과장하지 않는다.

## 고객의 목소리

- 후기 증거가 아니면 `오늘의 고민`, `옷장 앞 한마디`, `이런 날 있죠?`처럼
  편집 장치임을 밝힌다.
- 별점, 구매 인증, 가짜 이름·날짜·프로필, 출처 없는 체험 증언을 만들지 않는다.
- 말풍선은 18~42자, 2~4줄 이내로 쓰고 본체와 꼬리를 같은 불투명색으로 연결한다.

## 내부 표현을 고객 언어로 바꾸기

```text
제조사 확인 쿨 소재
→ 한여름의 팔 위로, 산뜻함이 머무는 소재

실물 구조를 기준으로 상용 촬영 톤으로 재구성
→ 공개 문장 삭제. 제품 장면과 자연스러운 캡션만 남긴다.

팔에는 여유를, 손등에는 이어지는 길이를
→ 햇살은 가볍게 멀리, 오늘의 실루엣은 그대로.
```

## 공개 금지

`제조사 확인`, `제조사 주장`, `MANUFACTURER_CLAIM`, `SSOT`, `ImageGen`,
`God Tibo`, `HyperFrames`, `생성 이미지`, `검수 완료`, `승인본`, `근거 이미지`,
`실물 구조를 기준으로`, `상용 촬영 톤으로 재구성`은 고객 화면에 쓰지 않는다.
