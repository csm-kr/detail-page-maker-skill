# 제품 동일성 계약

## 하드 잠금

- 실루엣과 가로·세로 비율
- 제품 색과 재질
- 로고·인쇄 문자·철자·방향
- 부품 수·위치·결합 구조
- 구멍·망사·돌기·얇은 부품
- 좌우 한 쌍의 거울 대칭 구조

제품 레이어의 프롬프트 수정은 조명·카메라·크롭·배경·그림자·연출에 한정한다. 구조 변경은 SSOT 수정과 새 개정판이 필요하다.

## 하드 실패

- 원본에 없는 구조 생성
- 로고·문자 오류
- 부품 이동·누락·추가
- 제품 기능과 다른 효과 시작점
- 중간 프레임에서 제품 정체성 붕괴
- 제품 길이·폭·아치 방향 변화

하드 실패는 사용자 승인 버튼을 잠근다. 잘못된 판정은 우회 승인하지 않고 QA를 다시 실행하거나 SSOT 연결을 수정한다.
