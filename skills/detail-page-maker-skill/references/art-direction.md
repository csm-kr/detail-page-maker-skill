# 상세페이지 아트디렉션

G1 카피 설계와 G4 HTML 조립에서 읽는다. `studio.md`가 배치와 QA를 다룬다면 이 문서는
**보이는 품질**을 다룬다. 사실과 안전선을 지켜도 이 문서를 어기면 결과물이 "그냥 만든 것"
으로 보인다.

조사 근거: Behance `상세페이지` 상위 프로젝트 실물 (누니 스튜디오, 브랜드 에이전시 슈터,
온라인창업사관학교, Sungbae Park, MINUTE design, Yeonjeong Jang 등 25개 프로젝트 · 실제
이미지 137장). 색과 밝기 항목은 그 이미지들을 medianCut으로 양자화해 **실측**한 값이다.
아래 규칙은 그 공통 문법을 추출한 것이다.

## 1. 헤드라인은 반드시 2단 웨이트다

한국 커머스 상세페이지에서 **가장 지배적인 단일 규칙**이다. 제목을 한 덩어리로 굵게 쓰면
바로 아마추어로 읽힌다.

```text
윗줄  조건 · 맥락 · 이유    Light 300, 작게(0.55~0.62배), 저채도 회색
아랫줄 결론 · 혜택 · 결과    Black 900, 크게, 잉크색 + 강조 단어만 브랜드 컬러
```

실측 예시.

| 윗줄 (Light, 작게) | 아랫줄 (Black, 크게) |
| --- | --- |
| 씻는 순간 채워지는 결 | 첫 세안부터 앰플케어 |
| 해마다 조금씩, 우리의 식탁에서 | 멀어지는 채소와 과일 |
| 영양을 가득 담은 쫀쫀한 모찌가 모발 한 올마다 밀착해 | 손상된 모발 큐티클 42.529% 개선 |
| 부드러운 과육과 깊은 향을 담은 | 프리미엄 고당도 머스크멜론 |

지키는 것.

- 윗줄은 문장을 끝내지 않는다. 아랫줄로 이어지는 연결 어미(`~해`, `~으로`, `~에서`,
  `~담은`)로 끝내 시선을 아래로 내린다.
- 윗줄과 아랫줄 사이 간격은 좁게(`margin-top: 6~10px`) 붙여 한 덩어리로 읽히게 한다.
- 별도의 회색 본문 문단을 제목 아래 또 붙이지 않는다. 윗줄이 그 역할을 이미 한다.
  본문이 정말 필요하면 이미지 **아래**로 내린다.

## 2. 강조는 단어 단위로, 문장 전체가 아니다

한 화면에서 색이 들어가는 단어는 **1~2개**다.

- 브랜드 컬러 + 900 웨이트로 그 단어만 올린다.
- 필요하면 그 단어 뒤에만 옅은 하이라이트 띠(`background: linear-gradient(transparent 62%, tint 62%)`)를 깐다.
- 숫자와 단위는 한 덩어리로 묶어 별도 스타일을 준다. 단위는 숫자보다 한 단계 작게.

`피부 결에도 <b>밀도</b>가 있다는 사실` 처럼 조사를 강조 밖에 두어야 문장이 살아 있다.

## 3. 라벨(eyebrow)은 작고 담백하게

`POINT 01`, `Problem`, `SOLUTION` 같은 라벨은 섹션의 이름표일 뿐이다.

- 얇은 아웃라인 pill(1px 브랜드 컬러 테두리, 투명 배경, 브랜드 컬러 글자) 또는
  그냥 작은 컬러 텍스트 한 줄.
- **진한 그라디언트 solid pill을 모든 섹션에 반복하지 않는다.** 가장 흔한 템플릿 신호다.
- 크기 16~18px, 자간 살짝 넓게, 굵기 700 이하.

## 4. 입체감은 그림자가 아니라 톤 대비로 만든다

**이 항목이 "세련됨"과 "템플릿"을 가르는 가장 큰 변수다.** 레퍼런스 카드는 대부분
`box-shadow`가 아예 없다. 대신 **배경에 톤을 넣고 카드를 순백으로** 둬서 밝기 차이만으로
띄운다.

```css
/* 하지 않는다 */
.card { background:#fff; box-shadow:0 22px 44px rgba(0,0,0,.16); }
/* 한다 */
.section { background:#eceae6; }          /* 배경에 톤 */
.card    { background:#fff; box-shadow:none; }  /* 카드는 순백 */
```

- 배경과 카드의 밝기 차는 **6~12%면 충분하다.** 그 이상은 카드가 떠 보인다.
- 그림자를 정말 써야 하면 blur를 크게 쓰지 말고 `0 2px 8px rgba(brand,.06)` 수준으로,
  반드시 배경색 계열로 틴트한다. 검정 그림자는 쓰지 않는다.
- 라운드는 페이지 전체에서 하나의 값으로 고정한다. 0 또는 8~20px 중 하나.
- 비교·시험 결과·단계처럼 **경계가 의미를 만드는 곳에만** 카드를 쓴다.
- 나머지는 풀블리드 컬러 필드 위에 제품을 그대로 얹는다.

## 5. 색: 넓은 면은 저채도, 좁은 면만 고채도

실측 결과(123장, medianCut 6색 양자화).

| 항목 | 실측 |
| --- | --- |
| 프레임 최대 면적 색의 밝기 | `L=1.0` 41% · `L=0.9` 17% · `L≤0.2` 20% · 나머지 22% |
| 비중성 브랜드 컬러의 채도 | 대부분 `S=0.20~0.45`, `S>0.6`은 거의 없음 |

여기서 나오는 규칙.

- **흰색과 초저채도 틴트가 페이지의 58%를 차지한다.** 기본은 밝은 화면이다.
- **딥 배경은 5섹션에 1개꼴**의 구두점이다. 연속으로 쓰지 않는다.
- **넓은 면적에 고채도를 칠하지 않는다.** 딥 배경도 채도를 눌러 쓴다.
- 고채도는 강조 단어, 라벨 바, 배지, 아이콘처럼 **좁은 면적에만** 남긴다.
- 제품 실물에서 색을 뽑되 그대로 쓰지 말고 두 갈래로 만든다.

```text
brand-deep   넓은 딥 배경   원색에서 채도를 20~30% 낮춘 값
brand        라벨 · 캡션    중간
brand-accent 강조 단어만    원색 그대로 (페이지에서 가장 채도 높은 색)
tint         옅은 배경      brand의 L을 0.95 이상으로 올린 값
```

섹션 배경은 3종을 넘기지 않는다. `white → tint → deep`.

## 6. 3분할 원형 아이콘 + 2줄 캡션

문제 나열, 핵심 요약, 사용 장면에 반복해서 등장하는 표준 장치다.

- 원형 아웃라인(1.5px) 안에 얇은 라인 아이콘, 지름 대략 화면 폭의 1/5.
- 아래 캡션 2줄. **1줄은 회색 Regular, 2줄은 브랜드 컬러 Bold.**
- 3개를 가는 수평선으로 연결하면 흐름이 생긴다.
- 원의 배경은 섹션 배경보다 밝게 둔다. 틴트 섹션이면 흰색, 흰 섹션이면 틴트.
- 아이콘 글리프는 **캡처에서 눈으로 읽어 본다.** 아이콘 라이브러리 없이 직접 그리면
  추상적인 곡선이 되기 쉽고, "충격"이 해돋이로, "아치"가 언덕으로 읽힌다. 뜻이 바로
  안 잡히면 화살표·느낌표·점선처럼 **문자에 가까운 기호**로 다시 그린다.

## 7. 780px 기준 타이포 스케일

| 역할 | 크기 | 굵기 | 자간 | 행간 |
| --- | ---: | ---: | ---: | ---: |
| 헤드라인 아랫줄 | 56~64px | 900 | -0.045em | 1.24 |
| 헤드라인 윗줄 | 30~34px | 300~400 | -0.02em | 1.45 |
| 라벨 | 16~18px | 600 | 0.06em | 1 |
| 본문 | 21~23px | 400~500 | -0.01em | 1.72 |
| 캡션 | 18~19px | 500/700 | -0.01em | 1.45 |
| 각주 | 14~15px | 400 | 0 | 1.55 |
| 큰 숫자 | 60~90px | 900 | -0.05em | 1 |

한글은 라틴보다 커 보이므로 자간을 음수로 조인다. 900 웨이트에서 자간을 조이지 않으면
글자가 뭉개진다.

## 8. 폰트는 굵기 폭이 있는 것을 쓴다

2단 웨이트는 **Light와 Black이 같은 가족 안에 있어야** 성립한다.

- 맑은 고딕은 Light/Regular/Bold 3단뿐이라 이 문법을 만들 수 없다. 기본값으로 쓰지 않는다.
- 우선순위: `Pretendard` → `Noto Sans KR`(가변 폰트, 100~900) → `나눔스퀘어` → 맑은 고딕.
- Windows 10/11에는 `NotoSansKR-VF.ttf`가 기본 설치되어 있어 300·400·500·700·900을
  모두 쓸 수 있다. `@font-face { font-family:'Noto Sans KR'; src: local('Noto Sans KR'); }`로
  선언한 뒤 `font-weight`만 바꾸면 된다.
- 로컬 폰트만 쓸 때는 실제 렌더 캡처에서 300과 900이 **눈에 띄게 다른지** 확인한다.
  차이가 없으면 폰트가 폴백된 것이다.

### 한 벌로 끝내지 말고 역할을 나눈다

폰트 하나로 전 페이지를 처리하면 아무리 잘 짜도 밋밋해진다. **역할이 다르면 얼굴도
달라야 한다.** 다만 어떤 얼굴을 쓸지는 고정 규칙이 아니라 **제품·타깃·톤을 보고
AI가 판단한다.** 아래는 배정할 역할의 축이지 폰트 목록이 아니다.

| 역할 | 고를 때 보는 것 |
| --- | --- |
| 본문 · 캡션 · 표 · FAQ | 굵기 폭이 넓고 작은 크기에서 버티는 중립 고딕. 페이지의 8할을 차지한다 |
| 기능 설명 헤드라인 | 본문과 같은 가족의 최대 굵기. 정보 전달이 목적이라 튀지 않아야 한다 |
| 감성 임팩트 헤드라인 | **다른 얼굴.** 후킹·문제 제기·클로징 2~3곳에만. 여기서 페이지의 성격이 정해진다 |
| 라틴 라벨 · 큰 숫자 | 콘덴스드 대문자체. 한글과 섞이지 않아 역할 구분이 즉시 읽힌다 |
| 손글씨 악센트 | 한두 곳. "그래서 준비했습니다!" 같은 전환 지점에만 |

지키는 선.

- **얼굴은 3~4개까지.** 그 이상은 통제가 안 된다.
- 감성 헤드라인용 얼굴을 **모든 제목에 쓰지 않는다.** 두세 곳에서 멈춰야 임팩트가 산다.
- 한글 고딕 두 종류를 비슷한 인상으로 섞지 않는다. 섞을 거면 **인상이 확실히 달라야** 한다.
- 라틴 전용체는 한글에 적용하지 않는다. 폴백이 일어나 자간이 무너진다.
- 배포본이 로컬 폰트에 의존하지 않도록, 쓰는 글자만 **서브셋해서 HTML에 임베드**한다.
  페이지에 실제로 쓰인 글자만 남기면 한글 서브셋도 수십 KB 수준이다.
- 임베드하는 폰트는 **재배포가 허용된 라이선스**인지 먼저 확인한다. SIL OFL은 허용된다.
  "무료 사용"이라도 재배포·임베딩을 금지하는 국내 배포 폰트가 많다.

## 8.5 정렬은 섹션의 역할에 따라 바뀐다

페이지 전체를 중앙정렬로 밀면 읽어야 하는 섹션에서 눈이 지친다. 레퍼런스는 두 모드를
번갈아 쓴다.

| 섹션 역할 | 정렬 |
| --- | --- |
| 후킹 · 문제 · POINT · 증명 · 클로징 | 중앙정렬 |
| 사용법 · 성분 · 제품정보 · 주의사항 · FAQ | **좌측정렬**, 번호나 라벨을 왼쪽 컬럼에 세움 |

좌측정렬 섹션의 표준 형태.

```text
01.   트리트먼트 샴푸 후 모발에
      물기를 가볍게 제거하고 바른 뒤
      약 3분 후 물로 헹구어주세요.
```

번호는 밑줄을 긋거나 컬러를 주고, 본문 블록은 왼쪽 가장자리를 맞춘다.

## 8.6 반복해서 나타나는 표준 부품

| 부품 | 형태 |
| --- | --- |
| 섹션 타이틀 | 영문 대문자 + 2~3px 브랜드 컬러 언더라인 |
| 단계 구분자 | `01 │ 라벨` solid pill, 좌우로 점선 rule이 뻗음 |
| 체크 리스트 | 브랜드 컬러 체크 아이콘 + 한 줄, 아이콘은 텍스트보다 작게 |
| 전후 라벨 바 | 이미지 바로 아래 붙는 **각진** 바. 전 = 회색, 후 = 브랜드 컬러, 흰 글자 |
| 수치 배지 | 원형 아이콘 + 숫자(900, 크게) + 단위(작게) + `*` |
| 본문 강조 | 한 문단에 핵심 어절 **하나만** 브랜드 컬러 + Bold |

본문 강조는 제목에만 색을 쓰던 습관을 깨는 지점이다. 설명 문단 안에서도 어절 하나를
올려 주면 스캔하는 눈이 걸린다. 단, 문단당 하나를 넘기지 않는다.

## 9. 각주 문화

수치·시험·조건에는 `*`를 붙이고 섹션 하단에 아주 작은 회색 글씨로 근거를 적는다.
근거가 없으면 수치를 쓰지 않는다. 각주는 신뢰의 장치이지 면피 장치가 아니다.

시험 결과의 각주는 **네 요소를 고정 순서로** 적는다.

```text
*시험 항목 / 시험 기관 / 시험 기간 / 대상 수와 개인차 고지
```

## 10. 근거를 보여주는 표준 UI

| 주장 | 장치 |
| --- | --- |
| 전후 변화 | 좌우 2분할 + 라벨 바(사용 전 = 회색, 사용 후 = 브랜드 컬러) |
| 추세·비교 수치 | 라인 차트 + 강조 배지 + 출처 각주 |
| 고객의 불편 | 말풍선 3~4개, 핵심 어절만 브랜드 컬러 |
| 구조·성분 | 분해도 + 얇은 지시선 콜아웃 |
| 규격 | 치수선 + 숫자, 표는 마지막에 |

## 11. 여백

한 화면에 하나의 메시지를 넣고, 제목 위아래로 **크게 비운다.** 섹션 상하 패딩은 780px
기준 90~120px가 기본이다. 빈 공간을 없애라는 말은 *의미 없는* 공간을 없애라는 뜻이지
여백을 줄이라는 뜻이 아니다. 이미지가 작아서 생긴 여백은 이미지를 키워서 없애고,
호흡을 위한 여백은 남긴다.

## 11.5 쿠팡은 Behance와 다르다 — 충돌하면 쿠팡을 따른다

앞의 규칙은 **포트폴리오 기준의 심미**다. 쿠팡은 **모바일에서 빠르게 스크롤하는 전환
매체**이므로 몇 지점이 정면으로 갈린다. 상세페이지가 쿠팡에 올라간다면 아래가 우선한다.

근거: 기준작으로 지정된 쿠팡 상품 페이지의 상세 이미지 원본(폭 780px · 높이 29,594px).

### 축소 배율이 모든 것을 정한다

**780px로 만든 페이지는 390px 스마트폰에서 정확히 절반으로 축소된다.** 디자인할 때의
크기가 아니라 **÷2 한 크기로 판단해야 한다.**

| 역할 | 780px 값 | 모바일 환산 | 판정 |
| --- | ---: | ---: | --- |
| 헤드라인 | 56~64px | 28~32px | ✔ |
| 서브 헤드 | 34~40px | 17~20px | ✔ |
| 본문 | **26~30px** | 13~15px | 최소선 |
| 캡션 · 표 | **24~27px** | 12~13.5px | 최소선 |
| 각주 | 20~22px | 10~11px | 하한 |

**본문을 20px 이하로 쓰지 않는다.** 모바일에서 10px가 되어 읽히지 않는다. Behance 작업물의
본문이 작아 보인다면 그 이미지가 860~1000px로 제작돼 축소율이 다르기 때문이다.

### 얇은 웨이트를 쓰지 않는다

Light 300은 절반으로 축소되면 획이 흐려져 사라진다. **쿠팡용 kicker는 500~600**을 쓰고,
계층은 굵기가 아니라 **색으로** 만든다.

```text
Behance  윗줄 Light 300 회색   →  아랫줄 Black 900 잉크
쿠팡     윗줄 Medium 600 잉크  →  아랫줄 ExtraBold 800 브랜드 컬러
```

### 헤드라인은 3단이다

쿠팡은 제목 아래에 **한 줄짜리 감성 서브카피**를 더 붙인다. 이 줄이 있어야 화면이
완결된다.

```text
편안한 착용감을 위한          ← kicker
아치 서포트 설계              ← punch (브랜드 컬러)
마치 물 위를 걷는 듯 편안합니다  ← 서브카피 (회색, 한 줄)
```

제목이 3줄까지 가는 것도 허용된다. Behance의 2줄 제한보다 느슨하다.

### 쿠팡 고유 부품

| 부품 | 형태 |
| --- | --- |
| POINT 라벨 | 아웃라인 pill + **오른쪽 끝에 solid 원**, 원 안에 숫자 |
| 강조 | 제목은 **색만**(하이라이트 띠 없이), 본문은 **실선 언더라인 + Bold** |
| 고지 박스 | 라운드 없는 **각진 아웃라인 사각형** |
| 구간 전환 | 굵고 큰 **컬러 아래 화살표** 하나 |
| 스크롤 유도 | 질문형 제목(`왜 …일까요?`), 말줄임표 뒤 느낌표(`통증… 그래서 준비했습니다!`) |
| 부위 설명 | 이미지 위 A·B·C 원형 인덱스 + 지시선 |
| 이미지 오버레이 | 사진 좌상단에 좌측정렬 카피를 얹어 이미지와 글을 합침 |

### 배경은 흰색이 아니라 옅은 브랜드 틴트가 기본

Behance는 흰색이 58%지만 쿠팡 상세는 **옅은 블루/브랜드 틴트가 바탕**이고 흰색은 카드로
쓰인다. 페이지 전체가 한 색계열로 물들어 보이는 쪽이 쿠팡에서는 더 완성돼 보인다.

## 12. 조립 전 자가 점검

타이포
- 모든 제목이 2단 구조인가. 한 덩어리 굵은 제목이 남아 있지 않은가.
- 웨이트 대비가 실제 캡처에서 구분되는가. 폴백된 것은 아닌가.
- **모든 글자 크기를 ÷2 해 봤는가. 본문이 13px 아래로 내려가지 않는가.**
- 쿠팡 출고면 얇은 웨이트(300)가 남아 있지 않은가.
- 한 화면에서 색이 들어간 단어가 2개를 넘지 않는가.
- 설명 문단에도 강조 어절이 하나씩 들어가 있는가.

재질
- **`box-shadow`가 큰 blur로 남아 있지 않은가.** 카드는 배경 톤 대비로 떠 있는가.
- 라운드 값이 페이지 전체에서 하나인가.
- 카드가 정말 경계가 필요한 곳에만 있는가.

색
- 넓은 면적에 고채도가 칠해져 있지 않은가.
- 딥 배경이 연속으로 붙어 있지 않은가. 5섹션에 1개 수준인가.
- 배경이 3종을 넘지 않는가. 브랜드 컬러가 페이지 끝까지 같은가.

구조
- 읽는 섹션(사용법·정보·FAQ)이 좌측정렬로 전환되어 있는가.
- 라벨이 모든 섹션에 solid pill로 반복되고 있지 않은가.
- 근거 없는 수치가 남아 있지 않은가. 각주 4요소가 지켜졌는가.
