# 판매형 카피와 구매 불안 해소

제품 상세페이지의 문장을 `판매 정보 70 : 브랜드 감성 30`으로 설계하는 실행
계약이다. 감성은 제품 차이와 구매 판단을 흐리지 않는 범위에서만 사용한다.

## 1. 첫 화면

첫 2~3초 안에 다음 세 가지가 함께 보여야 한다.

1. 판매 제품 자체가 화면에서 가장 크다.
2. 기존 대안과 다른 핵심 차이를 직접 말한다.
3. 확인된 구성·규격 중 구매에 중요한 한 가지를 짧게 보여 준다.

모델만 크게 보이거나 추상적인 계절 문장만 남으면 실패다. 제품은 유효 화면의
45~65%를 기본으로 하고, 제목은 제품을 가리지 않는 한쪽 안전영역에 둔다.

```text
약함: 그늘은 길게, 실루엣은 가볍게.
통과: 조이지 않게 여유롭고, 손등까지 길게.
```

```text
약함: 오늘의 옷에 살랑.
통과: 팔에 달라붙는 팔토시가 불편했다면, 여유롭게 떨어지는 루즈핏으로.
```

## 2. 한 장의 판매 공식

일반 설득 장은 다음 순서로 작성한다.

```text
특징 → 고객이 얻는 효익 → 실제 사용 장면 → 바로 붙는 시각 증거
```

- 특징: 눈으로 확인하거나 공급처가 명시한 구조·소재·치수
- 효익: 고객이 선택할 이유
- 사용 장면: 운전, 산책, 출근, 외출처럼 구체적인 순간
- 증거: 같은 장 또는 바로 다음 장의 제품 중심 이미지·GIF·실측

```text
특징: 세로 플리츠와 루즈핏
효익: 타이트한 스포츠형처럼 팔을 꽉 감싸는 인상을 줄인다
장면: 운전과 산책, 일상복
증거: 같은 축척의 팔 중심 비교와 드레이프 GIF
```

특징에서 멈추거나 효익을 `편안하게`, `가볍게`, `시원하게` 같은 추상어 한 단어로
끝내지 않는다. 어떤 구조가 어떤 상황에서 왜 도움이 되는지 한 번은 설명한다.

## 3. 명확성 우선

- 한 문장에는 장점 하나만 넣는다.
- 메인 제목은 결론, 서브는 구조와 사용 장면, 캡션은 무엇을 볼지 맡는다.
- 비유를 지워도 제품 차이가 남아야 한다.
- 소비자가 실제로 쓰는 말이 있으면 조어보다 우선한다.
- `손목에서 끝나는 토시`처럼 형태를 새로 이름 붙이지 않는다.
- `손등이 드러나는 팔토시`, `타이트하게 붙는 스포츠형`처럼 보이는 사실을 쓴다.
- 제품명이 없어도 통하는 계절 감성 문장을 세 장 이상 반복하지 않는다.
- 같은 장점은 문제 제기와 증명 회수를 포함해 최대 두 번만 말한다.

```text
모호: 손등은 또 그대로.
명확: 손목에서 끝나는 팔토시는 손등을 그대로 노출합니다.
```

```text
모호: 햇살보다 먼저 느껴지는 조임.
명확: 타이트하게 붙는 팔토시가 답답했다면, 루즈핏으로 바꿔보세요.
```

## 4. 줄바꿈

- 제목은 1~2줄, 한 줄 8~16자 의미 덩어리를 우선한다.
- 조사·어미·복합어 중간을 자르지 않는다.
- 첫 줄은 문제 또는 차이, 둘째 줄은 결과 또는 선택 이유를 맡긴다.
- 360px에서 한 글자만 다음 줄에 남는 고아 줄을 금지한다.
- 모바일에서 자동 줄바꿈이 달라져도 의미가 무너지지 않게 핵심 제목은 `<br>`로
  고정한다.

## 5. 제품 중심 비교

- 비교의 주인공은 얼굴·전신이 아니라 제품이 착용된 팔과 손등이다.
- 두 상태는 같은 축척·팔 각도·크롭 높이·배경 명도를 사용한다.
- 팔과 제품이 비교 프레임의 60% 이상을 차지하게 한다.
- `타이트형 / 루즈핏`, `손등 노출 / 손등 커버`처럼 비교 축 하나만 둔다.
- 모델 표정, 라벨, 배경 소품을 소구로 확대하지 않는다.
- 실제 제품 라벨은 보일 수 있지만 구매 이유가 아니면 제목·콜아웃·확대·표 행으로
  강조하지 않는다.

## 6. 구매 불안

상세페이지는 장점 소개와 같은 비중으로 구매 직전 질문을 해결한다. 상품마다 다음
항목을 근거 원장에서 확인하고, 확인된 값만 공개한다.

| 구매 질문 | 우선 증거 |
| --- | --- |
| 꽉 끼는가 | 평면 폭, 상단 단면, 신축 범위, 모델 팔둘레와 착용 상태 |
| 손등까지 오는가 | 엄지홀부터 손등 커프까지의 착용 이미지 |
| 흘러내리는가 | 밴딩 구조, 실제 착용 실험, 팔둘레 조건 |
| 비치는가 | 같은 조명 조건의 밝은 배경·피부 위 실물 |
| 팔이 굵어도 맞는가 | 상단 단면과 신축 범위, 권장 팔둘레 |
| 실제로 시원한가 | 공급처의 정성 소재 주장 또는 시험 결과 |
| 옷에 어울리는가 | 같은 제품의 캐주얼·출근·원피스 장면 |
| 한 쌍인가 | 실제 한 쌍 이미지와 `1세트 2개입` |
| 길이는 얼마인가 | 측정 시작·끝점 GIF와 규격표 |
| 어떻게 관리하는가 | 공급처 세탁 방법과 주의사항 |

값이 없으면 추정하지 않는다. `확인 필요` 카드를 공개 화면에 나열하지도 않는다.
해당 주장을 빼고 프로젝트 `blocked_claims`와 다음 수집 작업에 기록한다. 사이즈처럼
부분 사실만 있는 경우 확인된 값과 안전한 비교 방법만 안내한다.

## 7. 쿨·UV·성능

- 제조사 제공 `쿨 소재`는 정성적 소재 사실로 사용할 수 있다.
- 독립 냉감 시험이 없으면 온도가 내려간다, 열감이 낮아진다, 즉시 차가워진다고
  단정하지 않는다.
- 수치 근거가 없는 냉감은 그래프·막대·꺾은선·가짜 열화상 범례로 표현하지 않는다.
- 허용 시각화는 실제 제품 위의 짧은 쿨 스윕·공기 흐름과 정성적 색 전환이다.
- UPF·UV 차단율·지속 시간은 시험 또는 공급처 수치가 없으면 만들지 않는다.

```text
통과: 얇고 가벼운 여름용 쿨 소재.
통과: 타이트하게 밀착되지 않아 여름 외출에 한결 가볍게.
실패: 착용 후 온도가 내려갑니다.
```

## 8. 권장 서사

```text
제품 우선 Hero
→ BEFORE YOU CHOOSE 구매 질문 3개
→ 우리 제품의 직접 답
→ 핵심 차별점 3~4개와 각각의 즉시 증거
→ 스타일·사용 장면
→ 착용법
→ 구매 불안 Q&A
→ 구성
→ 핵심 치수 위치 GIF
→ 규격·소재·세탁·제조 정보
→ 핵심 차이와 구성 리마인드
```

한 장점을 정지 이미지·GIF·Q&A·피날레에서 모두 반복하지 않는다. 기존 페이지에서
같은 말을 3회 이상 반복하면 약 30%를 먼저 줄이고, 남은 두 번의 역할을
`주장`과 `증명 또는 최종 회수`로 구분한다.

## 9. 최종 정보

마지막 정보 장에는 확인된 항목만 한눈에 정리한다.

- 상품명
- 색상·옵션
- 수량·구성
- 총길이, 상단·하단 단면, 폭, 신축 범위 중 확인된 값
- 소재 혼용률
- 세탁 방법과 주의사항
- 제조국
- 제조자 또는 수입자

항목이 없다고 다른 제품·경쟁사·일반 상식에서 값을 가져오지 않는다.

## 10. QA

- 첫 화면의 가장 큰 시각 대상이 제품인가?
- 첫 제목만 읽어도 기존 대안과의 차이를 말할 수 있는가?
- 모든 핵심 장점이 `특징→효익→사용 장면→증거`를 갖는가?
- 팔·손등 비교가 제품 중심으로 같은 축척에서 보이는가?
- 라벨을 구매 이유로 강조하지 않았는가?
- 손등 불편을 `노출`이라는 명확한 결과로 표현했는가?
- 같은 장점이 세 번 이상 반복되지 않는가?
- 구매 불안 항목에 확인되지 않은 답을 만들지 않았는가?
- 냉감·UV·흘러내림·신축을 근거보다 강하게 말하지 않았는가?
- 360px에서 제목 의미 단위와 고아 줄이 안전한가?
