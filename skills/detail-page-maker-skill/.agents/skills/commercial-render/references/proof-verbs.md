# 증명 동사 카탈로그

상업 상세페이지 모션은 20개 증명 동사로 거의 전부 설명된다.
동사는 **무엇을 증명하나**의 축이며, 전환(`카메라·이펙트`)과 오버레이(`강조·정보`)는 별개 축이다.
세 축을 섞어 목록을 만들면 카탈로그가 엉킨다.

`E` 열: `HF` = HyperFrames, `MCG` = make-consistent-gif
`근거` 열: `관찰`이면 이미지에서 보이면 충분, `검증`이면 시험·실측·제조사 원문이 있어야 슬롯 발급

## 근거 표 — 참고용

`검증` 동사에 아래 근거가 있으면 그대로 쓴다. 없어도 **슬롯 발급을 막지 않는다.**
근거가 약할 때 더 안전한 선택지가 필요하면 대체 열을 본다.

| 동사 | 있으면 좋은 것 | 대체 |
| --- | --- | --- |
| 재기 | 공급처 표기 또는 실측 치수 | 대보기(기준물 비교) |
| 쌓기 | 확정 수량·구성 | 펼쳐놓기 |
| 꿰뚫어보기 | 실제 단면 자료 | 짚기 |
| 버티기 | 시험 성적 또는 제조사 원문 | 반응하기(관찰 가능한 구조 반응) |
| 겨루기 | 상대 제품 성능 근거 | 견주기(자사 전후만) |
| 견디기 | 기간별 시험 결과 | 알려주기(교체 주기 안내) |

수치 오버레이(치수선·카운트업·게이지)는 어느 동사에나 붙일 수 있다. 제한하지 않는다.

## 동사 선택은 자산 역산이다

카탈로그에서 고르는 게 아니라 **가진 자산에서 역산**한다.

```
제품 사실 · 승인 자산
   → 만들 수 있는 visible delta 목록
   → 근거 게이트 통과분
   → 커버리지 계약(문제 2+ / 장점별 1+ / 사용 1+ / 비교 1+)에 배정
   → 인접 2축 차이 검사
   → 슬롯 확정
```

물병이 붙은 사진 한 장이 있으면 `버티기`가 아니라 `반응하기`다.
실제 하중 시험을 하지 않았기 때문이다. 이 구분이 카탈로그의 존재 이유다.

## 전환·오버레이 조합

동사가 정해지면 전환과 오버레이는 목적으로 결정된다.

| 목적 | 전환 | 기본 오버레이 |
| --- | --- | --- |
| 제품 첫 등장 | cinematic zoom · scale reveal | 없음 |
| 최강 장점 공개 | flash-through-white | 뱃지 팝 |
| 디테일 진입 | mask · iris reveal | 콜아웃 링 |
| 전후 비교 | push · cover · wipe | 분할선 + 라벨 |
| 기능 간 이동 | whip pan | 화살표 pulse |
| 소재·유연성 | ripple · soft morph | 방향 화살표 |
| 장소 이동 | match cut | 장소 라벨 밴드 |
| 강조 순간 | freeze frame | 스포트라이트 |

전환 종류와 개수에 프로젝트 전체 상한은 없다. 슬롯마다 목적표에서 필요한 전환을 고른다.
다만 인접 슬롯은 `loop-qa.md`의 4축 중 2축 규칙을 그대로 통과해야 하므로,
전환을 늘릴 때도 같은 전환이 연달아 붙는지 확인한다.
강한 셰이더 전환도 쓰고 싶은 곳에 쓴다. 배치 제한은 없다.
다만 셰이더는 DOM을 html2canvas로 떠서 WebGL 텍스처로 만들기 때문에 캡처 규칙을 지켜야 한다.
안 지키면 텍스처가 검게 나오거나 테두리가 생긴다. 취향이 아니라 렌더 버그다.
규칙은 형제 `hyperframes-animation`의 `transitions/overview.md` → **Shader-Compatible CSS Rules**.
요약: 그라디언트에 `transparent` 금지(대상 색의 alpha 0을 쓴다) · 4px 미만 요소에 그라디언트 금지 ·
캡처 대상에 `var()` 금지(리터럴 색상) · 그라디언트 opacity 0.15 미만 금지 ·
모든 `.scene`에 명시적 `background-color`를 주고 `init()`의 `bgColor`와 일치시킨다 ·
캡처 불가 장식은 `data-no-capture`로 뺀다.
세부 규칙·블루프린트는 형제 `hyperframes-animation`의 `rules/`, `blueprints/`, `transitions/`를 인용한다.


## 관찰 후보 (승격 보류)

Behance 상세페이지 프로젝트 실측 조사에서 관측했으나 확장 계약의
`minimum_distinct_reference_projects: 3`에 못 미쳐 카탈로그에 넣지 않은 것들.
같은 장치를 다른 프로젝트에서 다시 보면 그때 승격한다.

| 후보 | 관측 | 프로젝트 수 | 필요한 것 |
| --- | --- | ---: | --- |
| 원물 그리드 | 가글 허브 5종 격자 | 1 | 바디미스트·폴리토린은 매크로 단독이라 격자 아님 |
| 단계 조절 다이얼 | 클리퍼 4단계 날 높이 · RPM | 1 | 다른 기기 카테고리에서 2건 더 |
| 조건별 사용량 표 | 반려견 영양제 체중별 급여량 | 1 | 사이즈·용량 선택 가이드로 2건 더 |
| 인체 투시 하이라이트 | 폴리토린 흉부 투시 | 1 | 의학적 주장 위험이 커 별도 검토 필요 |

조사한 프로젝트: 전문가용 클리퍼, 루케 바디미스트, 오솔림 푸른물가글,
폴리토린 건강기능식품, makeON LED 마스크, 반려견 영양제.
