# 주장 → 시각 은유 카탈로그

증명 동사는 **무엇을 증명하나**, 전환·오버레이는 **어떻게 움직이나**를 정한다.
이 문서는 세 번째 축이다. **눈에 보이지 않는 주장을 무엇으로 보이게 하나.**

`따뜻하다` `발이 편하다` `통기성이 좋다` 같은 감각·성능 주장은 제품을 아무리 크게
찍어도 사진으로 전달되지 않는다. 은유를 하나 골라 화면에 세워야 한다.

## 등급이 재는 것은 연출이 아니라 숫자다

**비유 연출 자체에는 제한이 없다.** 서리가 번지고, 온기가 퍼지고, 하중이 여러 점으로
흩어지는 연출은 상업 광고의 문법이며 화려할수록 좋다. 아래 등급은 그 연출에
**숫자·눈금·단위·범례를 붙일 수 있는가**만 판정한다.

| 등급 | 뜻 | 연출 | 숫자·눈금·범례 |
| --- | --- | --- | --- |
| `관찰` | 이미지에서 보임 | 자유 | 붙일 수 있음 |
| `조건` | 제조사 표기·사용 조건 있음 | 자유 | 조건 각주를 같은 화면에 |
| `검증` | 독립 시험 결과 필요 | **자유** | 근거 없으면 숫자만 뺀다 |

즉 `검증` 등급이라도 **연출을 포기하지 않는다.** `-5°C` 눈금과 온도 범례를 빼고
서리 연출은 그대로 간다. 아래 표의 마지막 열은 "연출 금지"가 아니라
"숫자를 뺀 버전"이다.

## 고르는 법

```
주장 문장 하나
   → 이 표에서 은유 하나
   → 근거 등급 확인. 검증인데 근거가 없으면 강등 열로 교체
   → 증명 동사 확정 (proof-verbs.md)
   → 전환·오버레이 확정 (proof-verbs.md 조합표)
   → 슬롯
```

한 주장에 은유 하나다. 냉감을 서리로 보여 주고 같은 화면에서 온도 숫자까지
띄우면 검증 대상이 둘로 늘어난다.

## 결정론 구현 메모

허용 속성은 `opacity` `x` `y` `scale` `rotation` `color` `backgroundColor`
`borderRadius` `transform` 뿐이다. `clip-path`·`width`·`height` 트윈은 금지다.

- 번짐·퍼짐(1·2·9·11) — 원형 레이어를 `scale` 0→1 + `opacity`. 반지름 트윈이 아니다.
- 투시(4·6) — 겉면 레이어 `opacity` 1→0, 속 구조 레이어 0→1. 같은 좌표에 겹쳐 둔다.
- 흐름 화살표(10·13) — 상수 좌표 배열에 `x`/`y` 트윈. `Math.random()` 금지.
- 게이지·타이머(19·20) — `scaleX`/`scaleY` + `transformOrigin`. `width` 트윈 우회.
- 형상 유지(12·14) — 하중 레이어만 움직이고 제품 레이어는 고정. 제품을 변형시키면
  생성형 모핑이 되어 제품 동일성 게이트에 걸린다.

제품 자체가 실제로 변해야 하는 5·14·16·17은 `make-consistent-gif` 경로를 검토한다.
판단 기준은 `engine-routing.md`의 단 하나의 질문이다.

## 확장 규칙

새 은유는 서로 다른 실제 프로젝트 3개 이상에서 반복 관측된 뒤 이 표에 넣는다.
한 상품에서 한 번 통했다는 이유로 추가하지 않는다.
