  ** 기본 명령 **

  - 공개 결과물에는 내부 메타데이터를 넣지 말아야 하고 완성된 상용 상세페이지의 품질로 만들어야 해
  - 상품에 대한 이해와 구매 전환을 최우선으로 하고, gif를 적극적으로 이용해서 이 제품의 상세페이지를 만들어줘
  - 이미지를 잘 생성해서 완성본 상세페이지까지 받아볼 수 있게 만들어줘. 쿠팡의 시각적 소구점과 우리 제품의 장점을 잘 보여주고 쿠팡의 기획을 잘 따라줘. 이미지와 영상은 다르되 메시지는 비슷하게 가져가줘
  - 배경용 백그라운드도 만들어서 멋지게 겹친 페이지를 만드는 것도 고려해줘
  - 이미지 크기는 상황에 따라 바꿔서 만들어줘. 정방형과 가로형을 주로 쓰고, 표현하려는 장면이 충분히 들어오는 사이즈를 지정해서 생성해줘
  - 비포&애프터 이미지는 하나를 먼저 생성한 뒤 그것을 레퍼런스로 1:1 종횡비로 변경하면 비교가 훨씬 눈에 잘 들어와
  - hyperframes로 만든 gif가 더 화려해야 해
  - gif의 시작 프레임과 끝 프레임이 어긋나 루프가 튀는 경우를 방어해줘
  - 효과가 확실하게 드러나도록 이미지와 이펙트는 화려하게, 약간 과장해서 써도 돼
  - 쿠팡 URL을 참고해서 우리도 훨씬 자극적이게 만들어줘. 제품과 구성이 비슷하니 이 페이지의 상세페이지 구성을 따라 장점을 살려줘
  - 각 부분/제품 사이즈와 사용법은 gif로 만들고 SSOT가 중요해. 일관성 유지를 신경 써줘
  - 메시지가 make sense 해야 해. 한눈에 메시지와 장점을 보여주면서 카피를 작성해줘
  - 디자인은 읽기 쉬운 줄바꿈과 심미적인 레이아웃 정렬을 지키고 기본은 중앙정렬로 해줘. 그리고 텅 빈 공간이 없게 .html을 구성해줘
  - 쿠팡이 타겟이니 자극적이고, 한눈에 메시지와 장점을 보여주면서 전달력이 있어야 해

  **쿠팡 상세페이지 제작 핵심 팁**

  쿠팡 상세페이지는 예쁜 이미지를 나열하는 광고가 아니라, 고객에게 제품의 구매 이유를 즉각적으로 전달하는 광고여야 한다.

  **1. 한 화면에는 하나의 핵심 메시지만 전달한다**

  각 섹션은 1초 안에 다음 중 하나를 명확하게 보여줘야 한다.

  - 어떤 불편을 해결하는가
  - 제품의 가장 중요한 장점은 무엇인가
  - 실제로 어떻게 작동하거나 사용하는가
  - 사용하면 어떤 결과를 얻는가

  제목은 짧고 결과 중심으로 작성하고, 보조 문구로 증명하도록 한다.
  문구를 읽는 순간 이미지가 그 주장을 직접 증명해야 한다.

  **2. 경쟁 페이지에서는 문구가 아니라 판매 논리를 참고한다**

  경쟁사의 카피와 이미지를 그대로 복제하지 말고 다음을 분석한다.

  - 어떤 고객 문제로 시작하는가
  - 어떤 장점을 가장 먼저 보여주는가
  - 장점을 어떤 순서로 설명하는가
  - 이미지와 영상으로 어떻게 증명하는가
  - 사용법, 옵션, 제품정보를 언제 제시하는가
  - 마지막에 어떤 메시지로 구매를 유도하는가

  동일 상품은 확인된 소구점과 전개 순서를 따라가도 되고 좋은 소구점을 이용한다.
  이미지·카피·그래픽은 새롭게 제작한다.
  유사 상품은 경쟁사의 주장을 그대로 사용하지 말고 실제 제품 근거를 별도로 확인한다.

  **3. 한글 문장은 의미 단위로 청킹한다**

  AI가 생성한 문장을 그대로 넣지 말고, 읽는 의미에 맞게 줄바꿈을 다시 설계해야 한다.

  좋은 예

  오래 사용해도

  부담은 가볍게

  다음과 같은 줄바꿈은 금지한다.

  간편한 설

  치 방법

  - 조사와 명사를 분리하지 않는다.
  - 숫자와 단위를 분리하지 않는다.
  - 제목은 보통 2~3줄 이내로 제한한다.
  - 핵심 단어를 마지막 줄에 배치한다.
  - 브라우저 자동 줄바꿈에만 의존하지 않는다.

  **4. 중앙 정렬과 시각적 밀도를 실제 화면에서 검수한다**

  제목, 제품, 원형 배지, 아이콘, 단계 안내는 같은 중심축을 사용한다.
  flex나 grid를 이용해 정렬하고 임의의 margin 값에 의존하지 않는다.

  CSS상 중앙이어도 글자의 자폭과 line-height 때문에 시각적으로 치우쳐 보일 수 있으므로,
  최종 렌더링 화면에서 광학 중심까지 확인해야 한다.

  빈 공간을 무조건 없애는 것이 아니라 의미 없는 공간을 없앤다.
  각 화면은 제품, 사용 장면, 핵심 문구, 기능 확대, 비교 이미지 중 하나가 충분히 크게 보이게 해야 한다.

  **5. 이미지는 결과를, GIF는 변화를 보여준다**

  정지 이미지는 제품의 형태, 완성된 결과, 구성품처럼 멈춰 있어도 이해되는 정보에 사용한다.
  GIF는 접기, 설치, 세척, 부착, 작동, 변화처럼 움직임이 있어야 이해되는 기능에만 사용한다.

  기능별로 모션 문법을 다르게 설계한다.

  | **기능** | **적합한 모션** |
  | --- | --- |
  | 사용 전후 | 슬라이더, 와이프, 좌우 비교 |
  | 설치·조립 | 단계별 손동작 |
  | 방수 | 물방울 낙하와 흘러내림 |
  | 탄성·복원 | 누르기, 변형, 복귀 |
  | 수납력 | 제품이 채워지거나 정리되는 과정 |
  | 제품 디테일 | 매크로 이동과 원형 콜아웃 |
  | 규격 | 가로·세로 측정선 순차 표시 |
  | 수량·구성 | 제품 누적과 숫자 카운트 |
  | 사용 장소 | 서로 다른 공간으로 장면 전환 |

  연속된 GIF는 카메라, 핵심 변화, 전환 방식, 강조 그래픽 중 최소 두 가지가 달라야 한다.
  모든 GIF에 확대·흔들기·스캔 효과를 반복하지 않는다.

  **6. GIF는 첫 프레임과 루프까지 검수한다**

  첫 프레임만 표시되더라도 제품과 핵심 메시지가 전달돼야 한다.
  애니메이션은 메시지를 새로 만드는 것이 아니라 첫 프레임의 메시지를 강화해야 한다.

  루프에서는 다음을 확인한다.

  - 첫 장면이 검거나 비어 있지 않은가
  - 마지막에서 처음으로 자연스럽게 연결되는가
  - 속도, 방향, 밝기가 루프 경계에서 튀지 않는가
  - 제품 위치와 크기가 갑자기 변하지 않는가
  - 제품 형태, 색상, 부품이 중간에 바뀌지 않는가
  - 숫자와 단계가 정확한 최종 값까지 도달하는가

  GIF는 변화, 작동 방식, 전후 비교, 숫자 세기처럼 강조를 위한 모션이 필요한 장면에 집중한다.
  복잡한 다중 장면과 정확한 타이밍이 필요하면 MP4를 먼저 완성한 뒤 GIF나 WebP 파생본을 제작한다.

  **7. 생성 이미지에서는 제품 정체성을 고정한다**

  이미지 생성 전에 제품의 불변 조건을 정한다.

  - 실루엣과 비율
  - 실제 색상과 재질
  - 버튼, 구멍, 손잡이, 로고 위치
  - 구성품과 결합 방식
  - 실제로 존재하지 않는 부품 생성 금지

  모든 장면에서 동일한 기준 제품 이미지를 참조한다. 배경, 장소와 보조 효과는 변경할 수 있지만
  제품 자체가 다른 상품처럼 변해서는 안 된다.
  AI 생성 이미지에는 가급적 한글을 넣지 않는다. 제품과 배경은 이미지로 만들고, 한글 카피와 숫자·단위는
  HTML이나 검증된 영상 폰트로 처리한다.

  **8. 썸네일은 각각 독립적인 광고로 만든다**

  같은 제품 사진에 문구 색상만 바꾼 썸네일을 여러 장 만들지 않는다. 썸네일 한 장이 소구점 하나를 맡는다.

  - 대표 장점
  - 사용 결과
  - 주요 기능
  - 간편한 사용법
  - 수량·구성 또는 규격

  **9. 모바일 우선 구성**

  - 작은 화면에서도 제품과 핵심 결과가 가장 먼저 보여야 한다.
  - 사용자가 빠르게 스크롤해도 장점이 즉시 이해되어야 한다.

  **10. 상세페이지 제작 순서를 반드시 지킨다**

  1. 제품 사실과 사용할 수 있는 주장을 확정한다.
  2. 고객의 문제와 구매 이유를 정의한다.
  3. 경쟁 상세페이지의 판매 논리를 분석한다.
  4. 전체 메시지 흐름과 우선순위를 설계한다.
  5. 각 메시지를 증명할 이미지와 장면을 정한다.
  6. 움직임이 실제 장점을 보여주는 부분에만 GIF를 배정한다.
  7. 이미지와 GIF를 제작하고 제품 동일성을 검수한다.
  8. 승인된 소재만 사용해 HTML을 조립한다.
  9. 모바일 줄바꿈, 중앙 정렬, 정보 밀도, 이미지 비율, GIF 루프를 조정한다.
  10. 빠르게 스크롤하며 전체 판매 흐름을 최종 검수한다.

  ** 핵심 **

  HTML부터 만들고 빈자리에 이미지를 채우는 방식이 아니라, 판매 논리 → 메시지 → 증명 소재 → HTML 순서로 제작한다.
  품질 기준은 이미지나 GIF의 개수가 아니라, 각 화면이 장점을 얼마나 빠르고 명확하게 전달하고 설득력 있게 증명하는가다.

  ** 안티패턴 **

  - HTML부터 먼저 만들지 않는다.
  - 빈 레이아웃을 만든 뒤 이미지를 채워 넣는 방식은 피한다.
